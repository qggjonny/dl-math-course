00-24 信息论：熵、交叉熵、KL 散度

一、信息量：越不可能的事，信息越大

画面： 有人告诉你两件事——

「明天太阳会升起来。」→ 你心想：废话。
「明天会下雪。」（你在三亚）→ 你震惊：怎么可能！

第一条信息量几乎为零——你早就知道。第二条信息量巨大——概率极低的事件真的发生了。

信息量与概率成反比。 数学上定义为：

$$I(x) = -\log P(x)$$

概率越小 → $-\log P$ 越大 → 信息量越大。对数底取 2 时单位是比特（bit），取 $e$ 时单位是奈特（nat）。深度学习里通常用 $e$。

例子：公平硬币正面概率 $P=0.5$，信息量 $-\ln(0.5) = 0.693$ nat。如果 $P=0.99$（几乎确定），信息量 $-\ln(0.99) \approx 0.01$ nat——几乎没信息。

二、熵：平均来看，有多不确定？

信息量是一件事的。如果你想描述整个概率分布的不确定性——把所有可能结果的信息量按概率加权平均：

$$\boxed{H(P) = -\sum_x P(x) \ln P(x)}$$

这就是熵。它衡量的是：从这个分布里随机抽一个结果，平均会得到多少 surprise。

极值情况：

  • 确定性分布 $P=[1, 0, 0]$（只有一个选项，概率 100%）：$H = -1\ln1 - 0 - 0 = 0$。零不确定性。
  • 均匀分布 $P=[\frac13, \frac13, \frac13]$：$H = -3 \times \frac13 \ln\frac13 = \ln 3 \approx 1.099$。最大化——你完全不知道会抽到哪个。

在分类问题里：如果模型的预测分布熵很高（接近均匀）→ 模型很不确定。熵很低（接近 one-hot）→ 模型很自信。

# 00-20 熵：衡量一个概率分布的不确定性
# 导入numpy，别名np
import numpy as np
# probs：概率数组，如 [0.95, 0.03, 0.02]
def entropy(probs):
    """H(P) = -Σ p_i ln(p_i)"""
# 只算 p > 0 的项（ln(0) 数学上无定义，也会产生-inf）
    # H = -Σ pᵢ log(pᵢ)，只对 pᵢ>0 的项求和（log0无定义）
    return -np.sum(probs[probs > 0] * np.log(probs[probs > 0]))
#        np.log()：自然对数ln（底e→单位nat）
#        probs[probs>0]：布尔索引，只取概率>0的元素
#        -sum(p_i * ln(p_i)) → 非负值，熵越小越确定
# 三个猫狗鸟分类——展示不同确定程度对应的熵值
# 模型：95%确定是猫，熵应≈0.2（很确定）
confident = np.array([0.95, 0.03, 0.02])
# 模型：不太确定，熵应≈1.1（中等）
uncertain = np.array([0.40, 0.35, 0.25])
# 完全均匀分布，熵应=ln(3)≈1.099（最大）
uniform   = np.array([1/3, 1/3, 1/3])
# ~0.2 —— 几乎确定
print(f"熵(确定)  = {entropy(confident):.4f}")
# ~1.1 —— 比较混乱
print(f"熵(不确定)= {entropy(uncertain):.4f}")
# ~1.099 = ln(3) —— 完全不确定的最大熵
print(f"熵(均匀)  = {entropy(uniform):.4f}")

三、交叉熵：我的模型和真相差多远？

真实分布是 $P$（比如图片的真标签：100% 是猫）。模型的预测是 $Q$（输出 [0.7, 0.2, 0.1]）。怎么量化模型错得有多离谱？

用交叉熵：

$$\boxed{H(P, Q) = -\sum_x P(x) \ln Q(x)}$$

和熵公式对比——唯一的区别：对数里是 $Q$ 而不是 $P$。也就是：真实的分布 $P$ 来决定「哪个结果重要」，但用模型预测的概率 $Q$ 来算信息量。

画面： 真实标签说「这就是猫」（$P = [1, 0, 0]$）。如果模型也输出 $Q = [0.99, 0.01, 0]$，交叉熵 = $-\ln(0.99) \approx 0.01$——很小，模型几乎没错。如果模型瞎猜 $Q = [0.01, 0.5, 0.49]$，交叉熵 = $-\ln(0.01) \approx 4.6$——巨大，模型被狠狠打脸。

分类任务里交叉熵为什么当损失函数？ 交叉熵最小 = 模型的预测分布 $Q$ 最接近真实分布 $P$。梯度下降让交叉熵越来越小 → 模型的预测越来越准。

# 00-20 交叉熵：衡量模型预测与真实标签的差距
# p_true=真实分布(one-hot)，q_pred=模型预测
def cross_entropy(p_true, q_pred):
    """H(P,Q) = -Σ p_i ln(q_i)"""
# 只算 p > 0 的项（真实概率为0的类别不参与损失计算）
    # mask：布尔数组，标记哪些位置p_i>0
    mask = p_true > 0
    # H(P,Q) = -Σ pᵢ log(qᵢ)，用真实分布p算、模型预测q做log
    return -np.sum(p_true[mask] * np.log(q_pred[mask]))
#        p_true[mask]：真实概率>0的项（one-hot时只有一个1.0）
#        np.log(q_pred[mask])：模型对"真类别"预测概率的ln
#        叉熵越小 → 模型预测越接近真实分布
# 真标签：猫（one-hot编码：[猫=1, 狗=0, 鸟=0]）
# 真实标签：100%是猫
y_true = np.array([1.0, 0.0, 0.0])
# 三个模型的预测——展示不同程度的偏差
# 好：90%确定是猫 → 交叉熵 =-ln(0.90)≈0.105
good  = np.array([0.90, 0.05, 0.05])
# 一般：一半确定是猫 → 交叉熵 =-ln(0.50)≈0.693
ok    = np.array([0.50, 0.30, 0.20])
# 差：认为很可能是狗 → 交叉熵 =-ln(0.10)≈2.303
bad   = np.array([0.10, 0.60, 0.30])
# ~0.105 — 模型几乎没错
print(f"交叉熵(好) = {cross_entropy(y_true, good):.4f}")
# ~0.693 — 有偏差
print(f"交叉熵(一般)= {cross_entropy(y_true, ok):.4f}")
# ~2.303 — 错得离谱
print(f"交叉熵(差) = {cross_entropy(y_true, bad):.4f}")

四、KL 散度：两个分布"形状"差多少？

交叉熵 = 熵 + KL 散度。推导只差一行——把 $D_{KL}$ 的定义展开再拆分：

$$\begin{aligned} D_{\mathrm{KL}}(P \parallel Q) &= \sum_x P(x) \ln\frac{P(x)}{Q(x)} \\ &= \sum_x P(x) \big[\ln P(x) - \ln Q(x)\big] \\ &= \underbrace{\sum_x P(x) \ln P(x)}_{-H(P)} \;-\; \underbrace{\sum_x P(x) \ln Q(x)}_{-H(P,Q)} \\ &= -H(P) + H(P, Q) \end{aligned}$$

移项即得：$H(P,Q) = H(P) + D_{\mathrm{KL}}(P \parallel Q)$。

KL 散度的定义公式：

$$\boxed{D_{\mathrm{KL}}(P \parallel Q) = \sum_x P(x) \ln\frac{P(x)}{Q(x)}}$$

KL 散度衡量的是： 用 $Q$ 来近似 $P$，比直接用 $P$ 多浪费了多少信息。熵 $H(P)$ 是「最低消费」——数据本身的不确定性。KL 散度是「超额消费」——模型不好带来的额外成本。

关键性质：

  • $D_{\mathrm{KL}}(P \parallel Q) \ge 0$，当且仅当 $P=Q$ 时等于 0（两个分布完全一样）
  • 不对称：$D_{\mathrm{KL}}(P \parallel Q) \neq D_{\mathrm{KL}}(Q \parallel P)$。不是真正的「距离」

为什么训练时用交叉熵而不是 KL 散度？ 因为 $H(P)$（真实标签的熵）是常数——训练数据固定了就不变。最小化交叉熵 = 最小化 KL 散度，所以交叉熵就够了。

# 00-20 KL 散度：验证 H(P,Q) = H(P) + D_KL(P||Q)
# p=真实分布，q=模型预测分布
def kl_divergence(p, q):
    """D_KL(P||Q) = Σ p_i ln(p_i/q_i)"""
    # 只算真实概率>0的项（避免ln(0)）
    mask = p > 0
    # D_KL = Σ pᵢ log(pᵢ/qᵢ)，衡量q偏离p的程度
    return np.sum(p[mask] * np.log(p[mask] / q[mask]))
#        ln(p_i/q_i)：比值越大 → 模型预测偏离越大 → KL散度越大
#        D_KL≥0恒成立（吉布斯不等式），P=Q时D_KL=0
# 真实标签：one-hot（猫）
y_true = np.array([1.0, 0.0, 0.0])
# 模型预测：90%猫，5%狗，5%鸟
pred   = np.array([0.90, 0.05, 0.05])
H_P = entropy(y_true)                     # 真实标签的熵：one-hot的熵恒为0
H_PQ = cross_entropy(y_true, pred)        # 交叉熵：-ln(0.90) ≈ 0.105
D_KL = kl_divergence(y_true, pred)        # KL散度：计算"额外成本"
# 0.0000 —— one-hot没有不确定性
print(f"H(P)    = {H_P:.4f}")
# 0.1054 —— 交叉熵≈KL散度（因为H(P)=0）
print(f"H(P,Q)  = {H_PQ:.4f}")
# 0.1054 —— 模型不好带来的额外成本
print(f"D_KL    = {D_KL:.4f}")
# 验证恒等式：H(P,Q) = H(P) + D_KL(P||Q)
# 验证恒等式：交叉熵 = 熵 + KL散度
print(f"H(P,Q) = H(P) + D_KL? {abs(H_PQ - (H_P + D_KL)) < 1e-10}")
# abs(差值) < 1e-10 → True，浮点误差范围内相等 ✓
# 结论：训练时最小化交叉熵 = 最小化KL散度（H(P)是常数无影响）
