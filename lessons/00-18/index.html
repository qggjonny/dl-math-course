最大似然估计 MLE

一、反问题：看到结果，猜原因

画面： 你走进一间屋子，发现地上有几根头发、一杯没喝完的咖啡。你想知道：刚才在这里的人更喜欢喝咖啡还是喝茶？

你没法直接知道，但可以反推：如果这个人喝咖啡，地上出现这些现象的概率有多大？如果喝茶呢？比较这两个概率——哪个更高，哪个解释更合理。

这就是似然的直觉：

$$P(\text{观察到这些} \mid \text{假设这个参数})$$

数据是固定的，参数是变量。在所有可能的参数值中，选那个"让观测数据出现概率最大"的参数。

二、抛硬币的例子

抛一枚硬币 10 次，7 次正面。硬币正面概率 $\theta$ 是多少？

如果 $\theta = 0.5$（公平硬币），出现"10 次中 7 次正面"的概率：

$$P(7\text{正} \mid \theta=0.5) = \binom{10}{7} (0.5)^7 (0.5)^3 \approx 0.117$$

如果 $\theta = 0.7$：

$$P(7\text{正} \mid \theta=0.7) = \binom{10}{7} (0.7)^7 (0.3)^3 \approx 0.267$$

$0.267 > 0.117$——$\theta=0.7$ 比 $\theta=0.5$ 更有可能产生这个结果。那最可能的是哪个？

三、似然函数

把概率写成 $\theta$ 的函数——这就是似然函数：

$$L(\theta) = P(\text{数据} \mid \theta) = \binom{10}{7} \theta^7 (1-\theta)^3$$

$\binom{10}{7}$ 是常数，不影响最大化。所以最大化 $L(\theta)$ 等价于最大化：

$$\theta^7 (1-\theta)^3$$ 
# 00-18 似然函数 — 抛硬币 10 次 7 正，猜 θ
import numpy as np

thetas = np.linspace(0.01, 0.99, 100)  # 100 个候选 θ 值
likelihood = thetas**7 * (1 - thetas)**3      # L(θ) = θ⁷(1-θ)³
best_idx = np.argmax(likelihood)              # 似然最大的 θ 的下标

print(f"最大似然估计 θ̂ = {thetas[best_idx]:.3f}")
print(f"直觉：7/10 = {7/10}")
print(f"一致！MLE = 样本比例")

结果 $\hat{\theta}_{\text{MLE}} = 0.7$。直觉正确：抛 10 次 7 正，正面率最可能是 0.7。

四、对数似然——把乘变加

实际问题中数据量很大，$\theta_1 \times \theta_2 \times \cdots \times \theta_N$ 会溢出或下溢。对策：取对数。

$\ln$ 是单调增函数，所以最大化 $L(\theta)$ 和最大化 $\ln L(\theta)$ 等价：

$$\ell(\theta) = \ln L(\theta) = 7\ln\theta + 3\ln(1-\theta) + \text{常数}$$

乘法变成加法——好算了。然后对 $\theta$ 求导：

$$\frac{d\ell}{d\theta} = \frac{7}{\theta} - \frac{3}{1-\theta} = 0 \quad\Longrightarrow\quad \hat{\theta} = \frac{7}{10}$$

一般情况：$n$ 次试验 $k$ 次成功 → $\hat{\theta}_{\text{MLE}} = k/n$。

五、MLE 通向损失函数

这是 MLE 最核心的用途——它解释了为什么交叉熵是分类的损失函数、MSE 是回归的损失函数。

回归：假设误差服从高斯分布。

模型预测 $\hat{y}$，真实值 $y$。假设 $y = \hat{y} + \varepsilon$，$\varepsilon \sim \mathcal{N}(0, \sigma^2)$：

$$P(y \mid \hat{y}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y - \hat{y})^2}{2\sigma^2}\right)$$

$N$ 个独立样本的似然：

$$L = \prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)$$

取对数——把连乘变成连加：

$$\begin{aligned} \ell &= \ln L = \ln\prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right) \\[4pt] &= \sum_{i=1}^N \ln\left[\frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)\right] \\[4pt] &= \underbrace{N \ln\frac{1}{\sqrt{2\pi\sigma^2}}}_{\text{常数，不依赖 }\hat{y}_i} \;+\; \sum_{i=1}^N \left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right) \end{aligned}$$

常数项 $N\ln(1/\sqrt{2\pi\sigma^2})$ 不含模型参数 $\hat{y}_i$，不影响优化——最大化 $\ell$ 时可以丢掉。因子 $1/(2\sigma^2) > 0$ 是正常数，最小化时也可省略。所以：

$$\text{最大化 }\ell \;\Longleftrightarrow\; \text{最小化 } \sum_{i=1}^N (y_i - \hat{y}_i)^2$$

最大化 $\ell$ = 最小化 $\sum (y_i - \hat{y}_i)^2$ → MSE！

分类：假设标签服从伯努利/类别分布。

二分类，模型预测概率 $\hat{p}$，真实标签 $y \in \{0,1\}$：

$$P(y \mid \hat{p}) = \hat{p}^y (1-\hat{p})^{1-y}$$

取负对数：

$$-\ln L = -\sum_{i=1}^N \big[y_i \ln \hat{p}_i + (1-y_i) \ln(1-\hat{p}_i)\big]$$

这就是交叉熵损失！

# 00-18 用 MLE 拟合高斯分布 — 从数据反推均值和方差
import numpy as np

# 生成真实分布为 N(5, 2²) 的 1000 个样本
np.random.seed(42)
true_mu, true_sigma = 5.0, 2.0
data = np.random.normal(true_mu, true_sigma, 1000)

# MLE 估计：高斯分布的 MLE 就是样本均值和样本标准差
mu_hat = np.mean(data)                       # μ̂ = (1/N) Σ xᵢ
sigma_hat = np.std(data)                     # σ̂ = sqrt((1/N) Σ (xᵢ-μ)²)

print(f"真实参数: μ={true_mu}, σ={true_sigma}")
print(f"MLE 估计: μ̂={mu_hat:.3f}, σ̂={sigma_hat:.3f}")

# 验证：算对数似然
def log_likelihood(mu, sigma, data):
    """高斯分布的对数似然
    mu: 均值
    sigma: 标准差
    data: 观测数据
    """
    n = len(data)
    # log L = -n/2·log(2πσ²) - 1/(2σ²)·Σ(xᵢ-μ)²
    return -n/2*np.log(2*np.pi*sigma**2) - np.sum((data-mu)**2)/(2*sigma**2)

ll_mle = log_likelihood(mu_hat, sigma_hat, data)
ll_off = log_likelihood(4.0, 2.5, data)     # 故意用错误参数
print(f"\nMLE 对数似然: {ll_mle:.1f}")
print(f"错误参数对数似然: {ll_off:.1f}")
print(f"MLE 更高 ✓")

六、MLE 和贝叶斯的区别

00-17 学了贝叶斯定理：$P(\theta \mid \text{数据}) \propto P(\text{数据} \mid \theta) \cdot P(\theta)$。

  • MLE：只看 $P(\text{数据} \mid \theta)$，最大化它——不管 $\theta$ 本身有多大概率出现
  • 贝叶斯：还要乘先验 $P(\theta)$——如果 $\theta=0.99$ 按理说很罕见，贝叶斯会惩罚它
  • MAP（最大后验）：贝叶斯中最大化 $P(\theta \mid \text{数据})$ 而非 $P(\text{数据} \mid \theta)$
为什么深度学习都选 MLE： 数据量大的时候，似然主导，先验的影响很小。MLE 和 MAP 差别不大。所以等价于：做回归就最小化 MSE，做分类就最小化交叉熵——不需要显式计算先验。
