00-10 函数、对数与指数

函数：一台自动售货机

想象一台自动售货机：你投进去一个数字，机器内部按固定规则处理，吐出一个数字。

投 3 → 吐出 7。投 5 → 吐出 11。投 0 → 吐出 1。

这个机器就是函数。给它一个输入 $x$，它按规则产生一个输出。记成：

$$f(x) = \text{输出}$$

$f$ 是函数的名字（就像给机器贴个标签），$x$ 是输入（投进去的东西），$f(x)$ 是输出（吐出来的东西）。

术语含义售货机比喻
输入 $x$自变量，你选的数你投进去的硬币
输出 $f(x)$因变量，机器算出的结果掉出来的饮料
定义域 (domain)所有能投的 $x$ 的集合机器能识别的硬币种类
值域 (range)所有可能吐出的值的集合机器里所有饮料种类

函数就是一个映射——把定义域里的每个元素，映射到值域里的一个元素。投一个 $x$，只能吐出一个结果（不能同时吐两瓶可乐）。但不同的 $x$ 可以吐出同一个结果（选不同按钮可能得到同一款饮料）。

函数是数学中最基础的概念。搞懂函数——理解「输入→规则→输出」这个模型——就像学会了数学世界的通用语法。后续课程中你会看到：所有复杂的计算，本质上都是函数的组合与变换。

最简单的函数：线性函数

售货机最简单的规则是「加倍再加 1」：

$$f(x) = 2x + 1$$

$x=0 \to f(0)=1$，$x=1 \to f(1)=3$，$x=2 \to f(2)=5$……每次 $x$ 增加 1，$f(x)$ 增加 2。线性的意思是：变化是匀速的。图像是一条直线，斜率 = 2（每走一步升 2），截距 = 1（在 $x=0$ 时的高度）。

线性函数很好理解，但世界不是线性的。下面进入真正有趣的部分。

指数函数：增长会加速

放一个细菌在培养皿里。每分钟分裂一次：1 个变 2 个，2 个变 4 个，4 个变 8 个……这不是「每次加 2」的匀速增长——这是每次翻倍。

第 $n$ 分钟后，细菌数量 = $2^n$。

$$2^0 = 1,\; 2^1 = 2,\; 2^2 = 4,\; 2^3 = 8,\; 2^4 = 16,\; \dots$$

注意增长速度：从 $n=3$ 到 $n=4$，增加了 8 个。从 $n=10$ 到 $n=11$，增加了 1024 个。指数增长的特征：增长量越来越大——存量越大，增量越大。这和线性增长（每次加固定量）完全不同。

自然常数 $e$

在数学中，最重要的指数底数不是 2，不是 10，而是一个奇怪的数：

$$e \approx 2.718281828\dots$$

$e$ 叫自然常数，和圆周率 $\pi$ 一样是个无理数（无限不循环小数）。它为什么「自然」？

核心原因：$e^x$ 的导数（变化率）就是它自己。 也就是说，$e^x$ 在任意点的增长速率恰好等于它当前的值——这是唯一具有这个性质的函数。这条性质让 $e^x$ 成为微积分中最核心的函数。

🧠 直观理解 $e$： 想象银行给你 100% 年利率，但按复利计算。如果一年计息一次 → 年底 $1 变 $2。如果每半年计息一次 → 年底 $(1+0.5)^2 = 2.25$。如果每秒计息 → 年底趋近 $e \approx 2.718$。$e$ 就是「无穷细粒度复利」的极限结果。

在数学中，$e^x$（通常写成 np.exp(x)）和正态分布、复利计算、种群增长模型等紧密相关。后续课程中你会频繁遇到它——先把基本操作学会。

用代码看 $e^x$ 的增长

# 00-10 第一步：感受指数函数——线性 vs 指数的增长速度对比
# 导入numpy，别名np
import numpy as np

# np.exp(x) — 计算 e^x。exp = exponential（指数）
# 输入一个数，返回 e 的这个数次方
print(f"e^0 = {np.exp(0)}")      # 任何数的0次方都是1 → 1.0
print(f"e^1 = {np.exp(1)}")      # e^1 = e本身 → 2.71828...
print(f"e^2 = {np.exp(2)}")      # e² ≈ 7.389
print(f"e^5 = {np.exp(5)}")      # e⁵ ≈ 148.4 — 已经超过100了

# np.exp支持数组输入——对数组每个元素分别计算e^x
x = np.array([0, 1, 2, 3, 4, 5])        # 输入值 [0,1,2,...,5]
print(f"e^x 对 [0..5] = {np.exp(x)}")    # 批量输出: [1, 2.72, 7.39, 20.1, 54.6, 148.4]

# 对比线性函数 f(x) = 2x+1：
linear = 2 * x + 1
print(f"线性 2x+1   = {linear}")      # [1, 3, 5, 7, 9, 11] — 匀速增长
print(f"指数 e^x    = {np.exp(x)}")    # [1, 2.7, 7.4, 20, 55, 148] — 加速增长！

看输出：$x=5$ 时线性只到 11，指数已经飙到 148。这就是指数爆炸——增长速度远超直觉，是理解很多数学现象的关键。

对数：指数的逆运算

指数问的是：「$e$ 的多少次方等于这个数？」比如 $e^3 = 20.085$，那么：

$$\ln(20.085) = 3$$

$\ln$ 读作「natural log」（自然对数），它就是 $e^x$ 的逆运算：

🔗 互为逆运算：
$e^x = y \;\Longleftrightarrow\; \ln(y) = x$
指数问「底数的次数方等于多少」，对数问「多少次数方等于这个数」。一个向前，一个倒退。

比喻： 指数是「把细菌培养 $n$ 分钟，有多少细菌？」对数反过来问：「培养到 1000 个细菌，需要多少分钟？」

如果底数是 2：$\log_2 8 = 3$（因为 $2^3=8$）。如果底数是 10：$\log_{10} 100 = 2$（因为 $10^2=100$）。在高等数学中，我们几乎只用 $\ln$（底数是 $e$），因为它有最简洁的数学性质。

关键性质：对数把乘法变成加法

这是对数最重要的性质——把乘法降级为加法：

$$\boxed{\ln(ab) = \ln a + \ln b}$$

证明： 设 $a = e^x$，$b = e^y$。那么 $ab = e^x \cdot e^y = e^{x+y}$（指数法则：同底数幂相乘，指数相加）。取对数：$\ln(ab) = \ln(e^{x+y}) = x+y = \ln a + \ln b$ ✓。

用数字验证： $\ln(2 \times 3) = \ln 6 \approx 1.792$，$\ln 2 + \ln 3 \approx 0.693 + 1.099 = 1.792$ ✓。

为什么这个性质如此关键？ 因为很多计算涉及大量数字连乘。$0.9 \times 0.8 \times 0.7 = 0.504$——乘着乘着数字变得非常小，计算机的浮点精度扛不住（下溢）。取对数后：$\ln 0.9 + \ln 0.8 + \ln 0.7 \approx -0.105 - 0.223 - 0.357 = -0.685$——都是好算的普通数字。

对数把乘积变成求和，稳定的求和。

第二个关键性质：把指数拉到前面

$$\boxed{\ln(a^n) = n \cdot \ln a}$$

指数 $n$ 被「拉下来」变成乘法系数。证明：$\ln(a^n) = \ln(\underbrace{a \cdot a \cdots a}_{n\text{ 个}}) = \underbrace{\ln a + \ln a + \cdots + \ln a}_{n\text{ 个}} = n \cdot \ln a$。

这个性质极其有用——能把指数表达式变成简单的线性形式，大幅简化计算。

自然对数 vs 常用对数

写法底数用途
$\ln x$$e \approx 2.718$高等数学、微积分（性质最简洁）
$\log_{10} x$$10$工程（分贝、pH 值）、科学计数法
$\log_2 x$$2$计算机科学（比特、二分查找）

注意：在数学文献和编程中，$\log$ 经常默认指 $\ln$（自然对数）。numpy 中也是：np.log(x) 就是 $\ln(x)$。这点容易搞混——看到 $\log$ 时先确认底数。

用代码验证对数性质

# 00-10 第二步：验证对数的两个核心性质
import numpy as np

# np.log(x) — 计算 ln(x)，自然对数（以e为底）
# 注意：x必须大于0，ln(0)和ln(负数)无定义
print(f"ln(1) = {np.log(1)}")      # e^0=1 → ln(1)=0.0
print(f"ln(e) = {np.log(np.e)}")  # e^1=e → ln(e)=1.0（np.e = e ≈ 2.718）

# 性质①：ln(ab) = ln(a) + ln(b)
a, b = 4, 7
left = np.log(a * b)                       # ln(28) ≈ 3.332
right = np.log(a) + np.log(b)              # ln(4)+ln(7) ≈ 1.386+1.946 = 3.332
print(f"ln(4×7) = {left:.4f}")        # 3.3322
print(f"ln4+ln7 = {right:.4f}")      # 3.3322
# allclose容忍浮点误差判断近似相等 → True
print(f"相等? {np.allclose(left, right)}")

# 性质②：ln(a^n) = n·ln(a)
n = 3
left2 = np.log(a ** n)                     # ln(4³) = ln(64) ≈ 4.159
right2 = n * np.log(a)                     # 3 × ln(4) = 3 × 1.386 = 4.159
print(f"ln(4³) = {left2:.4f}")       # 4.1589
print(f"3·ln4  = {right2:.4f}")     # 4.1589
print(f"相等? {np.allclose(left2, right2)}")

指数和对数互相「抵消」

因为是逆运算，指数和对数互相抵消——就像加法和减法、乘法和除法：

$$\ln(e^x) = x, \qquad e^{\ln x} = x \quad (x > 0)$$

用代码快速验证：

# 00-10 第三步：指数和对数互为逆运算——互相抵消
import numpy as np

x = 2.5
# ln(e^x) = x — 先exp再log，回到原点
print(f"ln(e^2.5) = {np.log(np.exp(x)):.6f}")  # 2.5 ✓
# e^(ln x) = x — 先log再exp，回到原点（x必须>0）
print(f"e^(ln 2.5) = {np.exp(np.log(x)):.6f}")  # 2.5 ✓

# 对数组批量操作：
vals = np.array([0.5, 1, 2, 10, 100])
# 全部应该回到原始值（浮点误差可忽略）
print(f"e^(ln vals) = {np.exp(np.log(vals))}")

为什么 $\ln$ 这么重要？

上面学的两个性质——乘法变加法和指数拉下来——让 $\ln$ 成为数学中不可或缺的工具。

  1. 把乘变成加： 大量数字连乘 → 取对数 → 变成简单的连加。不仅手算方便，更重要的是数值稳定——$0.1 \times 0.1 \times 0.1 = 0.001$，再乘几次就小到计算机的浮点数扛不住了（下溢）。取对数后变成 $\ln 0.1 + \ln 0.1 + \ln 0.1 \approx -2.30 - 2.30 - 2.30 = -6.91$——都是好算的普通数字。
  2. 把指数拉下来： $\ln(e^x) = x$——$e^x$ 和 $\ln$ 是逆运算，嵌套时互相抵消，干干净净。$\ln(a^n) = n\ln a$——指数 $n$ 降级为乘法系数，把指数级复杂度降为乘法级。

这两个性质会在后续课程中反复登场——到时候你不需要重新学 $\ln$，只需要调用这两条规则。
