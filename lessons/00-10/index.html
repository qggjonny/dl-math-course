00-10 梯度下降

一、复习：梯度下降核心公式

梯度下降 = 闭着眼睛，每一步都往最陡的下坡方向踩一脚。 $$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$
  • $\theta_t$：你现在站的位置
  • $\nabla f(\theta_t)$：这个位置的最陡上坡方向
  • 负号：因为我们想下降，所以反着走
  • $\eta$（学习率）：走多大步。太大→可能跨过山谷冲到对面山上去了；太小→半天走不到底

二、学习率多大算太大？——发散条件推导

推导：从「会跨过山谷」到具体数值条件

不是说「学习率大了就会跨过山谷」——要多大才会跨过去？用二次函数来算。

拿一个具体例子：$f(x) = x^2 - 4x + 4$，导数 $f'(x) = 2x - 4$（斜率是一条直线），最小值在 $x=2$（因为 $f'(2)=0$）。

梯度下降更新：

$$x_{t+1} = x_t - \eta \cdot (2x_t - 4) = (1 - 2\eta) x_t + 4\eta$$

关心的是离谷底还有多远：定义误差 $e_t = x_t - 2$（当前离最小值 2 的距离）。

$$e_{t+1} = x_{t+1} - 2 = (1-2\eta)x_t + 4\eta - 2 = (1-2\eta)(x_t - 2) = (1-2\eta) \cdot e_t$$

所以每一步误差乘以 $(1-2\eta)$：

  • $|1-2\eta| < 1$ → 误差越来越小 → 收敛。解出来：$-1 < 1-2\eta < 1$ → $0 < \eta < 1$
  • $|1-2\eta| = 1$ → 误差不变 → 来回跳但不缩小（$\eta=1$ 时原地振荡）
  • $|1-2\eta| > 1$ → 误差越来越大 → 发散！

验证：$\eta = 1.5$，$1-2\eta = 1-3 = -2$，$|{-2}| = 2 > 1$ → 发散。

$x_0 = 1$，误差 $e_0 = 1-2 = -1$（谷底在右边）。$e_1 = (-2) \times (-1) = 2$，$|e_1| = 2 > |e_0| = 1$。直接验证：$x_1 = 1 - 1.5 \times (-2) = 1 + 3 = 4$，确实从谷底左边直接跳到右边更远的地方——典型的发散。

一般结论：对于二次函数 $f(x) = ax^2 + bx + c$（其中 $a>0$，开口朝上），收敛条件是 $0 < \eta < 1/a$。$f''(x) = 2a$ 越大（函数越弯），允许的学习率越小。

💭 概念题

  1. 学习率太大的后果：画面上你站在山谷一边，步子太大跨到对面山上去了，再一步又跨回来，来回振荡——永远到不了谷底。试算一下 lr=1.5 在 x=1 处会发生什么。梯度是 $f'(1)=2\times1-4=-2$，更新后 x 变成多少？——考察：梯度下降的发散条件
