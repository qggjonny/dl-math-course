00-05 链式法则

反向传播的核心引擎

链式法则就是复合函数求导的规则。深度学习 100 层的网络，梯度怎么从最后一层传到第一层？答案就是链式法则一层一层乘回去。

一、单变量链式法则

$$h(x) = f(g(x)) \quad\Rightarrow\quad h'(x) = f'(g(x)) \cdot g'(x)$$

"外函数的导数 × 内函数的导数"。像剥洋葱：外层求导（内层先不动），乘以内层求导。

二、多变量链式法则

$$z = f(y_1, y_2, \ldots), \quad y_i = g_i(x)$$

$$\frac{dz}{dx} = \sum_i \frac{\partial z}{\partial y_i} \cdot \frac{dy_i}{dx}$$

所有路径的导数之和。 x 通过 $y_1, y_2, \ldots$ 多条路径影响 z，每条路径贡献一个乘积，全部加起来。

反向传播的本质： 前向算输出 → 算损失 → 从最后一层开始，用链式法则把梯度一层层往回传。每一层只需要知道"自己这层的局部导数"和"从后面传来的梯度"，乘起来传下去。

🖥️ 代码

import numpy as np

# 手算链式法则：h(x) = sin(x²)
# 外层 f(u)=sin(u), f'(u)=cos(u)
# 内层 g(x)=x²,    g'(x)=2x
# h'(x) = cos(x²) * 2x

def h(x):
    return np.sin(x ** 2)

def h_grad_analytic(x):
    return np.cos(x ** 2) * 2 * x

# 中央差分数值验证
def numerical_grad(f, x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

x = 1.5
num = numerical_grad(h, x)
ana = h_grad_analytic(x)
print(f"h'(1.5) 数值={num:.5f} 解析={ana:.5f}")

# 模拟反向传播：损失 L = (wx - y)²
# dL/dw = 2(wx - y) * x
w, x, y = 0.5, 2.0, 1.0
pred = w * x                       # 前向
loss = (pred - y) ** 2            # 损失
dloss_dpred = 2 * (pred - y)        # ∂L/∂pred（外层求导）
dpred_dw = x                       # ∂pred/∂w（内层求导）
dloss_dw = dloss_dpred * dpred_dw  # 链式法则！
print(f"\n损失 L={loss:.3f}, dL/dw={dloss_dw:.3f}")
