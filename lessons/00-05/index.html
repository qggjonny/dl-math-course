00-05 链式法则

如果说梯度是"往哪走"，那链式法则就是"在多层的机器里，最里面那颗螺丝钉拧一下，最终输出会变多少"。这条规则单独看简单，但它是后面所有复杂求导的基础。

一、咬合的齿轮：链式法则的直觉

画面： 你面前有三个咬合在一起的齿轮。你转动第一个齿轮（输入 $x$），它带动第二个齿轮（中间结果 $g(x)$），第二个带动第三个（最终输出 $f(g(x))$）。

现在问：你拧第一个齿轮 1 圈，最后一个齿轮转几圈？

答案 = 第一个齿轮到第二个齿轮的传动比 × 第二个齿轮到第三个齿轮的传动比。

这就是链式法则：

$$h(x) = f(g(x)) \quad\Rightarrow\quad h'(x) = f'(g(x)) \cdot g'(x)$$
  • $g'(x)$：拧输入 $x$，中间结果 $g(x)$ 怎么变（第一个传动比）
  • $f'(g(x))$：中间结果 $g(x)$ 变一点，最终输出怎么变（第二个传动比）
  • 乘起来：输入→输出的总传动比

来一个具体例子：$h(x) = \sin(x^2)$

  • 内层齿轮 $g(x) = x^2$，传动比 $g'(x) = 2x$
  • 外层齿轮 $f(u) = \sin(u)$，传动比 $f'(u) = \cos(u)$
  • 注意：外层传动比要在 $u=x^2$ 那个位置算，不是在 $x$ 处算
  • 总传动比：$h'(x) = \cos(x^2) \cdot 2x$

二、多列齿轮：多条路径求和

如果一个输入变量通过多条路径影响最终输出——就像一台机器同时驱动两条传送带——那总传动比 = 各条路径的传动比之和：

$$\frac{dz}{dx} = \frac{\partial z}{\partial y_1} \cdot \frac{dy_1}{dx} + \frac{\partial z}{\partial y_2} \cdot \frac{dy_2}{dx} + \cdots$$

画面： 发动机驱动两条传送带，两条传送带都汇到一个包装箱。发动机加速 → 两条传送带都加速 → 包装箱加速。总效应 = 两条路径的效应相加。

多级齿轮的启示： 100 级齿轮咬合在一起。如果每级传动比都 < 1（比如 0.25），100 次连乘后 → 0.25¹⁰⁰ ≈ 0——第一个齿轮拧 10000 圈，最后一个纹丝不动。如果每级都 > 1，最后一个会疯狂加速。链式法则的乘法性质意味着：连乘 100 次的结果对每一级的传动比极度敏感——这就是为什么深层复合函数的导数要么趋近 0，要么爆炸。

三、手算一个例子：$(wx-y)^2$ 的导数

$L = (wx - y)^2$。假设 $y$ 是常数（一个目标值），我们想知道 $w$ 变一点，$L$ 变多少。

  • 内层：$u(w) = wx - y$，$\frac{du}{dw} = x$
  • 外层：$L(u) = u^2$，$\frac{dL}{du} = 2u$
  • 链式：$\frac{dL}{dw} = 2(wx-y) \cdot x$
import numpy as np

# ===== sin(x²) 验证链式法则 =====
def h(x):
    return np.sin(x ** 2)       # 复合函数

def h_grad(x):
    return np.cos(x ** 2) * 2 * x  # 链式：cos(x²)·2x

# 数值验证（中央差分）
def num_grad(f, x, eps=1e-5):
    return (f(x+eps) - f(x-eps)) / (2*eps)

x = 1.5
print(f"h'(1.5) 数值={num_grad(h,x):.6f}  解析={h_grad(x):.6f}")
# 两个值应该几乎相同

# ===== 线性回归：一步梯度下降 =====
w, x_val, y = 0.5, 2.0, 1.0

# 前向：输入 → 预测 → 差值
pred = w * x_val               # 预测 = 0.5×2.0 = 1.0
L = (pred - y) ** 2           # 差值的平方 = (1.0-1.0)² = 0.0

# 从外层往内层，用链式法则求 ∂L/∂w
dloss_dpred = 2 * (pred - y)  # 外层：∂L/∂pred
dpred_dw = x_val               # 内层：∂pred/∂w = x
dloss_dw = dloss_dpred * dpred_dw  # 链式！∂L/∂w

print(f"\nL={L:.3f}  ∂L/∂w={dloss_dw:.3f}")

💭 概念题

  1. 用齿轮比喻解释：如果每一级齿轮的传动比都是 0.25（减速），100 级串联后，拧第一个齿轮 10000 圈，最后一个转几圈？——考察：连乘的指数衰减效应
  2. 为什么求 $h(x)=f(g(x))$ 的导数时必须先算出 $g(x)$ 的值？用齿轮比喻：你必须知道第二个齿轮现在卡在哪个齿上，才能算这一级的传动比。——考察：复合函数求导的计算顺序
  3. $h(x) = (2x+1)^3$，用链式法则手算 $h'(x)$。先分别写出外导和内导，再乘起来。——考察：链式法则的手算练习
