00-05 链式法则

如果你只记住深度学习里一样东西，就记这个：反向传播 = 链式法则从最后一层往前一层一层地乘。

一、剥洋葱：外导 × 内导

$$h(x) = f(g(x)) \quad\Rightarrow\quad h'(x) = f'(g(x)) \cdot g'(x)$$

画面： $g$ 是洋葱内层，$f$ 是洋葱外层。求 $h$ 的变化率 = 先对外层求导（内层暂时不动），再乘以内层求导。

来一个具体例子。$h(x) = \sin(x^2)$：

  • 外层 $f(u) = \sin(u)$，它的导数 $f'(u) = \cos(u)$
  • 内层 $g(x) = x^2$，它的导数 $g'(x) = 2x$
  • 链式法则：$h'(x) = \cos(x^2) \cdot 2x$

不要跳过这一步想明白： $f'(g(x))$ 里的 $g(x)$ 就是 $x^2$——外层导数要在 $g(x)$ 处算，不是直接在 $x$ 处算。

二、多变量链式法则：所有路径求和

如果一个变量 $x$ 通过多条路径影响最终结果 $z$：

$$\frac{dz}{dx} = \frac{\partial z}{\partial y_1} \cdot \frac{dy_1}{dx} + \frac{\partial z}{\partial y_2} \cdot \frac{dy_2}{dx} + \cdots$$

每一条路径贡献一个乘积，全部加起来。

这就是反向传播干的事。 100 层网络 → 损失对第一层权重的梯度 = 100 个偏导数连乘。如果每个都 < 1，积趋近 0 → 梯度消失。如果每个都 > 1，积爆炸 → 梯度爆炸。这就是深层网络难训练的根本原因。

三、反向传播最小例子：线性回归

$$L = (wx - y)^2$$

我们要 $\frac{dL}{dw}$。跟剥洋葱一样：

  • 外层 $L(u) = u^2$，$\frac{dL}{du} = 2u$
  • 内层 $u(w) = wx - y$，$\frac{du}{dw} = x$
  • 链式法则：$\frac{dL}{dw} = 2(wx-y) \cdot x$
import numpy as np

# ===== 数值验证 sin(x²) 的导数 =====
def h(x):
    return np.sin(x ** 2)  # 复合函数

def h_grad_analytic(x):
    return np.cos(x ** 2) * 2 * x  # 链式法则：cos(x²)·2x

def num_grad(f, x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

x = 1.5
print(f"h'(1.5) 数值={num_grad(h, x):.6f}  解析={h_grad_analytic(x):.6f}")

# ===== 反向传播：L = (wx - y)² =====
w, x_val, y = 0.5, 2.0, 1.0  # 参数和样本

# 前向传播
pred = w * x_val                  # 预测 = 0.5 × 2.0 = 1.0
loss = (pred - y) ** 2           # 损失 = (1.0 - 1.0)² = 0.0

# 反向传播：从损失往回求梯度
# 第 1 步：∂L/∂pred = 2×(pred - y)（外层）
dloss_dpred = 2 * (pred - y)
# 第 2 步：∂pred/∂w = x（内层）
dpred_dw = x_val
# 第 3 步：链式法则！∂L/∂w = ∂L/∂pred × ∂pred/∂w
dloss_dw = dloss_dpred * dpred_dw

print(f"\nL={loss:.3f}  dL/dw={dloss_dw:.3f}")

# ===== 梯度下降一步 =====
lr = 0.1
w_new = w - lr * dloss_dw  # 沿反方向走
print(f"w: {w} → {w_new:.3f}")
