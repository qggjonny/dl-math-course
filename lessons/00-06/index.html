00-06 概率基础①：离散分布

一、随机变量

取值不确定但知道分布规律的变量。抛硬币的结果 X：正面=1，反面=0。X 的取值是确定的 {0,1}，但哪次抛到什么是随机的。

二、PMF：概率质量函数

离散分布用 PMF 描述。每个可能的取值对应一个概率质量，所有质量之和 = 1。

$$P(X = x_i) = p_i, \quad \sum_i p_i = 1$$

三、伯努利分布

一次抛硬币。参数 $p$ = 正面概率。

$$P(X=1) = p, \quad P(X=0) = 1-p$$

深度学习里：Dropout 中每个神经元是否被丢弃 = 伯努利(p=dropout_rate)。

四、二项分布

抛 n 次硬币，恰好 k 次正面的概率。

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$

Batch 中 k 个样本分对的概率 = 二项(n=batch_size, p=accuracy)。

五、多项分布

不止两个结果。掷骰子有 6 种。softmax 输出的概率分布就是多项分布的一个样本。

🖥️ 代码

import numpy as np

# 伯努利：抛 1000 次 p=0.7 的硬币
np.random.seed(42)
p = 0.7
# np.random.random(n) 生成 n 个 [0,1) 随机数
# < p 的概率恰好是 p → True 表示正面
bernoulli = np.random.random(1000) < p
print(f"伯努利 p=0.7: 正面比例={bernoulli.mean():.3f}")
# .mean() 对布尔数组：True=1, False=0，均值=正面比例

# 二项：抛 10 次硬币，重复 10000 轮
n, p = 10, 0.5
# np.random.binomial(n, p, size) 抽 size 个二项样本
# 每个样本 = 抛 n 次硬币的正面次数
binomial = np.random.binomial(n, p, size=10000)
for k in [3, 5, 7]:
    freq = np.mean(binomial == k)  # 恰好 k 次正面的频率
    print(f"P(X={k}) ≈ {freq:.4f}")

# 多项：掷骰子 1000 次
# np.random.multinomial(n, probs) 掷 n 次，每面出现次数
dice = np.random.multinomial(1000, [1/6]*6)
print(f"\n掷骰 1000 次: {dice}")
print(f"总和={dice.sum()}")  # 一定 = 1000
