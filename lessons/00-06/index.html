00-06 线性方程组

线性方程组：两条线相交的地方

画面： 操场上有两条跑道，它们交叉在一起。在它们交叉的那个点上，跑道 A 和跑道 B 同时经过——这个点就是「方程组的解」。

线性方程组就是好几个直线方程放一起，问：「有没有一个点，同时落在所有这些直线上？」

从具体例子开始

两条直线：

$$\begin{cases} 2x + 3y = 8 \\ x - y = 1 \end{cases}$$

第一条说： $2x+3y=8$——满足这个条件的点 $(x,y)$ 全都在第一条直线上。
第二条说： $x-y=1$——满足这个条件的点全都在第二条直线上。
两个条件同时成立： 这个点必须在两条线的交叉处。

怎么解？——代入法

从第二条 $x - y = 1$ 推出 $x = 1 + y$。把这个代入第一条：

$$2(1+y) + 3y = 8$$ $$2 + 2y + 3y = 8$$ $$5y = 6$$ $$y = 1.2$$

$y$ 代回去：$x = 1 + 1.2 = 2.2$。

解： $(x,y) = (2.2, 1.2)$。验证：$2\times2.2 + 3\times1.2 = 4.4+3.6=8$ ✓，$2.2-1.2=1$ ✓。

三个未知数、三个方程

扩展到三维空间——三个平面相交于一个点：

$$\begin{cases} x + y + z = 6 \\ x - y + z = 2 \\ x + y - z = 0 \end{cases}$$

从第二式：$x - y + z = 2$，从第一式减第二式：$(x+y+z) - (x-y+z) = 6-2$，得 $2y=4$，所以 $y=2$。

从第三式：$x + 2 - z = 0$，得 $x - z = -2$，即 $z = x+2$。

代回第一式：$x + 2 + (x+2) = 6$，$2x+4=6$，$x=1$。所以 $z=3$。

解： $(x,y,z) = (1, 2, 3)$。

矩阵形式：$A\mathbf{x} = \mathbf{b}$

把方程组写成矩阵的样子。上面那个二元方程组：

$$A = \begin{bmatrix} 2 & 3 \\ 1 & -1 \end{bmatrix}, \qquad \mathbf{x} = \begin{bmatrix} x \\ y \end{bmatrix}, \qquad \mathbf{b} = \begin{bmatrix} 8 \\ 1 \end{bmatrix}$$ $$A\mathbf{x} = \begin{bmatrix} 2 & 3 \\ 1 & -1 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 2x+3y \\ x-y \end{bmatrix} = \begin{bmatrix} 8 \\ 1 \end{bmatrix} = \mathbf{b}$$

矩阵形式把所有方程压缩成一行：$A\mathbf{x} = \mathbf{b}$。$A$ 是系数矩阵，$\mathbf{x}$ 是未知数（列向量），$\mathbf{b}$ 是右边的常数。

这个形式极其简洁——而且恰恰是 00-02 学的「矩阵×向量」。

什么时候有解？

两条直线在平面上，一般有三种情况：

情况几何行列式
唯一解两条线不平行，交于一点$\det(A) \neq 0$
无解两条线平行但不重合$\det(A) = 0$，但方程矛盾
无穷多解两条线完全重合$\det(A) = 0$，且方程不矛盾

回忆 00-04：行列式为 0 意味着矩阵把空间压扁了。压扁之后就回不去了（不可逆）——所以不能用「乘逆矩阵」的办法求解。只有 $\det(A) \neq 0$（矩阵没有压扁空间）时，$A\mathbf{x} = \mathbf{b}$ 才有唯一解。

矩阵角度：列空间

$A\mathbf{x} = \mathbf{b}$ 换个读法。把 $A$ 按列拆开：

$$A\mathbf{x} = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = x\begin{bmatrix} a_{11} \\ a_{21} \end{bmatrix} + y\begin{bmatrix} a_{12} \\ a_{22} \end{bmatrix}$$

$A\mathbf{x}$ 就是 $A$ 的两列按 $x$ 和 $y$ 的比例混合。 $x$ 和 $y$ 是配方——你取 $x$ 份第一列 + $y$ 份第二列，搅在一起，得到 $\mathbf{b}$。

那么所有可能的 $\mathbf{b}$（把 $x$ 和 $y$ 取遍所有实数）构成的集合，就叫 $A$ 的列空间——$A$ 的列「能到达的所有地方」。

$$A = \begin{bmatrix} 2 & 3 \\ 1 & -1 \end{bmatrix} 的列空间：两列 \begin{bmatrix}2\\1\end{bmatrix} 和 \begin{bmatrix}3\\-1\end{bmatrix} 不共线 → 能张成整个平面 → \mathbf{b} 无论在哪，都能配出来。$$ $$A = \begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix} 的列空间：两列都是 \begin{bmatrix}1\\1\end{bmatrix}，共线 → 只能张成 y=x 这条直线 → \mathbf{b}=[3,5] 不在线上 → 无解。$$

一句话： $\det(A) \neq 0$ → 列空间 = 整个平面 → 永远有唯一解。$\det(A) = 0$ → 列空间被压成一条线 → $\mathbf{b}$ 必须恰好落在这条线上才有解，否则无解。

和特征向量的关系

第五课我们解 $(A-\lambda I)\mathbf{v} = \mathbf{0}$ 来求特征向量。注意这个方程右边是 $\mathbf{0}$（零向量），不是一般的 $\mathbf{b}$。

当 $\mathbf{b} = \mathbf{0}$ 时，方程 $A\mathbf{x} = \mathbf{0}$ 永远有一个「废话解」$\mathbf{x} = \mathbf{0}$。但我们要的是非零解——只有在 $\det(A) = 0$ 时才存在。

⚠️ 注意符号：上面 $A\mathbf{x}=\mathbf{0}$ 里的 $A$，和 $(A-\lambda I)\mathbf{v}=\mathbf{0}$ 里的 $A$，是同一个原始矩阵。区别在于问题：

  • $A\mathbf{x}=\mathbf{0}$ 问的是「$A$ 本身是不是压扁了空间？」（看 $\det(A)$ 是否为零）
  • $(A-\lambda I)\mathbf{v}=\mathbf{0}$ 问的是「$\lambda$ 取什么值时，$A-\lambda I$ 会压扁空间？」

这就是为什么特征方程必须是 $\det(A-\lambda I) = 0$：我们把 $\lambda$ 当作未知数，找那些让 $A-\lambda I$ 行列式为零的 $\lambda$。一旦找到这样的 $\lambda$，$A-\lambda I$ 就压扁了空间，对应的「压扁方向」就是特征向量 $\mathbf{v}$。

# 00-06：用 numpy 解线性方程组 A x = b
# 导入numpy，别名np
import numpy as np

# 系数矩阵 A = [[2,3],[1,-1]]
A = np.array([[2, 3],
# 第一行系数：2x+3y=8
              [1, -1]])
# 第二行系数：x−y=1

# 右边常数向量 b = [8, 1]
b = np.array([8, 1])

# np.linalg.solve(A, b)：解 A x = b，返回解向量 x
# 前提：det(A) ≠ 0（矩阵可逆），否则报错 LinAlgError
x = np.linalg.solve(A, b)
# 输出：x = [2.2, 1.2]
print(f"x = {x}")

# 验证：A @ x 应该等于 b
print(f"A@x = {A @ x}")
print(f"等于 b? {np.allclose(A @ x, b)}")

# 三维例子：三个未知数
A3 = np.array([[1, 1, 1],
# 第一行：x+y+z=6
               [1, -1, 1],
# 第二行：x−y+z=2
               [1, 1, -1]])
# 第三行：x+y−z=0
b3 = np.array([6, 2, 0])
x3 = np.linalg.solve(A3, b3)
# 输出：x3 = [1, 2, 3]
print(f"x3 = {x3}")
