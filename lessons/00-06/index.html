00-06 离散分布

一、随机变量：知道规律但不知道结果

画面： 你在微信上给朋友发了一条消息。根据经验，70% 的概率他秒回，20% 的概率半小时后回，10% 的概率忘了回。你不知道这次会怎样，但你知道每种可能性的比例。这就是随机变量：一个取值不确定但分布规律确定的量。

数学里写：$X = \text{"回复所需时间"}$。$X$ 可以取「秒回」「半小时」「不回」三个值。

二、PMF：三个盒子，按比例抽

画面： 桌上有三个盒子，标着「秒回」「半小时」「不回」。你有 10 个筹码要往里放——秒回盒放 7 个，半小时盒放 2 个，不回盒放 1 个。总共 10 个筹码。

现在从这三个盒子里按筹码比例随机抽一个——抽到秒回的概率 = 7/10 = 70%，半小时 = 20%，不回 = 10%。

PMF（概率质量函数）就是给每个可能的取值分配一个"筹码重量"。所有筹码加起来 = 1。

$$P(X = x_i) = p_i, \quad \sum_i p_i = 1$$

三、伯努利分布：抛一次硬币

只有两种结果：成功（1）和失败（0）。

$$P(X=1) = p, \quad P(X=0) = 1-p$$

画面： 一枚偏心的硬币，正面概率 $p=0.7$。抛一次，不是正面就是反面——就这么简单。

import numpy as np

np.random.seed(42)           # 固定随机种子，保证每次运行结果一样
p = 0.7
# np.random.random(1000) 生成 1000 个 [0, 1) 的随机小数
# < p: 小于 0.7 的变成 True（正面），其余 False（反面）
flips = np.random.random(1000) < p
# .mean() 对布尔数组：True=1, False=0, 平均值=正面的比例
print(f"p=0.7, 抛1000次: 正面比例 {flips.mean():.3f}")

四、二项分布：抛 n 次硬币

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$

逐件拆开：

  • $\binom{n}{k} = \frac{n!}{k!(n-k)!}$：n 次里选 k 次正面，有多少种排列方式。比如抛 3 次恰好 2 次正面：可以是「正正反」「正反正」「反正正」三种排法
  • $p^k$：k 次正面同时发生的概率（每次独立，概率相乘）
  • $(1-p)^{n-k}$：剩下 n-k 次全部反面的概率

形状：中间鼓，两头瘪。 抛 10 次公平硬币，恰好 5 次正面的概率最大——因为 $\binom{10}{5}=252$ 种排法，远比两端的 $\binom{10}{1}=10$ 种排法多。

n, p = 10, 0.5
# np.random.binomial(n, p, size) 模拟抛 size 轮，每轮抛 n 次
results = np.random.binomial(n, p, size=10000)
for k in [3, 5, 7]:
    freq = np.mean(results == k)   # == True/False, mean=比例
    print(f"P(X={k}) ≈ {freq:.4f}")
# P(X=5) 最大，P(X=3) 和 P(X=7) 对称

五、多项分布：不止两个盒子

掷六面骰子，每面概率都是 1/6——六个盒子，每个放一样多的筹码。

# np.random.multinomial(总次数, 各面概率)
# 掷 1000 次骰子
dice = np.random.multinomial(1000, [1/6]*6)
print(f"掷骰1000次: {dice}")       # 六个面的出现次数
print(f"总和={dice.sum()}")        # 一定 = 1000

💭 概念题

  1. 抛 10 次公平硬币。为什么 P(X=5) 最大，P(X=0) 最小？从组合数 C(10,k) 的形状解释——哪种 k 值对应的排列方式最多？——考察：二项分布中间鼓的本质（本课拆过组合数的含义）
  2. PMF 要求所有概率之和 = 1。$[0.1, 0.1, 0.7, 0.1]$ 满足这个条件吗？它代表什么意思？——考察：PMF 定义验证（本课讲过"所有筹码加起来 = 1"）
  3. 抛一枚 p=0.9 的偏心硬币 10 次。P(X=9) 和 P(X=1) 哪个更大？不用算，用直觉判断。——考察：二项分布的偏斜（p 偏离 0.5 时钟形不对称）
