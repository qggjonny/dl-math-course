00-06 离散分布

一、随机变量——不确定但知道规律

你用微信给朋友发消息。你知道大概 70% 的概率他会秒回、20% 的概率半小时后回、10% 的概率忘了回。你不知道这次会怎样，但知道每种结果的可能性。这就是随机变量。

在数学里写：$X = \text{"回复所需时间"}$。$X$ 可以取三个值：秒回、半小时、不回。

二、PMF：概率质量函数——每个结果的"筹码"

离散分布用 PMF 描述。每个可能的取值分配一个概率质量，所有筹码加起来恰好等于 1。

$$P(X = x_i) = p_i, \quad \sum_i p_i = 1$$

画面： 桌上有三个盒子，分别标着「猫」「狗」「鸟」。你往里面放筹码——猫盒子放 0.5 个筹码，狗放 0.3，鸟放 0.2。所有筹码加起来 = 1。抽一次 = 按筹码比例随机抽一个盒子。

三、伯努利分布——抛一次硬币

只有两种结果：成功（1）和失败（0）。

$$P(X=1) = p, \quad P(X=0) = 1-p$$

深度学习里：Dropout 层，每个神经元被丢弃的概率 = $p$ → 伯努利。

import numpy as np

np.random.seed(42)
p = 0.7
# np.random.random(1000) 生成 1000 个 [0,1) 的随机数
# < p 返回布尔数组：小于 0.7 → True(正面), >= 0.7 → False(反面)
flips = np.random.random(1000) < p
# .mean() 对布尔：True=1, False=0 → 均值 = 正面比例
print(f"p=0.7, 1000次: 正面比例={flips.mean():.3f}")
# 结果 ~0.7（大数定律）

四、二项分布——抛 n 次硬币，恰好 k 次正面

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$

拆开看：

  • $\binom{n}{k} = \frac{n!}{k!(n-k)!}$：n 次里选 k 次正面，有多少种排法
  • $p^k$：k 次正面的概率
  • $(1-p)^{n-k}$：剩下 n-k 次反面的概率
n, p = 10, 0.5
# np.random.binomial(n, p, size) 抽 size 个样本
# 每个样本 = 抛 n 次硬币的正面数
results = np.random.binomial(n, p, size=10000)
for k in [3, 5, 7]:
    freq = np.mean(results == k)  # == 返回布尔，mean = 比例
    print(f"P(X={k}) ≈ {freq:.4f}")
# P(X=5) 最大，两端小 → 二项分布是"中间鼓"的

五、多项分布——不止两个结果

掷骰子有 6 面。softmax 的输出 $[0.02, 0.05, 0.91, 0.02]$ 就是多项分布的一个概率向量。

# np.random.multinomial(总次数, 概率向量)
# 掷 1000 次六面骰子，每面概率 1/6
dice = np.random.multinomial(1000, [1/6]*6)
print(f"掷骰 1000 次: {dice}")
print(f"总和={dice.sum()}")  # 一定 = 1000
