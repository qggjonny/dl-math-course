SVD（上）：任意矩阵的"特征值"

一、特征值为什么不够用

前面 00-05 学了特征值分解：对方阵 $A$，存在向量 $\mathbf{v}$ 使得：

$$A\mathbf{v} = \lambda \mathbf{v}$$

$A$ 作用在 $\mathbf{v}$ 上，方向不变，只拉伸 $\lambda$ 倍。这很直观——但有一个致命限制：$A$ 必须是方阵。

现实中大多数矩阵是长方形的：1000 个样本 × 50 个特征 → $1000 \times 50$，神经网络权重 $256 \times 784$……这些都不是方阵，没法直接做特征值分解。

SVD（奇异值分解）就是特征值分解的推广——对任意形状的矩阵都有效。

二、思路：批量做你已经会的事

你会的操作：矩阵 × 一个向量 = 一个新向量。比如：

$$A = \begin{bmatrix} 3 & 1 \\ 1 & 3 \end{bmatrix}, \quad A\begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 3 \\ 1 \end{bmatrix}$$

现在换个思路：不只看一个向量，一次看很多个。

取 8 个均匀分布的方向（每 45° 一个），每个方向上取一个长度为 1 的向量。用 $A$ 分别去乘它们——看看每个向量被拉伸了多少、转到了哪个方向。

# 00-06 第一步：对8个方向上的单位向量，用A去乘，观察谁被拉得最长
import numpy as np

A = np.array([[3, 1],            # 待研究的矩阵 2×2
              [1, 3]])

angles = np.linspace(0, 2*np.pi, 9)[:-1]  # 8个角度: 0°,45°,90°...315°
                                                # [:-1] 去掉最后一个(360°=0°重复)

print("输入向量 → 输出向量 → 输出长度（拉伸倍数）")
print("-" * 50)
for angle in angles:
    v = np.array([np.cos(angle), np.sin(angle)])  # 单位向量，长度=1
    w = A @ v                                      # A 作用在 v 上，得到输出向量 w
    stretch = np.linalg.norm(w)                    # w 的长度 = 这个方向上的拉伸倍数
    
    print(f"v=[{v[0]:+.2f},{v[1]:+.2f}] → "
          f"w=[{w[0]:+.2f},{w[1]:+.2f}] 拉伸={stretch:.2f}倍")

# 谁被拉得最长？谁最短？
stretches = [np.linalg.norm(A @ np.array([np.cos(a), np.sin(a)]))
             for a in angles]
max_idx = np.argmax(stretches)
min_idx = np.argmin(stretches)
print(f"\n最大拉伸: {stretches[max_idx]:.2f}倍（角度 {np.degrees(angles[max_idx]):.0f}°）")
print(f"最小拉伸: {stretches[min_idx]:.2f}倍（角度 {np.degrees(angles[min_idx]):.0f}°）")

🔗 在线运行

跑完你会发现：45° 方向（向量 [0.707, 0.707]）被拉了 4 倍——是所有方向里拉伸最多的。135° 方向只拉 2 倍——最少。

这两个特殊方向，就是 SVD 要抓的东西：

  • 拉伸最多的方向 → 最大奇异值（$\sigma_1 = 4$）
  • 拉伸最少的方向 → 次大奇异值（$\sigma_2 = 2$）

三、从 8 个方向扩展到无数个方向——椭圆

上面只看了 8 个方向。如果把所有可能的方向都考虑进来——每个方向上放一个长度为 1 的向量——这些向量的终点连起来就是一个单位圆。

用矩阵 $A$ 去乘圆上的每一个点，得到的点连起来就是一个椭圆。

"矩阵变换一个圆"到底是什么意思？

不是矩阵「吃掉了」一个圆。而是：
① 圆的本质 = 无数个长度为 1、方向各异的向量（的终点）
② 对每个向量，做 $A\mathbf{v}$（你已经会的操作）
③ 所有输出向量的终点围成椭圆

所以「圆变椭圆」=「对大量向量逐个做矩阵乘法，观察结果的形状」。和 $A\mathbf{x}$ 没有本质区别，只是做了很多次。 
# 00-06 第二步：用100个方向，密集采样，验证输出围成椭圆
import numpy as np

A = np.array([[3, 1],
              [1, 3]])

# 在单位圆上取 100 个点（每个点 = 一个长度为1的向量）
angles = np.linspace(0, 2*np.pi, 100)
circle_x = np.cos(angles)                   # 100 个点的 x 坐标
circle_y = np.sin(angles)                   # 100 个点的 y 坐标
circle = np.vstack([circle_x, circle_y])    # 形状 (2, 100) — 每一列是一个点

# 用 A 同时乘所有 100 个向量 → (2,2) × (2,100) = (2,100)
ellipse = A @ circle                        # 100 个输出向量，围成椭圆

# 输出点的范围——用来判断椭圆的长轴和短轴
x_vals = ellipse[0, :]                      # 所有输出点的 x 坐标
y_vals = ellipse[1, :]                      # 所有输出点的 y 坐标

print(f"输出 x 范围: [{x_vals.min():.1f}, {x_vals.max():.1f}]")
print(f"输出 y 范围: [{y_vals.min():.1f}, {y_vals.max():.1f}]")

# 找到离原点最远的输出点——这就是最大奇异值对应的方向
distances = np.linalg.norm(ellipse, axis=0)   # 每个输出向量的长度
max_idx = np.argmax(distances)              # 最长的那根
min_idx = np.argmin(distances)              # 最短的那根

print(f"\n椭圆长轴（最大拉伸）: 长度={distances[max_idx]:.1f}，方向=[{ellipse[0,max_idx]:.1f},{ellipse[1,max_idx]:.1f}]")
print(f"椭圆短轴（最小拉伸）: 长度={distances[min_idx]:.1f}，方向=[{ellipse[0,min_idx]:.1f},{ellipse[1,min_idx]:.1f}]")

🔗 在线运行

结论：长轴指向 [2.83, 2.83] 方向，长度 ≈ 4；短轴指向 [-1.41, 1.41] 方向，长度 ≈ 2。

这两个方向互相垂直（点乘 = 2.83×(-1.41) + 2.83×1.41 = 0 ✓），它们是矩阵 $A$ 的左奇异向量。

四、SVD 公式登场——现在它不神秘了

有了上面的直觉，SVD 就是三件事的合并：

$$A = U \Sigma V^T$$
矩阵做什么对应刚才看到的什么
$U$ 椭圆两个轴的方向（单位化） 长轴方向 [0.707, 0.707] 和短轴方向 [-0.707, 0.707]
$\Sigma$ 两个轴的长度 对角线上的 4 和 2——就是那两个拉伸倍数
$V^T$ 「这两个方向在被拉伸之前指向哪里」 长轴在被拉之前是 45°，短轴在被拉之前是 135°

一句话： $V^T$ 把坐标轴转到位 → $\Sigma$ 沿这两个方向分别拉伸 → $U$ 把拉伸后的轴转到最终方位。三步走。

用代码验证：

# 00-06 第三步：用 numpy 的 SVD 函数，把 A 拆成三步
import numpy as np

A = np.array([[3, 1],
              [1, 3]])

U, s, VT = np.linalg.svd(A)                # U, 奇异值(1D数组), V^T

print("U (椭圆轴方向) =\n", U)
print(f"\nΣ 对角线: σ₁={s[0]}, σ₂={s[1]}")
print("\nV^T (轴被拉伸之前的方位) =\n", VT)

# 验证：三步合成应等于原矩阵
Sigma = np.diag(s)                         # 1D数组 → 对角矩阵
A_rebuilt = U @ Sigma @ VT                 # U Σ V^T
print(f"\nU Σ V^T =\n{A_rebuilt}")
print(f"等于 A？ {np.allclose(A, A_rebuilt)}")

五、长方形矩阵呢？一样能用

上面的 $A$ 是 $2\times 2$ 方阵。换成 $3\times 2$ 长方形矩阵试试：

# 00-06 第四步：长方形矩阵也能做 SVD
import numpy as np

A = np.array([[1, 2],             # 3×2 长方形矩阵
              [3, 4],
              [5, 6]])

U, s, VT = np.linalg.svd(A)

print(f"A 形状: {A.shape}")
print(f"U 形状: {U.shape}  (椭圆轴方向，在 3 维空间里)")
print(f"奇异值: σ₁={s[0]:.2f}, σ₂={s[1]:.2f}")
print(f"V^T 形状: {VT.shape}  (被拉伸之前的方位，在 2 维空间里)")

# 验证
# Σ 是 3×2，前两行是对角矩阵，第三行全是 0
Sigma = np.zeros((3, 2))
Sigma[:2, :2] = np.diag(s)
print(f"\nU Σ V^T 等于 A？ {np.allclose(A, U @ Sigma @ VT)}")

🔗 在线运行

$3\times 2$ 矩阵只有 2 个奇异值（因为只有 2 列——最多拉伸 2 个独立方向）。虽然输出是 3 维的，但椭圆实际躺在一个 2 维平面上。

六、奇异值和 $A^T A$ 特征值的关系

奇异值可以用你已经学过的方法算出来。对任意矩阵 $A$（不要求方阵），$A^T A$ 一定是对称方阵，可以做特征值分解：

$$\text{奇异值 } \sigma_i = \sqrt{\lambda_i(A^T A)}$$

其中 $\lambda_i(A^T A)$ 是 $A^T A$ 的第 $i$ 大特征值。

# 验证：σ = sqrt( A^T A 的特征值 )
import numpy as np

A = np.array([[3, 1],
              [1, 3]])

ATA = A.T @ A                              # A^T A，一定是 2×2 对称方阵
eigvals = np.linalg.eigvals(ATA)           # 特征值分解
eigvals = np.sort(eigvals)[::-1]           # 从大到小排

sigma_from_eig = np.sqrt(eigvals)          # σ = sqrt(λ)

# 直接算 SVD 得到奇异值
_, s, _ = np.linalg.svd(A)

print(f"A^T A 的特征值: {eigvals}")
print(f"sqrt(特征值) = {sigma_from_eig}")
print(f"SVD 奇异值  = {s}")
print(f"一致？ {np.allclose(sigma_from_eig, s)}")

🔗 在线运行

为什么 $A^T A$ 能用来算奇异值？ 直觉：$A^T A$ 相当于「先用 $A$ 变换，再用 $A^T$ 拉回来」。被拉伸最多的方向（奇异向量）在 $A^T A$ 下也是拉伸最多的方向（特征向量），但拉伸倍数是原来的平方——所以奇异值 = sqrt(特征值)。

💭 概念题

1. 猜拉伸倍数

不用计算，凭直觉判断：$B = \begin{bmatrix} 5 & 0 \\ 0 & 0.1 \end{bmatrix}$ 对一个单位圆变换后，椭圆的长轴指向哪？长度是多少？短轴呢？

——考察：对角矩阵的奇异值就是对角线元素本身

2. SVD vs 特征值

特征值分解 $A = Q\Lambda Q^{-1}$ 和 SVD $A = U\Sigma V^T$ 最大的两个区别是什么？（提示：形状限制 + 正交性）

——考察：SVD 对任意形状有效、U 和 V 都是正交的

3. $A^T A$ 总是方阵

$A$ 是 $100\times 5$ 矩阵（100 个样本，5 个特征）。$A^T A$ 的形状是多少？有几个特征值？所以 $A$ 最多有几个奇异值？

——考察：奇异值个数 = min(m, n)
