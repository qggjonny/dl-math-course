00-07 连续分布

上节课 PMF 用柱子高度表示概率。但这招对「气温 25.317°C」完全没用——它有无限精度，你没法给每一个可能的气温画一根柱子。连续分布需要换一种思考方式。

一、单点概率 = 0，概率 = 面积

连续随机变量取任意一个确定值的概率 = 0。

不是说「气温恰好 25°C 不可能发生」——而是说在数学的无限精度下，恰好等于 25.0000... 是个零测集。想象一根针尖去戳一张纸：针尖戳到某个点的概率是 0（点没有面积），但针尖戳到某个区域的概率可以通过区域面积来算。

所以连续分布的概率不看「柱子的高度」，而是看 PDF 曲线下方的面积：

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

翻译成人话：$X$ 落在 $[a,b]$ 里的概率 = 曲线下面、$x=a$ 和 $x=b$ 两条竖线夹出来的面积。

PDF 两条铁律：
① $f(x) \ge 0$ — 密度不能是负数
② $\int_{-\infty}^{\infty} f(x)\,dx = 1$ — 总面积恰好等于 1

二、均匀分布——最诚实的分布

区间 [a,b] 里每个点的密度一模一样。PDF 是一段水平线。

$$f(x) = \begin{cases} \frac{1}{b-a}, & a \le x \le b \\ 0, & \text{其他地方} \end{cases}$$

宽 $(b-a)$ × 高 $1/(b-a)$ = 面积 1。没有任何偏好——这是最大熵分布。

三、正态分布——深度学习里最重要的钟

两个数字决定一切：

公式逐零件拆开：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

零件它在干什么
$(x-\mu)^2$离中心有多远的平方。远处→平方很大→指数部分很负→exp 后趋近 0→密度很小
$2\sigma^2$（分母）σ 越大，同样的距离被更大的分母「稀释」→衰减变慢→钟变胖
$\frac{1}{\sigma\sqrt{2\pi}}$归一化系数。σ 翻倍→系数减半，把变胖的钟拉矮确保证总面积 = 1
核心直觉： σ 翻倍 → 钟宽了一倍 → 为了总面积不变，高度必须减半。$\sigma=1$ 时 $f(0)=0.399$，$\sigma=2$ 时 $f(0)=0.199$——正好是一半。

四、CDF：累积分布函数——一路扫过去

从 $-\infty$ 出发，往右扫，把 PDF 下的面积不断累加。

画面： 一把刷子从最左边往右刷，每经过一段曲线，就把颜料扫进桶里。桶从空慢慢装满，到最右边刚好满。

五、68-95-99.7 法则

σ 就是天然的尺子：1σ 是正常波动，2σ 少见，3σ 极端。不是线性增长——正态尾部指数衰减，超出 3σ 的概率微乎其微。

🖥️ 完整代码

import numpy as np

# ===== 均匀分布 U(0,1) =====
a, b = 0.0, 1.0
# PDF 高度 = 1/(b-a)，使矩形面积 = 宽 × 高 = 1
h = 1.0 / (b - a)
print(f"U(0,1) PDF 高度 = {h}")
# 子区间 [0.2, 0.5] 概率 = 长度占比
c, d = 0.2, 0.5
prob = (d - c) / (b - a)
print(f"P({c}≤X≤{d}) = {prob}")

# numpy 验证：抽 10 万样本，频率逼近概率
np.random.seed(42)
samples = np.random.uniform(a, b, 100000)
in_int = np.sum((samples >= c) & (samples <= d))
print(f"模拟 P = {in_int/100000:.4f}")

# ===== 正态分布 PDF（手工实现） =====
def normal_pdf(x, mu, sigma):
    """正态密度 f(x;μ,σ) = exp(-(x-μ)²/2σ²) / (σ√(2π))"""
    coeff = 1.0 / (sigma * np.sqrt(2 * np.pi))
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coeff * np.exp(exponent)

# 验证 σ 减半效应
for s in [0.5, 1.0, 2.0]:
    print(f"σ={s}: f(0)={normal_pdf(0,0,s):.4f}")

# ===== 模拟验证 68-95-99.7 =====
np.random.seed(42)
sn = np.random.normal(0, 1, 100000)
for k in [1,2,3]:
    r = np.mean((sn >= -k) & (sn <= k))
    t = {1:0.6827,2:0.9545,3:0.9973}[k]
    print(f"±{k}σ: 模拟{r:.4f} 理论{t:.4f}")

# ===== CDF 数值积分 =====
xg = np.linspace(-4,4,501)
pdf = normal_pdf(xg, 0, 1)
dx = xg[1]-xg[0]
cdf = np.cumsum(pdf) * dx
print(f"\nF(-2)≈{cdf[125]:.4f} F(0)≈{cdf[250]:.4f} F(2)≈{cdf[375]:.4f}")
