00-07 连续分布

上一课我们跟伯努利、二项分布打交道——随机变量只能取几个离散值。每个值有一个概率质量，画成柱状图，柱子高度就是概率。这叫 PMF（概率质量函数）。

连续分布不是这样。随机变量可以取一个区间里的任意实数——"明天的气温 25.317……°C"，无限细分，无穷无尽。

连续随机变量取任意一个确定值的概率 = 0。

因为实数有无穷精度——你永远不可能用无限精度恰好卡在某个点上。那么概率怎么算？用面积。

一、PDF：密度 ≠ 概率

PMF（离散）PDF（连续）
纵轴概率本身概率密度
单点值可以 ≤ 1可以 > 1
概率 =柱子高度曲线下的面积

类比：一块不均匀的金属板。每个点的「密度」可以超过 1（单位 g/cm²），但你要知道某块区域的总质量，必须把密度积分：

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

这就是为什么单点概率为 0——一条竖线没有宽度，面积自然是 0。

PDF 两条铁律：
① $f(x) \ge 0$：密度不能是负数
② $\int_{-\infty}^{\infty} f(x)\,dx = 1$：总面积必须恰好等于 1

二、均匀分布

最简单的连续分布。区间 [a, b] 内每个点的密度一样——PDF 是一段水平线。

$$f(x) = \begin{cases} \dfrac{1}{b-a}, & a \le x \le b \\[8pt] 0, & \text{其他} \end{cases}$$

宽度 (b−a) × 高度 1/(b−a) = 面积 1。干净利落。
子区间概率 = 长度占比，没有任何花活。

三、正态分布：深度学习的皇冠

参数初始化（Xavier/He）、批归一化、VAE 潜在空间、扩散模型噪声——全跟它有关。

两个参数，各司其职：

公式拆开看

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$
零件作用
$(x-\mu)^2$离中心的平方。远处指数衰减
$2\sigma^2$（分母）σ 大 → 衰减慢 → 钟变胖
$\dfrac{1}{\sigma\sqrt{2\pi}}$归一化系数。σ 大变胖 → 系数变小拉矮
直觉：$\sigma$ 翻倍 → 钟胖了一倍 → 为保持总面积 = 1，高度必须减半。
验证：$f(0;0,\sigma) = 1/(\sigma\sqrt{2\pi})$，σ 翻倍时峰值恰好减半。

四、CDF：累积分布函数

从 −∞ 出发，一路往右扫，把 PDF 下的面积不断累加。

$$F(x) = P(X \le x) = \int_{-\infty}^x f(t)\,dt$$

几何直觉：一把宽度无限窄的刷子从 −∞ 往右刷，每经过一段 PDF 曲线，就把底下的颜料扫进桶里。桶里的颜料从 0 慢慢涨，到 +∞ 刚好满。

三个性质：

  • $F(-\infty)=0$ — 还没开始扫，桶是空的
  • $F(+\infty)=1$ — 全部刷完，桶满了
  • 单调不减 — 水只会涨，不会退

五、68–95–99.7 法则

σ 就是天然的"离中心有多远"的尺子。1σ 是常规波动，2σ 少见，3σ 极端事件。
不是线性增长——正态尾部指数衰减，超出 3σ 的概率微乎其微。

# 00-07 连续分布完整演示 — 复制到 online-python.com 运行
import numpy as np

# ==================== 一、均匀分布 U(a,b) ====================
a, b = 0.0, 1.0               # 区间端点 [a, b]
height = 1.0 / (b - a)       # PDF 高度 = 1/(b−a)，保证矩形面积 = 宽度×高度 = 1
print(f"均匀分布 U({a},{b}) PDF 高度 = {height}")  # 1.0

# 子区间 [c,d] 的概率 = 长度占比
c, d = 0.2, 0.5
prob_theory = (d - c) / (b - a)   # (0.5−0.2)/(1−0) = 0.3
print(f"理论 P({c}<=X<={d}) = {prob_theory}")

# numpy 模拟验证：抽样 10 万次，频率逼近概率
np.random.seed(42)          # 固定种子，结果可复现
# np.random.uniform(low, high, size)：从 [low, high) 均匀抽样 size 个
samples = np.random.uniform(a, b, 100000)
# (samples>=c) & (samples<=d) → 布尔数组，np.sum 求和 = 落在区间内的样本数
in_interval = np.sum((samples >= c) & (samples <= d))
prob_sim = in_interval / 100000  # 频率 ≈ 概率（大数定律）
print(f"模拟 P = {prob_sim:.4f}, 误差 {abs(prob_sim - prob_theory):.4f}")


# ==================== 二、正态分布 PDF（手工实现） ====================
def normal_pdf(x, mu, sigma):
    """正态分布概率密度函数
    x:     输入值（标量或数组，numpy 自动广播）
    mu:    均值 μ，控制钟的中心
    sigma: 标准差 σ，控制钟的胖瘦
    """
    # 归一化系数：σ 越大系数越小，把变胖的钟拉矮
    coeff = 1.0 / (sigma * np.sqrt(2 * np.pi))
    # 指数部分：−(x−μ)²/(2σ²)，离中心越远值越负，exp 后 → 0
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coeff * np.exp(exponent)

# 测试距中心 0, 1, 2, 3 个 σ 处的密度
x_test = np.array([0.0, 1.0, 2.0, 3.0])
densities = normal_pdf(x_test, mu=0.0, sigma=1.0)
for xv, d in zip(x_test, densities):
    print(f"  N(0,1) 在 x={xv:.0f}: f(x)={d:.4f}")
# 到 3σ 时密度已微乎其微（≈ 0.0044）


# ==================== 三、模拟验证 68-95-99.7 ====================
np.random.seed(42)
# np.random.normal(loc=μ, scale=σ, size=n)：从正态分布抽 n 个样本
samples_n = np.random.normal(loc=0.0, scale=1.0, size=100000)

for k in [1, 2, 3]:
    # np.mean 对布尔数组求平均 = True 的比例 = 概率估计
    in_range = np.mean((samples_n >= -k) & (samples_n <= k))
    theory = {1: 0.6827, 2: 0.9545, 3: 0.9973}[k]
    print(f"±{k}σ: 模拟 {in_range:.4f} | 理论 {theory:.4f}")


# ==================== 四、CDF 数值积分 ====================
x_grid = np.linspace(-4, 4, 501)      # 在 [-4,4] 上均匀取 501 个点
pdf_vals = normal_pdf(x_grid, mu=0.0, sigma=1.0)
dx = x_grid[1] - x_grid[0]               # 步长 ≈ 0.016
# np.cumsum 累积求和，×dx = 梯形法近似积分
cdf_approx = np.cumsum(pdf_vals) * dx
print(f"\nF(-2)≈{cdf_approx[125]:.4f}  F(0)≈{cdf_approx[250]:.4f}  F(2)≈{cdf_approx[375]:.4f}")
# F(0) 应 ≈ 0.5，验证对称性

题 1：σ 与峰值的关系

import numpy as np

def normal_pdf(x, mu, sigma):
    return np.exp(-0.5 * ((x - mu) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))

print(f"σ=0.5, f(0)={normal_pdf(0, 0, 0.5):.4f}")
print(f"σ=1.0, f(0)={normal_pdf(0, 0, 1.0):.4f}")
print(f"σ=2.0, f(0)={normal_pdf(0, 0, 2.0):.4f}")
# σ 翻倍 → 中心密度减半（总面积恒为 1 的约束）

  2. σ 变大时钟变矮变胖。从「总面积 = 1」这个硬约束出发，解释为什么胖了必须变矮。

    —— 考察：归一化约束的几何直觉（提示：σ 翻倍，中心密度打几折？）
