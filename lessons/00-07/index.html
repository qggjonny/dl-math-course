SVD（下）：用奇异值压缩信息

一、回忆：SVD 把矩阵拆成"图层"

上节课得到的 SVD 公式：

$$A = U \Sigma V^T$$

如果我们把 $U$ 的列记作 $\mathbf{u}_1, \mathbf{u}_2$，$V^T$ 的行记作 $\mathbf{v}_1^T, \mathbf{v}_2^T$，$\Sigma$ 对角线上的奇异值记作 $\sigma_1, \sigma_2$，那么 SVD 可以逐项展开写：

$$A = \sigma_1 \cdot \mathbf{u}_1 \mathbf{v}_1^T \;+\; \sigma_2 \cdot \mathbf{u}_2 \mathbf{v}_2^T$$

每一项 $\sigma_i \mathbf{u}_i \mathbf{v}_i^T$ 是一个 $2\times 2$ 矩阵（$\mathbf{u}_i$ 是 $2\times 1$ 列向量，$\mathbf{v}_i^T$ 是 $1\times 2$ 行向量，外积得到 $2\times 2$）。可以理解为一张"图层"——$\sigma_i$ 越大，这层贡献越大。

# 00-07 第一步：把 SVD 展开，看每一项（每一层）长什么样
import numpy as np

A = np.array([[3, 1],
              [1, 3]])

U, s, VT = np.linalg.svd(A)                # U(2×2), s=[σ₁,σ₂], VT(2×2)

print("原始矩阵 A:")
print(A)

# 逐层拆开
for i in range(len(s)):
    # 第 i 层: σᵢ · uᵢ · vᵢ^T
    # np.outer(a, b) = a @ b^T → 外积 得到矩阵
    layer = s[i] * np.outer(U[:, i], VT[i, :])
    print(f"\n第 {i+1} 层 (σ={s[i]:.1f}):")
    print(layer)

# 验证：两层加起来 = A
reconstructed = s[0]*np.outer(U[:,0], VT[0,:]) + \
               s[1]*np.outer(U[:,1], VT[1,:])
print(f"\n两层之和:\n{reconstructed}")
print(f"等于 A？ {np.allclose(A, reconstructed)}")

二、扔掉小奇异值——只用一层

$\sigma_1 = 4$，$\sigma_2 = 2$。第一层贡献大，第二层贡献小。如果只用第一层（扔掉第二层），结果差多少？

# 00-07 第二步：只用最大的奇异值重建——看看误差多大
import numpy as np

A = np.array([[3, 1],
              [1, 3]])
U, s, VT = np.linalg.svd(A)

# 只用 k=1 个最大奇异值
k = 1
A_1 = sum(s[i] * np.outer(U[:, i], VT[i, :])
          for i in range(k))

error = np.linalg.norm(A - A_1, 'fro')      # Frobenius 范数 = 所有元素平方和的根
                                            # 用来衡量两个矩阵之间的"距离"

print(f"只用 {k} 个奇异值重建:")
print(A_1)
print(f"\n原始 A:")
print(A)
print(f"\n误差 = {error:.3f}")
print(f"相对误差 = {error / np.linalg.norm(A, 'fro') * 100:.1f}%")

🔗 在线运行

只用 1 个奇异值（丢掉了一半信息），误差约 40%。不算小——但这个思路在更大的矩阵上威力巨大。如果一个矩阵有 100 个奇异值、只有前 5 个比较大，丢掉后 95 个可能只损失 1%。

三、更大的例子：5×3 矩阵

# 00-07 第三步：5×3 矩阵，用前 k 个奇异值重建
import numpy as np

np.random.seed(42)
# 生成一个"接近低秩"的 5×3 矩阵：前两列相关
A = np.random.randn(5, 3)             # 5×3 随机矩阵
A[:, 2] = A[:, 0] * 0.5 + A[:, 1] * 0.3  # 第3列 ≈ 前两列的线性组合
                                       # 这样第3个奇异值会很小

U, s, VT = np.linalg.svd(A)

print(f"A 形状: {A.shape}")
print(f"奇异值: σ₁={s[0]:.3f}, σ₂={s[1]:.3f}, σ₃={s[2]:.3f}")
print()
print("原始 A:")
print(np.round(A, 3))

for k in [1, 2]:
    # A_k = Σ_{i=0}^{k-1} σᵢ uᵢ vᵢ^T
    A_k = sum(s[i] * np.outer(U[:, i], VT[i, :])
              for i in range(k))
    error = np.linalg.norm(A - A_k, 'fro')
    rel_err = error / np.linalg.norm(A, 'fro') * 100
    print(f"\nk={k}: 误差={error:.3f}, 相对={rel_err:.1f}%")
    print(np.round(A_k, 3))

🔗 在线运行

第三个奇异值很小（因为我们故意让第三列 ≈ 前两列的线性组合）。只用前 2 个奇异值重建，误差可能不到 1%——15 个数字的矩阵，用 10 个数字的"压缩版"几乎无损恢复。

四、伪逆——长方形矩阵的"逆"

$A$ 是 $m \times n$ 长方形矩阵时，不能求 $A^{-1}$（只有方阵才有逆）。但 SVD 可以构造一个"最接近逆的东西"——伪逆 $A^+$：

$$A^+ = V \Sigma^+ U^T$$

其中 $\Sigma^+$ 是把非零奇异值取倒数然后转置。

举个例子立即就清楚了：

# 00-07 第四步：伪逆 — 手搓 vs 内置
import numpy as np

A = np.array([[1, 2],             # 3×2 长方形矩阵
              [3, 4],
              [5, 6]])

# 方法1: numpy 内置
A_plus_np = np.linalg.pinv(A)              # 伪逆，返回 2×3

# 方法2: 用 SVD 手搓
U, s, VT = np.linalg.svd(A)                # U:3×3, s:[σ₁,σ₂], VT:2×2

# 构造 Σ⁺：先取倒数，再转置
sigma_inv = np.diag(1.0 / s)              # 2×2 对角矩阵 [[1/σ₁, 0], [0, 1/σ₂]]
sigma_plus = np.zeros((2, 3))           # Σ⁺ 是 2×3（Σ 原来是 3×2）
sigma_plus[:2, :2] = sigma_inv            # 填入 1/σᵢ

A_plus_manual = VT.T @ sigma_plus @ U.T   # V Σ⁺ U^T = A⁺

print("numpy pinv:\n", np.round(A_plus_np, 4))
print("\n手搓:\n", np.round(A_plus_manual, 4))
print(f"\n一致？ {np.allclose(A_plus_np, A_plus_manual)}")

# 伪逆有什么用？解 Ax = b：
b = np.array([1, 2, 3])
x = A_plus_np @ b                          # x = A⁺ b，这是最小二乘解
print(f"\n解 Ax ≈ b: x = {np.round(x, 4)}")
print(f"验证 Ax = {np.round(A @ x, 4)}")
print(f"目标 b = {b}")
print(f"||Ax-b|| = {np.linalg.norm(A @ x - b):.4f}")

🔗 在线运行

伪逆的本质是：把非零奇异值取倒数——因为 SVD 告诉我们 $A$ 在这些方向上拉伸了 $\sigma$ 倍，要"撤销"这个拉伸，就除以 $\sigma$。

伪逆和最小二乘：
方程 $A\mathbf{x} = \mathbf{b}$（$A$ 是 $3\times 2$，3 个方程 2 个未知数）一般无解。
$\mathbf{x} = A^+ \mathbf{b}$ 给出的是最接近的近似解——让 $\|A\mathbf{x} - \mathbf{b}\|$ 最小。
这就是最小二乘。线性回归本质上就是在做这件事。

💭 概念题

1. 截断的直觉

一个 100×100 的矩阵有 80 个非零奇异值。只保留前 5 个重建，误差 0.3%。这说明什么？后 75 个奇异值大概多小？

——考察：奇异值衰减速度 = 矩阵"低秩程度"

2. 伪逆 vs 普通逆

$A$ 是 $2\times 2$ 可逆方阵。用 SVD 证明 $A^+ = A^{-1}$。（提示：$A = U\Sigma V^T$，所以 $A^{-1} = V\Sigma^{-1} U^T$）

——考察：伪逆是普通逆的推广

3. 秩和零奇异值

如果 $A$ 是 $5 \times 5$ 矩阵，`np.linalg.svd` 返回的奇异值中有一个是 0（或极接近 0）。$A$ 的秩是多少？`np.linalg.matrix_rank(A)` 会返回什么？验证代码。

——考察：秩 = 非零奇异值的个数
