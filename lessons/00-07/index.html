SVD（下）：低秩近似与伪逆

一、截断 SVD：扔掉不重要的部分

画面： 上节课讲的圆变椭圆。如果椭圆某个轴的方向拉伸倍数极小（$\sigma \approx 0$），那个方向上的信息几乎被压扁了——扔掉它对整体影响微乎其微。

把 SVD 展开写：

$$A = U\Sigma V^T = \sum_{i=1}^r \sigma_i \,\mathbf{u}_i \mathbf{v}_i^T$$

其中 $r$ 是非零奇异值的个数（矩阵的秩）。每一项 $\sigma_i \mathbf{u}_i \mathbf{v}_i^T$ 是一个秩为 1 的矩阵——可以理解为一张"图层"。

如果只保留前 $k$ 个最大的奇异值：

$$A_k = \sum_{i=1}^k \sigma_i \,\mathbf{u}_i \mathbf{v}_i^T$$

$A_k$ 是 $A$ 的最佳 $k$ 秩近似——在所有秩 ≤ $k$ 的矩阵中，$A_k$ 和原矩阵的误差最小。（这就是 Eckart–Young 定理）

类比： 就像用三原色画一幅画。相比 256 色调色板，只用红黄蓝三种颜料损失了很多细节——但画面的大致色调还在。奇异值最大的那几个方向就是"最重要的颜料"。

二、图像压缩：眼见为实

用一张灰度图来展示截断 SVD 的效果。灰度图就是一个矩阵——每个元素是像素灰度值（0~255）。

# 00-07 图像 SVD 压缩 — 只用前 k 个奇异值重建图像
import numpy as np

# 生成一个"玩具图像"：10×10 的十字图案
# 实际应用中可以用 plt.imread 读真实图像
img = np.zeros((10, 10))            # 10×10 全零矩阵（黑色）
img[4:6, :] = 1.0                   # 中间两行设为白色（水平线）
img[:, 4:6] = 1.0                   # 中间两列设为白色（竖直线）
                                       # 结果：一个白色十字架图案

# SVD 分解
U, s, VT = np.linalg.svd(img)          # s 是 1D 奇异值数组，从大到小排列

print("奇异值:", np.round(s, 2))
print("非零奇异值个数 =", np.sum(s > 1e-10))

# 只用前 k 个奇异值重建
for k in [1, 2, 3, 5]:
    # A_k = sum_{i=0}^{k-1} σᵢ · uᵢ · vᵢ^T
    # np.outer(a, b) 计算 a 和 b 的外积 a b^T
    A_k = sum(s[i] * np.outer(U[:, i], VT[i, :])
               for i in range(k))
    
    # 计算重建误差（Frobenius 范数）
    error = np.linalg.norm(img - A_k)   # 默认就是 Frobenius 范数
    
    print(f"\nk={k}:")
    print(np.round(A_k, 1))
    print(f"误差: {error:.3f}")

运行就能看到：只用 2 个奇异值，十字架的大致轮廓就恢复了；用 3 个，几乎完美。而原图有 9 个非零奇异值——前 3 个就携带了绝大部分信息。

三、伪逆：长方形矩阵怎么"求逆"

问题： 只有方阵才有逆矩阵。长方形的 $A$（比如 $3 \times 2$）不能直接求逆。但很多时候我们需要解 $A\mathbf{x} = \mathbf{b}$——比如线性回归里找最小二乘解。

答案：伪逆 $A^+$（读作"A dagger"），通过 SVD 定义：

$$A^+ = V \Sigma^+ U^T$$

其中 $\Sigma^+$ 是把 $\Sigma$ 的所有非零奇异值取倒数，然后转置：

$$\Sigma = \begin{bmatrix} \sigma_1 & 0 \\ 0 & \sigma_2 \\ 0 & 0 \end{bmatrix}_{3\times2} \quad\Longrightarrow\quad \Sigma^+ = \begin{bmatrix} 1/\sigma_1 & 0 & 0 \\ 0 & 1/\sigma_2 & 0 \end{bmatrix}_{2\times3}$$ 
# 00-07 伪逆 — 长方形矩阵的"逆"
import numpy as np

# 3×2 长方形矩阵，列数 > 行数时方程可能无解
# 但伪逆给出最小二乘解：min ||Ax - b||
A = np.array([[1, 2],
              [3, 4],
              [5, 6]])

b = np.array([1, 2, 3])         # 目标向量

# 方法1：numpy 内置
x_pinv = np.linalg.pinv(A) @ b         # pinv 返回伪逆 A^+

# 方法2：手搓 SVD 伪逆
U, s, VT = np.linalg.svd(A)             # U:3×3, s:[σ₁,σ₂], VT:2×2
r = np.sum(s > 1e-10)                    # 非零奇异值个数
S_inv = np.diag(1.0 / s[:r])            # Σ⁺ 的核心：非零奇异值取倒数
                                        # diag 把 1D 数组变成对角矩阵
S_inv_full = np.zeros((2, 3))          # Σ⁺ 是 2×3（Σ 是 3×2）
S_inv_full[:r, :r] = S_inv              # 非零部分填入
A_plus = VT.T @ S_inv_full @ U.T        # A⁺ = V Σ⁺ U^T
                                       # VT.T = V, U.T = U^T

x_manual = A_plus @ b                   # 解 A⁺ b

print("numpy pinv:", x_pinv)
print("手搓 SVD:", x_manual)
print("一致?", np.allclose(x_pinv, x_manual))

# 验证：Ax 应该尽量接近 b（最小二乘意义下）
print("\nAx =", A @ x_pinv)
print("b  =", b)
print("||Ax-b|| =", np.linalg.norm(A @ x_pinv - b))

四、伪逆和最小二乘

对 $A\mathbf{x} = \mathbf{b}$（$A$ 是 $m \times n$），分两种情况：

情况方程数解的性质
$m > n$（高瘦矩阵） 方程多于未知数 一般无精确解。伪逆给出最小二乘解：$\min \|A\mathbf{x} - \mathbf{b}\|$
$m < n$（矮胖矩阵） 未知数多于方程 无穷多解。伪逆给出最小范数解：所有解中 $\|\mathbf{x}\|$ 最小的那个

线性回归就是第一种情况：样本数 >> 特征数，用伪逆找最小二乘拟合。

截断 SVD 在深度学习中的应用：
  • LoRA：不更新整个权重矩阵 $W$，而是加一个低秩增量 $\Delta W = BA$，只训练 $A$ 和 $B$。本质：假设更新只在最大的几个奇异值方向上
  • 模型压缩：对全连接层的权重做 SVD，只保留前 k 个奇异值——压缩 10 倍但精度损失 < 1%
  • 权重初始化：一些方法用 SVD 初始化权重，确保初始时各方向拉伸均匀

💭 概念题

1. 截断的直觉

一张 1000×1000 的灰度图像，SVD 后有 500 个非零奇异值。只保留前 20 个重建，图像看起来模糊但轮廓清晰。为什么前 20 个奇异值能保留主要的视觉信息？后面 480 个奇异值携带了什么？

——考察：奇异值大小 = 信息重要性、截断 = 丢弃细节保留结构

2. 伪逆 vs 普通逆

如果 $A$ 是 $n \times n$ 可逆方阵，$A^+$ 和 $A^{-1}$ 是什么关系？用 SVD 验证：当所有奇异值都非零且 $A$ 是方阵时，$A^+ = A^{-1}$。

——考察：伪逆是普通逆的推广

3. 秩和奇异值

一个 $5 \times 5$ 矩阵只有 3 个非零奇异值。这个矩阵的秩是多少？用 numpy 生成一个秩为 3 的矩阵，验证 `np.linalg.matrix_rank(A)` 和非零奇异值个数一致。

——考察：秩 = 非零奇异值个数
