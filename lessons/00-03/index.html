00-03 范数

范数：箭有多长，看你怎么量

向量 $\mathbf{v} = [3, -4]$ 有多"大"？取决于你是开车还是坐直升机。

L1 范数：曼哈顿的出租车

画面： 你在纽约曼哈顿。街道全是横平竖直的网格，不能斜穿街区。从 $(0,0)$ 到 $(3,-4)$，只能先往东开 3 条街，再往南开 4 条街。一共走了 7 个街区。这就是 L1：把每个分量的绝对值加起来。

$$\|\mathbf{v}\|_1 = |3| + |-4| = 7$$

为什么用绝对值？ 因为往南走了 4 条街——走的距离是 4，不是 -4。绝对值吃掉正负号，只留"走了多远"。

L2 范数：坐直升机

画面： 这次你不管什么街道了，直接坐直升机从起点飞到终点。这就是你脑子里那个"两点之间最短"的距离——初中就学过的勾股定理。

$$\|\mathbf{v}\|_2 = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = 5$$

L2 就是直线距离。负号在平方里自动消失（$(-4)^2 = 16$），所以不用额外取绝对值。

# 导入numpy科学计算库，别名np
import numpy as np
# np.array(列表) → 创建一维向量v，shape=(2,)
v = np.array([3, -4])
# L1范数 = 各分量绝对值之和 —— 曼哈顿出租车走的街区数
# np.abs(v)：对数组每个元素取绝对值 → [3, 4]（吃掉负号）
# np.sum()：对数组所有元素求和 → 返回标量
# L1 = |3| + |-4| = 3 + 4 = 7
l1 = np.sum(np.abs(v))
# 输出: L1 = 7 —— 出租车计价器上的街区数
print(f"L1 = {l1}")
# L2范数 = 欧几里得距离 —— 直升机直线飞行的距离
# np.linalg.norm(v)：默认ord=None即L2范数，√(v₁² + v₂² + ...)
# L2 = √(3² + (-4)²) = √(9+16) = √25 = 5.0
l2 = np.linalg.norm(v)
                                      # 平方让负号自动消失：(-4)² = 16，不需要额外取绝对值
# 输出: L2 = 5.0 —— 直升机仪表盘上的直线距离
print(f"L2 = {l2}")

L1 和 L2 的形状有什么不同？

把所有长度为 1 的向量画出来：L1 画出来是一个菱形，L2 画出来是一个圆。

为什么这个形状重要？菱形有四个尖角，恰好戳在坐标轴上——这个性质意味着 L1 天然"喜欢"让某些分量精确为 0。圆没有尖角，L2 只会让分量变小但不会精确到 0。

💡 为什么尖角意味着零分量？ 用两个例子来感受。

向量 $(3, 5)$ — 两个分量都不为零，不稀疏。
向量 $(3, 0)$ — 有一个分量精确为 0，稀疏。
向量 $(0, 0, 7, 0, 0)$ — 5 个分量里 4 个是零，非常稀疏。

「稀疏」就是分量里有很多精确的零。

那么 L1 为什么天然产生稀疏向量？看图：菱形的四个尖角恰好戳在坐标轴上——在尖角上，总有一个分量为 0。而圆的边缘光滑，没有尖角，碰不到坐标轴。

打个比方：你有一根棍子（一条直线），想在上面找一个"最短"的点（按某种量法）。如果用圆形"尺子"量——圆形膨胀到碰到棍子时，接触点通常是光滑弧面上的一个点，两个分量都不为零。但用菱形"尺子"量——菱形膨胀到碰到棍子时，尖角先戳到棍子，接触点的某个分量恰好是 0。

这就是 L1 比 L2 更容易产生零分量的几何原因。 菱形有尖角，圆没有。以后当你需要「挑出最重要的几个分量，把不重要的清零」时，就会想起 L1 这个特性。
