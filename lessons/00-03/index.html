00-03 范数与特征值

一、范数：向量的"大小"怎么量

一个向量 $\mathbf{v} = [3, -4]$，它有多"大"？这取决于你怎么量。

L1 范数：走格子的距离

$$\|\mathbf{v}\|_1 = |3| + |-4| = 7$$

画面： 想象你在曼哈顿，街道全是横平竖直的网格。从 $(0,0)$ 走到 $(3,-4)$，你不能斜着走，必须沿街道走：先往东 3 个街区，再往南 4 个街区。总共走了 7 个街区。这就是 L1 范数（曼哈顿距离）。

L1 的妙用——产生稀疏权重： L1 正则化就是给损失函数加上 $\lambda \sum |w_i|$ 作为惩罚。为什么这样能产生很多精确为 0 的权重？因为 L1 的导数在除了 0 以外的任何地方都是 ±1——惩罚力度不随权重变小而减弱，一路推到 0 为止。

L2 范数：直线距离

$$\|\mathbf{v}\|_2 = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = 5$$

画面： 这次你不管什么街道了，直接从起点飞到终点。这就是欧几里得距离——你脑子里那个"两点之间最短"的概念。

L2 的妙用——Weight Decay： L2 正则化 = $\lambda \sum w_i^2$。它的导数是 $2\lambda w_i$——权重越大惩罚越狠，权重越小惩罚越轻。所以权重会趋向 0 但不会精确等于 0。这恰好防止过拟合又不损失信息。

为什么正则化 = 防过拟合？

极端权重 → 模型对输入的微小变化极度敏感 → 训练集上拟合太好但测试集上崩溃 = 过拟合。正则化就是把权重"往回拉"，强迫模型简单一点。

import numpy as np

v = np.array([3, -4])

# L1：np.abs 取绝对值，np.sum 求和
l1 = np.sum(np.abs(v))  # |3| + |-4| = 7
print(f"L1 范数: {l1}")

# L2：np.linalg.norm 默认参数是 L2
# 内部计算：sqrt(3² + (-4)²) = 5
l2 = np.linalg.norm(v)
print(f"L2 范数: {l2}")

二、特征值与特征向量：矩阵的「指纹」

问题： 矩阵 $A$ 把一个向量扭了。有没有哪些向量，扭完之后方向完全不变，只是被拉长或缩短了？

$$A\mathbf{v} = \lambda \mathbf{v}$$

如果存在这样的 $\mathbf{v}$（且 $\mathbf{v} \neq \mathbf{0}$），那 $\mathbf{v}$ 就叫 特征向量，$\lambda$ 就叫 特征值。

画面： 想象你把一块橡胶皮拉伸。有些方向只是被拉长（特征值 > 1），有些方向被压缩（0 < 特征值 < 1），有些方向完全不变（特征值 = 1）。特征向量就是这些"只缩放不旋转"的特殊方向。它们是矩阵的指纹——不同矩阵有不同的特征方向和缩放比例。

特征向量不唯一： 如果 $\mathbf{v}$ 是特征向量，$2\mathbf{v}$、$0.5\mathbf{v}$ 也是——方向一样只是长度不同。习惯上取长度为 1 的那个（单位特征向量）。

import numpy as np

A = np.array([[4, 1],
              [2, 3]])

# np.linalg.eig 返回两个东西：
#   eigvals: 特征值数组（排列顺序随机）
#   eigvecs: 特征向量矩阵（每列是一个特征向量）
eigvals, eigvecs = np.linalg.eig(A)

print(f"特征值: {eigvals}")        # [5, 2]  两个特征值
print(f"特征向量:\n{eigvecs}")

# 验证第一个特征值-特征向量对：A@v 应该等于 λ*v
v1 = eigvecs[:, 0]           # 取第 0 列（第一个特征向量）
l1 = eigvals[0]              # 第一个特征值
print(f"\n验证 A·v = λ·v:")
print(f"  A·v = {A @ v1}")
print(f"  λ·v = {l1 * v1}")
# np.allclose(a, b) 判断两个数组是否在浮点误差范围内相等
print(f"  np.allclose: {np.allclose(A @ v1, l1 * v1)}")  # True
谱归一化（Spectral Normalization）： GAN 的训练经常不稳定。谱归一化把判别器每一层的权重矩阵除以它的最大特征值，保证矩阵的"放大能力"不超过 1——这样信息流过每一层时不会被放大，训练就稳了。
