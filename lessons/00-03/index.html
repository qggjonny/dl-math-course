00-03 范数与特征值

一、范数：箭有多长，看你怎么量

向量 $\mathbf{v} = [3, -4]$ 有多"大"？这取决于你是开车还是走路。

L1 范数：曼哈顿的出租车

画面： 你在纽约曼哈顿。街道全是横平竖直的网格，不能斜穿街区。从 $(0,0)$ 到 $(3,-4)$，只能先往东开 3 条街，再往南开 4 条街。一共走了 7 个街区。

$$\|\mathbf{v}\|_1 = |3| + |-4| = 7$$

L1 为什么产生精确零？ L1 正则化给损失加上 $\lambda\sum|w_i|$。它的导数在 $w_i>0$ 时是 $+\lambda$，在 $w_i<0$ 时是 $-\lambda$——惩罚力度恒定，不论权重多小都照罚不误。所以权重会被一路推到精确的 0。

L2 范数：坐直升机

画面： 这次你不管什么街道了，直接坐直升机从起点飞到终点。这就是你脑子里那个"两点之间最短"的距离。

$$\|\mathbf{v}\|_2 = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = 5$$

L2 为什么不产生精确零？ L2 正则化加 $\lambda\sum w_i^2$。导数是 $2\lambda w_i$——权重越小惩罚越轻。所以权重趋向 0 但不会精确到 0（越接近 0 惩罚越弱，推不动了）。

正则化防过拟合的直觉

极端大的权重 → 模型对输入的微小变化极度敏感 → 训练集上拟合太完美，换一批数据就崩了。正则化就是把权重往回拉、往下压，强迫模型简单一点。

import numpy as np

v = np.array([3, -4])

# L1：绝对值求和（出租车走过的街区数）
l1 = np.sum(np.abs(v))
print(f"L1 = {l1}")  # 7

# L2：直线距离（直升机飞的）
l2 = np.linalg.norm(v)
print(f"L2 = {l2}")  # 5.0

二、特征值与特征向量：矩阵的"指纹"

画面： 想象你有一块方形的橡胶皮。你用两根手指扯住它的对角，往外拉。橡胶皮上的图案被扯变形了。

但有些方向只是被拉长，没有被扭曲。 如果你在橡胶皮上画了一个沿着对角线的箭头，拉完之后它还是沿着对角线的方向——只是变长了。这个方向就是特征方向。变长的倍数就是特征值。

用数学写：

$$A\mathbf{v} = \lambda \mathbf{v}$$

$A$ 是变换（扯橡胶皮），$\mathbf{v}$ 是特征向量（不被扭的方向），$\lambda$ 是特征值（拉长了几倍）。

如果 $\lambda=2$：这个方向被拉长到原来的 2 倍。
如果 $\lambda=0.5$：被压扁到原来的一半。
如果 $\lambda=0$：被压成了一条线（那个方向的信息消失了）。
如果 $\lambda$ 是负数：不仅拉长，还翻转了方向。

A = np.array([[4, 1], [2, 3]])

# eig 返回两样：eigvals=特征值数组, eigvecs=特征向量（每列一个）
eigvals, eigvecs = np.linalg.eig(A)

print(f"特征值: {eigvals}")        # 5 和 2
print(f"特征向量:\n{eigvecs}")

# 验证：A@v 应该 = λ×v
v1 = eigvecs[:, 0]            # 第一个特征向量
l1 = eigvals[0]               # 第一个特征值
print(f"A@v = {A @ v1}")       # 应该 = λ×v
print(f"λ×v = {l1 * v1}")
print(f"相等? {np.allclose(A @ v1, l1 * v1)}")  # True

💭 概念题

  1. 从梯度更新的角度解释：为什么 L1 正则化产生精确零权重，L2 只产生接近零的权重？——考察：L1 常数梯度 vs L2 线性梯度（本课讲过出租车 vs 直升机的比喻，以及两种惩罚的导数特性）
  2. 找特征向量就像找橡胶皮上"只被拉长不被扭"的方向。如果特征值 = 0，那个方向上的东西在变换后会变成什么？——考察：零特征值的几何含义（本课讲过 λ=0 = 被压成线）
  3. 用 np.linalg.eig 验证：把 A 改成 [[2,0],[0,3]]，特征值和特征向量各是什么？为什么这么简单？——考察：对角矩阵的特征值就是对角元素（本课讲了特征值定义 A·v = λ·v）
