00-01 标量、向量、矩阵、张量

数学和编程里每一片数据都有"形状"——就像积木有不同大小。这节课认识四种最基本的形状。每种形状我们先在脑子里建一个画面，再用代码看一眼。

▲ 四级台阶：每升一级，多一个维度

一、标量 Scalar — 一个单独的数

温度 25°C、考试分数 92、银行余额 384.50——这些都是标量：一个数，没有方向，没有形状。

在 Python 里怎么写？

# 导入numpy科学计算库，别名np —— Python做数学运算的核心库
import numpy as np
# np.array(标量) → 把Python浮点数包装成0维numpy数组（标量）
s = np.array(3.14)
                    # 3.14是个Python float，包一层后变成numpy的ndarray对象
# 打印标量的值 → 输出: 3.14 —— 就是那个数本身
print(s)
# .shape属性：返回元组表示数组各维大小 → () 空元组 = 零维
print(s.shape)
                    # 空括号意味着没有行也没有列——这就是"0维"的含义

二、向量 Vector — 一排数，像一根箭

画面： 想象你在黑板上画了一根从原点出发的箭，箭头落在 $(x, y)$ 的位置。这根箭就是向量 $[x, y]$。

如果箭头落在 $(3, 4)$：

  • 箭的长度 = $\sqrt{3^2 + 4^2} = 5$
    为什么是平方和开根号？勾股定理——从原点走到 (3,4)：先往右走 3，再往上走 4，这两段和斜线构成直角三角形。斜边² = 直角边²之和 = 3² + 4² = 25，所以斜边 = √25 = 5。
  • 箭的方向 = 箭头指的那个朝向

向量就是一排数——但不能只当一排数看。它背后是一根有长度、有方向的箭，这种直觉是后面所有线性代数的基础。

# np.array(列表) → 创建一维numpy数组（向量），形状(3,)
v = np.array([85, 92, 78])
                        # 方括号[]把三个数包在一起——numpy自动识别为一维
# 打印向量 → 输出: [85 92 78]
print(v)
# .shape属性 → 输出: (3,) —— 逗号表示"这是一维数组"
print(v.shape)
                        # (3,) 和 (1,3) 不同：(3,)是一维向量，(1,3)是只有一行的二维矩阵
# 索引访问：v[1]=92 —— Python索引从0开始，v[0]=85, v[2]=78
print(v[1])

向量就是"一张表"——你有一个学生三门课的成绩表，装在这个向量里。每个位置固定代表一门课：第 0 位是语文，第 1 位是数学，第 2 位是英语。

同一个箭头，两种容器：rank-1 vs rank-2

[85, 92, 78] 这根箭可以装在两种容器里：

rank-1 向量rank-2 列矩阵
代码np.array([85,92,78])np.array([[85],[92],[78]])
shape(3,) — 一个数(3,1) — 两个数
画面一根 3D 空间的箭同一根箭，但装在表格里

rank = shape 里有几个数。 () 是 rank-0（标量），(3,) 是 rank-1（向量），(3,1) 是 rank-2（矩阵）。

关键区别： rank-1 向量的 .T（转置）不生效——它没有"行"和"列"的概念，转置还是自己。为什么？ .T 的本质是「交换轴 0 和轴 1」——但 rank-1 只有轴 0，没有轴 1。没东西可交换，所以 .T 什么都不做。rank-2 列矩阵有两个轴（行和列），转置会交换它们：(3,1) → (1,3)。

# rank-1向量：np.array(一维列表) → shape=(3,)，只有轴0
a = np.array([1, 2, 3])
                            # 一根3D空间里的箭——有长度和方向，没有"行列"概念
# rank-2列矩阵：嵌套列表 → shape=(3,1)，有行轴和列轴
b = np.array([[1],[2],[3]])
                            # 同一根箭装在表格里——3行1列，每个分量独占一行
# rank-1向量调用.T转置 → 输出: [1 2 3] ——没变！
print(a.T)
# 原因：.T的本质是交换轴0和轴1，但rank-1只有轴0，无轴可换
# rank-2矩阵调用.T转置 → 输出: [[1 2 3]] —— 从(3,1)变成(1,3)
print(b.T)
