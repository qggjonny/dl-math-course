00-01 标量、向量、矩阵、张量

深度学习里每一片数据都有形状。这四个人名不是随便叫的——它们是从零维到高维的四级台阶。把这四级踩实了，后面所有矩阵运算、梯度传播、张量操作一看就懂。

一、标量 Scalar — 一个数

就是你脑子里的「一个数字」。

温度 25°C、损失值 0.37、学习率 0.001——都是标量。标量没有方向、没有形状，就是一个孤零零的数。 在 numpy 里怎么写？

import numpy as np  # numpy：Python 做数学运算的核心库

s = np.array(3.14)    # np.array() 把 Python 数字变成 numpy 数组
                       # 3.14 是 Python 的 float，包一层 np.array 后变成 numpy 标量
print(s)               # 输出: 3.14
print(s.shape)          # 输出: () —— 空括号，表示零维
                       # .shape 是每个 numpy 数组都有的属性，告诉你「几行几列」
                       # 标量没有行也没有列，所以 shape 是空元组 ()

标量是最简单的——它就是起点。但深度学习里很少单独用标量。一个标量要跟一千个标量一起算，怎么同时管一千个数？答案就是向量。

二、向量 Vector — 一排数 = 一根箭头

把一堆数排成一行（或一列），就是向量。比如一个学生的三门成绩：$[85, 92, 78]$。

但这只是「写法」。向量的真身是空间里的一根箭头：从原点 $(0,0,0)$ 出发，指向 $(85, 92, 78)$。

画面上看： 向量 $\mathbf{v} = [3, 4]$ 就是从 $(0,0)$ 到 $(3,4)$ 的一根箭头。它的长度 = $\sqrt{3^2 + 4^2} = 5$，它的方向就是箭头指的那个朝向。

代码里怎么写：

import numpy as np

v = np.array([85, 92, 78])  # 用方括号 [ ] 把三个数包起来，传给 np.array()
                              # numpy 自动识别：这是 1 维数组（向量）
print(v)                      # 输出: [85 92 78]
print(v.shape)                 # 输出: (3,) —— 长度为 3 的一维数组
                              # 逗号 (3,) 表示「这是一维，不是二维的单行」
                              # 如果是二维的单行，shape 会是 (1,3)
print(v[1])                   # 输出: 92 —— 索引从 0 开始，v[0]=85, v[1]=92, v[2]=78

向量在深度学习里无处不在：

  • 一个词嵌入就是向量：$[0.2, -0.5, 0.8, \ldots]$（几十到几百维）
  • 神经网络的一层输出就是向量：上一层 128 个神经元 → 128 维向量
  • 一个样本的特征就是向量：图片 X 的所有像素拉直

三、矩阵 Matrix — 向量的「操作手册」

矩阵不是数据——矩阵是对一个向量做操作的规则。

来看一个具体的例子。假设你有一个向量 $\mathbf{x} = [1, 2]$（2 维箭头），你想把它转一下、拉一下，得到一个新向量 $\mathbf{y}$。你需要一个「操作手册」告诉机器：怎么把旧向量的每个分量搅和到一起产生新分量。这本操作手册就是矩阵。

比如这个矩阵： $$\mathbf{W} = \begin{bmatrix} 2 & 1 \\ 0 & 3 \end{bmatrix}$$

把它乘到向量上：

$$\mathbf{y} = \mathbf{W}\mathbf{x} = \begin{bmatrix} 2 & 1 \\ 0 & 3 \end{bmatrix} \begin{bmatrix} 1 \\ 2 \end{bmatrix} = \begin{bmatrix} 2\times 1 + 1\times 2 \\ 0\times 1 + 3\times 2 \end{bmatrix} = \begin{bmatrix} 4 \\ 6 \end{bmatrix}$$

$\mathbf{x} = [1,2]$ 被扭成了 $\mathbf{y} = [4,6]$。矩阵是变换器。

形状规则必须记住：

操作条件结果形状
矩阵 × 向量 $Wx$$W$ 的列数 = $x$ 的长度$(m,n) \times (n,) \to (m,)$
矩阵 × 矩阵 $AB$$A$ 的列数 = $B$ 的行数$(m,n) \times (n,p) \to (m,p)$

代码：

import numpy as np

# 创建矩阵：用两层方括号 [[第一行], [第二行]]
W = np.array([[2, 1],     # 第一行：[2, 1]
              [0, 3]])    # 第二行：[0, 3]
                       # 形状：(2, 2) —— 2 行 2 列
print(W.shape)           # 输出: (2, 2)

x = np.array([1, 2])     # 向量，形状 (2,)

# @ 是 Python 3.5+ 引入的矩阵乘法运算符
# 等价于 np.dot(W, x) 或 np.matmul(W, x)
y = W @ x               # 矩阵乘向量：W(2,2) × x(2,) → y(2,)
print(y)                 # 输出: [4 6]

# 验证手算：y[0] = 2×1 + 1×2 = 4, y[1] = 0×1 + 3×2 = 6
深度学习里的矩阵： 全连接层的权重就是一个矩阵。$W.shape = (512, 256)$ 的意思是：输入 256 维向量 → 输出 512 维向量。网络就是一层又一层的矩阵乘法，把输入一步一步扭成输出。

四、张量 Tensor — 三维及以上的「数据容器」

标量是零维、向量是一维、矩阵是二维。三维及以上统称张量。

不需要怕这个词。 张量就是「多维数组」的学名。把形状写出来一看就明白：

数据形状含义
一张 224×224 的灰度图(224, 224)二维矩阵
一张 224×224 的 RGB 彩图(3, 224, 224)三维张量：3 个通道，各 224×224
一批 32 张 RGB 图(32, 3, 224, 224)四维张量：第 0 维是 batch
一段 10 秒音频（16kHz 采样率）(160000,)一维向量

第 0 维几乎总是 batch。 深度学习不一次处理一张图，而是一次处理一批（batch）。所以第一维从 1 变成 batch_size。

import numpy as np

# 三维张量：2 张 3×4 的灰度图
# np.ones(形状) 创建全 1 数组
T = np.ones((2, 3, 4))     # (batch=2, height=3, width=4)
print(T.shape)              # 输出: (2, 3, 4)

# .size 返回数组里总共有多少个元素
print(T.size)               # 输出: 24 (= 2×3×4)

# .ndim 返回维度数（几维）
print(T.ndim)               # 输出: 3
