00-01 标量、向量、矩阵、张量

深度学习中每一个数字都有形状。这节课把四种数据结构看清楚。

一、标量 Scalar

一个单独的数。温度 25°C、损失值 0.37、学习率 0.001——都是标量。

形状：()——空括号，零维。在 numpy 里是 np.array(3.14)。

二、向量 Vector

几何直觉：空间里的一根箭头。

$\mathbf{v} = [v_1, v_2, v_3]$ 是从原点到 $(v_1, v_2, v_3)$ 的箭头。长度 = 箭头的模，方向 = 箭头指哪。

形状：(n,)——一维。比如一个 3 维词向量：np.array([0.2, -0.5, 0.8])。

深度学习里向量无处不在：词嵌入是一个向量，隐藏层输出是一个向量，一个样本的特征也是一个向量。

三、矩阵 Matrix

几何直觉：空间变换的"操作手册"。

矩阵不是数据，是对向量做操作的规则。$\mathbf{y} = \mathbf{W}\mathbf{x}$ 的意思是：把向量 $\mathbf{x}$ 按照 $\mathbf{W}$ 规定的规则，扭成新向量 $\mathbf{y}$。

形状：(m, n)——二维。$m$ 行 $n$ 列。全连接层权重 W.shape = (512, 256) 意思是：输入 256 维向量 → 输出 512 维向量。

矩阵运算直觉形状规则
$\mathbf{W}\mathbf{x}$线性变换：旋转+缩放$(m,n) \times (n,) \to (m,)$
$\mathbf{W}_2\mathbf{W}_1$两次变换复合$(p,m) \times (m,n) \to (p,n)$
$\mathbf{W}^T$行列互换$(m,n) \to (n,m)$

四、张量 Tensor

三维及以上的数组统称张量。

一张 224×224 的 RGB 图片：形状 (3, 224, 224)——3 个通道，每个 224×224。

一批 32 张图片：(32, 3, 224, 224)——四维张量。第 0 维是 batch。

记住就四个：标量 = 零维，向量 = 一维箭头，矩阵 = 二维变换，张量 = 三维以上容器。深度学习的全部数据都是这四种。

🖥️ 代码

import numpy as np

# 标量：零维数组，形状是空元组 ()
s = np.array(3.14)
print(f"标量: 值={s}, 形状={s.shape}")  # 形状=()

# 向量：一维数组，形状 (n,)
v = np.array([1, 2, 3])
print(f"向量: {v}, 形状={v.shape}")  # 形状=(3,)

# 矩阵：二维数组，形状 (行, 列)
M = np.array([[1, 2, 3], [4, 5, 6]])
print(f"矩阵:\n{M}\n形状={M.shape}")  # 形状=(2,3)

# 张量：三维数组，形状 (depth, rows, cols)
T = np.ones((2, 3, 4))
print(f"张量: 形状={T.shape}")  # 形状=(2,3,4)
print(f"  总元素数={T.size}")       # 2×3×4=24
