00-08 期望与方差

一、期望：概率加权平均——不是最可能，是长期平均

掷一个六面骰子，每个面概率都是 1/6。问：掷很多很多次，平均值趋向多少？

$$\mathbb{E}[X] = 1\times\frac{1}{6} + 2\times\frac{1}{6} + \cdots + 6\times\frac{1}{6} = 3.5$$

画面： 想象你把骰子每个面的概率看成「砝码质量」，期望就是平衡支点的位置。支点放 3.5 的位置，整根横梁刚好平衡——左边三面的力矩 = 右边三面的力矩。

期望 ≠ 最可能的值。 骰子最可能的面？均匀分布没有「最可能」。期望 3.5 是对长期平均的预测，不是对下一次的预测。

连续版的期望

$$\mathbb{E}[X] = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$$

把离散的求和变成积分。

二、方差：数据有多散

$$\text{Var}(X) = \mathbb{E}[(X - \mu)^2]$$

拆开看：$X - \mu$ = 每个数据点离均值多远。平方（消除正负抵消）。取平均。

画面： 班上同学的身高。均值 165cm。有人 150，有人 180。方差度量了整体「散开」的程度。方差大 = 身高参差不齐；方差小 = 大家都差不多。

计算捷径： $$\text{Var}(X) = \mathbb{E}[X^2] - \mu^2$$。用平方的平均值减去平均值的平方。手算时比一个个减均值再平方快得多。

标准差：把方差单位调回正常

$$\sigma = \sqrt{\text{Var}(X)}$$

方差单位是原单位平方（比如「平方厘米」），标准差单位和原数据一致（「厘米」）。

三、两条重要性质

期望是线性的

$$\mathbb{E}[aX + b] = a\mathbb{E}[X] + b$$

$$\mathbb{E}[X + Y] = \mathbb{E}[X] + \mathbb{E}[Y]$$

不管 X 和 Y 是否独立，期望的加法都成立。

方差不线性

$$\text{Var}(aX + b) = a^2\text{Var}(X)$$

常数 b 消失了！ 因为方差度量的是分散程度，整体平移不改变分散程度——全班同时长高 10cm，身高的差异一点没变。但 a 被平方了——如果全班身高都翻倍，差异也会翻倍再翻倍（平方）。

四、深度学习里的应用

场景用到什么
BatchNorm每批次数据减均值（$\mu$）除标准差（$\sigma$）→ 稳定训练
参数初始化Xavier：$W \sim N(0, 1/\sqrt{n_{in}})$，保证每层输出的方差一致
MSE 损失$\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ 就是误差平方的经验期望

🖥️ 代码

import numpy as np

np.random.seed(42)
# 从 N(μ=5, σ=2) 抽 100000 样本
samples = np.random.normal(loc=5, scale=2, size=100000)

# 期望 ≈ 样本均值
mu_hat = np.mean(samples)
print(f"期望 μ: 理论=5, 样本={mu_hat:.4f}")

# 方差：np.var(ddof=0) 是总体方差（除以 n）
# ddof=1 是样本方差（除以 n-1，无偏估计）
var_hat = np.var(samples, ddof=0)
print(f"方差 σ²: 理论=4, 样本={var_hat:.4f}")
print(f"标准差 σ: 理论=2, 样本={np.std(samples, ddof=0):.4f}")

# 验证 E[aX+b] = aE[X]+b
a, b = 3, 10
trans = a * samples + b
print(f"\nE[aX+b] = {np.mean(trans):.2f} = aE[X]+b = {a*mu_hat+b:.2f} ✓")

# 验证 Var(aX+b) = a²Var(X)
print(f"Var(aX+b) = {np.var(trans,ddof=0):.2f} = a²Var(X) = {a**2*var_hat:.2f} ✓")
# b=10 对结果毫无影响——平移不改变散开程度

# 掷骰子验证：E[X]=3.5, Var(X)≈2.917
dice = np.random.randint(1, 7, size=100000)
print(f"\n骰子: E[X]≈{np.mean(dice):.3f} Var≈{np.var(dice,ddof=0):.3f}")

💭 概念题

  1. 方差用 $(X-\mu)^2$ 而不是 $|X-\mu|$。数学上为什么平方更好用？——考察：可导性（平方处处可导，绝对值在 0 处不可导）、与正态分布的解析对应
  2. BatchNorm 减均值除标准差后，这层输出的均值和方差分别是多少？——考察：归一化的统计效果（均值为 0，方差为 1）
  3. 为什么 Var(aX + b) 里 b 消失了？几何直觉上怎么理解？——考察：方差 = 分散程度，平移不改变形状
