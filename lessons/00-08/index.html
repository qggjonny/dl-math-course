00-08 导数与偏导数

一、导数：山路的坡度

画面： 你开车走盘山公路。仪表盘上的坡度计指着 15°。如果你继续往前开 1 公里，高度大约会上升 $\tan(15°)\times 1\text{km} \approx 270\text{m}$。

导数就是这个「坡度」——在某一点，你往前走一点点，高度变化的速率。

$$f'(x) = \lim_{\epsilon \to 0} \frac{f(x+\epsilon) - f(x)}{\epsilon}$$

逐符号拆开：

  • $f(x+\epsilon)$：你现在在 $x$ 位置，往前走一丁点 $\epsilon$ 后到达的新位置上的函数值
  • $f(x+\epsilon) - f(x)$：往前走 $\epsilon$ 后，函数值变化了多少（上升、下降、或不变）
  • 除以 $\epsilon$：归一化——不管走了多远，算出"每走 1 单位"的变化率
  • $\lim_{\epsilon \to 0}$：$\epsilon$ 无限趋近 0——我要的是这一点的瞬时坡度，不是一段路的平均坡度

回到开车的比喻：导数 > 0 = 正在上坡（往前走高度会增加），导数 < 0 = 正在下坡，导数 = 0 = 到了山顶或山谷（坡度为零）。

从定义推导求导规则

定义是好，但每次都用极限算太慢了。从定义出发，推几个最常用的规则。

$f(x) = x^2$ 的导数。 代入定义：

$$\begin{aligned} f'(x) &= \lim_{\epsilon \to 0} \frac{(x+\epsilon)^2 - x^2}{\epsilon} \\[4pt] &= \lim_{\epsilon \to 0} \frac{x^2 + 2x\epsilon + \epsilon^2 - x^2}{\epsilon} \\[4pt] &= \lim_{\epsilon \to 0} \frac{2x\epsilon + \epsilon^2}{\epsilon} = \lim_{\epsilon \to 0} (2x + \epsilon) = 2x \end{aligned}$$

所以 $(x^2)' = 2x$。每步做了什么：① 展开平方 ② 消掉 $x^2$ ③ 提出 $\epsilon$ 消掉 ④ $\epsilon \to 0$ 时 $\epsilon$ 项消失。

$f(x) = x^n$ 的通式（幂函数求导）： 还是走定义，三步拆开：

① 二项式展开：

$$(x+\epsilon)^n = x^n + n x^{n-1}\epsilon + \binom{n}{2} x^{n-2}\epsilon^2 + \dots + \epsilon^n$$

第一项是 $x^n$，后面每一项都带着 $\epsilon$ 或更高次幂。

② 代入差商：

$$\frac{f(x+\epsilon) - f(x)}{\epsilon} = \frac{(x^n + n x^{n-1}\epsilon + \epsilon^2\cdot(\cdots)) - x^n}{\epsilon} = n x^{n-1} + \epsilon \cdot (\cdots)$$

$x^n$ 被减掉消了；剩下的每一项都除以 $\epsilon$，$n x^{n-1}\epsilon / \epsilon = n x^{n-1}$，其余项除完后还有 $\epsilon$ 因子。

③ 取极限 $\epsilon \to 0$： 带 $\epsilon$ 的项全部归零——只留下 $n x^{n-1}$。结果是：

$$\boxed{(x^n)' = n \cdot x^{n-1}}$$

例子：$(x^3)' = 3x^2$，$(x)' = 1 \cdot x^0 = 1$，$(5)' = 0$（常数斜率永远是 0——一条水平线没有坡度）。

🔗 求和与常数倍的规则： 求导是线性运算。
  • $(f+g)' = f' + g'$ —— 和的导数 = 导数之和
  • $(c \cdot f)' = c \cdot f'$ —— 常数可以提到外面

这意味着 $(3x^2 + 2x + 5)' = 3 \cdot 2x + 2 \cdot 1 + 0 = 6x + 2$。逐项求导再拼起来就行。

代码验证：数值微分

定义里的 $\lim_{\epsilon \to 0}$ 在计算机上没法真正做到——但取一个很小的 $\epsilon$（比如 $10^{-5}$），差商 $\frac{f(x+\epsilon)-f(x)}{\epsilon}$ 会非常接近真实导数。这叫数值微分。

# 00-08 第一步：数值微分——用定义验证 f(x)=x² 的导数 f'(x)=2x
import numpy as np                       # 导入numpy，别名np（本例主要用于规范，实际未用numpy功能）

def f(x):                              # 定义函数 f(x) = x²
    """f(x) = x²"""                      # docstring文档字符串：说明这个函数做什么
    return x ** 2                        # **是幂运算：x**2 = x²，返回x的平方

def numerical_derivative(f, x, eps=1e-5):  # 数值微分函数，参数：函数f、求导点x、微小步长ε（默认10⁻⁵）
    """用定义算 f'(x)：取一个很小的 eps，算差商"""  # 用极限定义近似：f'(x) ≈ (f(x+ε)−f(x)) / ε
    return (f(x + eps) - f(x)) / eps     # 前向差商：(f(x+ε)−f(x))/ε，ε越小越精确

# 在 x=1, 2, 3 处验证——理论值：f'(x) = 2x
for x in [1, 2, 3]:                        # 循环测试3个点：x=1→导数值=2, x=2→4, x=3→6
    num = numerical_derivative(f, x)      # 调用数值微分，传入f和当前x → 数值近似导数
    exact = 2 * x                          # 理论值：幂函数求导法则 (x²)' = 2x
    # f-string: {x}=x值, {num:.6f}=数值结果保留6位, {exact}=理论值, {abs(...):.2e}=误差用科学记数法2位
    print(f"f'({x})  数值={num:.6f}  理论={exact}  误差={abs(num-exact):.2e}")

🔗 在线运行

误差约 $10^{-5}$——和 $\epsilon$ 同一量级。定义不是空洞的，是能在计算机上跑通的。

二、偏导数：只看一个踏板

如果函数有两个输入 $f(x,y)$——就像开车同时有油门和方向盘。偏导数就是问：「我只踩油门（$x$ 变），方向盘不动（$y$ 不变），高度变化多快？」

$$\frac{\partial f}{\partial x} = \lim_{\epsilon \to 0} \frac{f(x+\epsilon, y) - f(x, y)}{\epsilon}$$

$\partial$（读作 "round d"）这个符号只是提醒你：不止一个变量，但我现在只看这一个。

偏导数的计算规则——简单到离谱： 对 $x$ 求偏导时，把 $y$ 当成常数就行（就像把 $y$ 当成数字 5）。

例子：$f(x,y) = x^2 + 3xy + y^3$。

  • 对 $x$ 求偏导：$\frac{\partial f}{\partial x} = 2x + 3y + 0$。$y^3$ 看成常数 → 导数 = 0
  • 对 $y$ 求偏导：$\frac{\partial f}{\partial y} = 0 + 3x + 3y^2$。$x^2$ 看成常数 → 导数 = 0

代码验证：偏导数数值计算

# 00-08 第二步：偏导数数值计算——验证 ∂f/∂x 和 ∂f/∂y
import numpy as np                       # 导入numpy，别名np

def g(x, y):                            # 定义二元函数 g(x,y) = x² + 3xy + y³
    """f(x,y) = x² + 3xy + y³"""          # docstring：说明函数公式
    return x**2 + 3*x*y + y**3          # x**2=x², 3*x*y=3xy, y**3=y³

def partial_x(f, x, y, eps=1e-5):        # 对x的偏导数：f是原函数，x,y是求导点，eps=微小步长ε
    """对 x 的偏导：只动 x，y 不动"""       # 偏导数定义：∂f/∂x = lim_{ε→0} (f(x+ε,y)−f(x,y))/ε
    return (f(x + eps, y) - f(x, y)) / eps  # 只改变x（加ε），y保持不变 → 数值近似偏导

def partial_y(f, x, y, eps=1e-5):        # 对y的偏导数
    """对 y 的偏导：只动 y，x 不动"""       # 偏导数定义：∂f/∂y = lim_{ε→0} (f(x,y+ε)−f(x,y))/ε
    return (f(x, y + eps) - f(x, y)) / eps  # 只改变y（加ε），x保持不变 → 数值近似偏导

# 在点 (2, 3) 验证——把x₀=2, y₀=3代入偏导公式
x0, y0 = 2.0, 3.0                        # 测试点：x₀=2.0, y₀=3.0（浮点数）
# 理论：∂f/∂x = 2x + 3y（对x求偏导，y当常数）→ 2*2 + 3*3 = 4+9 = 13
# 理论：∂f/∂y = 3x + 3y²（对y求偏导，x当常数）→ 3*2 + 3*9 = 6+27 = 33
px_num = partial_x(g, x0, y0)             # 数值计算 ∂g/∂x 在 (2,3) 的值 → 应≈13.0
py_num = partial_y(g, x0, y0)             # 数值计算 ∂g/∂y 在 (2,3) 的值 → 应≈33.0
print(f"∂f/∂x  数值={px_num:.6f}  理论=13")  # :.6f=保留6位小数，误差约10⁻⁵量级
print(f"∂f/∂y  数值={py_num:.6f}  理论=33")  # 数值结果和理论值非常接近

🔗 在线运行

把 $y$ 当成常数——这个规则不是死记的，是「只动 $x$，$y$ 不动」这个定义的直接结果。

三、梯度：把所有偏导数打包

偏导数一个个算完之后，把它们装进一个向量里——这就是梯度：

$$\nabla f = \begin{bmatrix} \frac{\partial f}{\partial x} \\[4pt] \frac{\partial f}{\partial y} \end{bmatrix}$$

对 $f(x,y) = x^2 + 3xy + y^3$，梯度 = $\begin{bmatrix} 2x+3y \\ 3x+3y^2 \end{bmatrix}$。

在点 $(2,3)$ 处，梯度 = $\begin{bmatrix} 13 \\ 33 \end{bmatrix}$。

梯度的几何含义是下一课（00-07）的主题——这里先知道它就是把所有偏导打包成一个向量。
