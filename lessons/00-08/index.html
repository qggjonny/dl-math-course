00-08 期望与方差

一、期望：概率加权平均

离散： $$\mathbb{E}[X] = \sum_i x_i \cdot P(X = x_i)$$

连续： $$\mathbb{E}[X] = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$$

直觉： 如果重复实验无限次，结果的平均值往哪里收敛。不是"最可能的值"——那是众数。

概念含义例子：抛骰子
期望 $\mu$长期平均3.5
中位数正中间的值3.5
众数最常出现的值任一（均匀分布无众数）

二、方差：分散程度

$$\text{Var}(X) = \mathbb{E}[(X - \mu)^2] = \mathbb{E}[X^2] - \mu^2$$

直觉： 数据点离均值有多远，平方后取平均。方差大 = 数据散得开；方差小 = 数据聚在均值附近。

三、标准差：方差的平方根

$$\sigma = \sqrt{\text{Var}(X)}$$

方差单位是原单位的平方（比如"平方摄氏度"），标准差单位和原数据一致。

深度学习关键应用：
  • BatchNorm： 对每批数据减均值除标准差 → 稳定训练
  • 参数初始化： Xavier/He 初始化用方差控制信号传播
  • 损失函数： MSE = 期望(预测-真实)²

四、期望的线性性质

$$\mathbb{E}[aX + b] = a\mathbb{E}[X] + b$$

$$\mathbb{E}[X + Y] = \mathbb{E}[X] + \mathbb{E}[Y]$$

期望是线性算子——不管 X 和 Y 是否独立。

方差不线性： $$\text{Var}(aX + b) = a^2\text{Var}(X)$$（常数 b 被消掉了）

🖥️ 代码

import numpy as np

np.random.seed(42)

# 从 N(μ=5, σ=2) 抽 100000 个样本
# loc=均值, scale=标准差, size=样本数
samples = np.random.normal(loc=5, scale=2, size=100000)

# 期望：np.mean 算样本均值，近似理论期望
mu_hat = np.mean(samples)
print(f"期望 μ: 理论=5, 样本={mu_hat:.4f}")

# 方差：np.var(ddof=1) 算样本方差（ddof=1 是无偏估计）
# ddof=0 是总体方差（除以 n），ddof=1 是样本方差（除以 n-1）
var_hat = np.var(samples, ddof=0)
print(f"方差 σ²: 理论=4, 样本={var_hat:.4f}")

# 标准差
sigma_hat = np.std(samples, ddof=0)
print(f"标准差 σ: 理论=2, 样本={sigma_hat:.4f}")

# 验证期望的线性性质
a, b = 3, 10
transformed = a * samples + b  # aX + b
print(f"\nE[aX+b] = {np.mean(transformed):.2f}")
print(f"aE[X]+b = {a*mu_hat + b:.2f}")  # 应该相等

# 方差不线性：Var(aX+b) = a²Var(X)
print(f"\nVar(aX+b) = {np.var(transformed, ddof=0):.2f}")
print(f"a²Var(X)  = {a**2 * var_hat:.2f}")  # 应该相等

import numpy as np

np.random.seed(42)
# 抛骰子：离散均匀分布 {1,2,3,4,5,6}
dice = np.random.randint(1, 7, size=100000)
# randint(low, high, size) 抽 [low, high) 的整数
# 所以 high=7 才能包含 6

mu = np.mean(dice)
var = np.var(dice, ddof=0)
print(f"骰子期望={mu:.4f} (理论=3.5)")
print(f"骰子方差={var:.4f} (理论≈2.917)")
# 理论：E[X]=3.5, Var(X)=E[X²]-E[X]²=91/6-12.25≈2.917
