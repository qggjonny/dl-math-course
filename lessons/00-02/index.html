00-02 矩阵运算

一、点乘 — 一个人的影子有多长

画面： 正午大太阳。你站在操场上，太阳在你头顶正上方。你的影子有多长？取决于你站得多直：笔直站 → 影子为一团（最短），斜躺 → 影子拉得老长。

这就是点乘的几何含义：一个向量"投"到另一个向量上的投影长度。

$$\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + \cdots + a_nb_n = \|\mathbf{a}\|\,\|\mathbf{b}\|\,\cos\theta$$

拆开看：

  • $\|\mathbf{a}\|$：向量 $\mathbf{a}$ 的长度（从原点到箭头尖的距离）
  • $\|\mathbf{b}\|$：向量 $\mathbf{b}$ 的长度
  • $\cos\theta$：夹角的余弦。$\cos 0°=1$（同向），$\cos 90°=0$（垂直），$\cos 180°=-1$（反向）

三个情况一目了然： 同向 → 点乘最大（影子拉最长）；垂直 → 点乘 = 0（没有投影）；反向 → 点乘为负（影子"反方向"了）。

import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# np.dot(a,b)：对应位置相乘再求和 → 1×4+2×5+3×6=32
dot = np.dot(a, b)
print(f"点乘 = {dot}")

# 验证几何公式：cosθ = (a·b) / (|a|×|b|)
# np.linalg.norm 默认算 L2（欧几里得长度）
cos_theta = dot / (np.linalg.norm(a) * np.linalg.norm(b))
print(f"cosθ = {cos_theta:.3f}")  # 接近 1 → 几乎同向

二、矩阵乘法 — 流水生产线

画面： 工厂里一条生产线。第一台机器把原材料处理成半成品（$A$ 的变换），第二台机器把半成品加工成成品（$B$ 的变换）。两台机器首尾相连——这就是 $C = BA$。矩阵乘就是两张"操作手册"的接力。

怎么算： $C$ 的第 $i$ 行第 $j$ 列 = $A$ 的第 $i$ 行 与 $B$ 的第 $j$ 列 做点乘。

铁律：内维咬合。 $(m, \cancel{n}) \times (\cancel{n}, p) = (m, p)$。就像两台机器必须接口对上才能串联——$A$ 输出的宽度 = $B$ 输入的宽度。

A = np.array([[1,2,3], [4,5,6]])  # (2,3)
B = np.array([[7,8], [9,10], [11,12]])  # (3,2)：列数 3 = A 的行数 3 ✓

C = A @ B  # (2,3)×(3,2) → (2,2)
print(f"C = A@B:\n{C}")
# C[0,0]=1×7+2×9+3×11=58  C[0,1]=1×8+2×10+3×12=64
# C[1,0]=4×7+5×9+6×11=139 C[1,1]=4×8+5×10+6×12=154

三、广播 — 自动"复印"

画面： 老师发卷子。讲台上只有一份卷子，但老师把它"复印"了 40 份，每人一份——每一份的内容一模一样。广播就是 numpy 帮你自动"复印"小数组去匹配大数组的形状。

规则：从最后一维向前对齐，维度为 1 的那一维可以"复印"。

注意："复印"只是比喻——numpy 不是真的在内存里复制 40 份数据，它只是假装有那么多份。实际内存里只有一份。所以广播不浪费内存。

x = np.array([[1], [2], [3]])           # (3,1) — 3 行 1 列
y = np.array([[10, 20, 30, 40]])     # (1,4) — 1 行 4 列

# numpy 自动：x 的 1 列"复印"4 次 → (3,4)
#             y 的 1 行"复印"3 次 → (3,4)
z = x + y
print(z)
# [[11 21 31 41]   ← 1+10, 1+20, 1+30, 1+40
#  [12 22 32 42]   ← 2+10, 2+20, ...
#  [13 23 33 43]]  ← 3+10, ...
