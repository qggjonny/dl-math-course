00-02 矩阵运算

一、点乘 — 一个人的影子有多长

画面： 正午大太阳。你站在操场上，太阳在你头顶正上方。你的影子有多长？取决于你站得多直：笔直站 → 影子为一团（最短），斜躺 → 影子拉得老长。

这就是点乘的几何含义：两个向量各自有多长，乘起来，再按夹角打一个折。

也可以这样看：把 a "投"到 b 的方向上。投影怎么算？ a、投影、垂线构成直角三角形——a 是斜边，投影是邻边。直角三角形中，邻边 = 斜边 × cosθ，所以投影长度 = ‖a‖cosθ，再乘以 b 的长度。反过来也行——把 b 投到 a 上，再乘以 a 的长度。两种看法结果一样。

注意： 当 θ > 90° 时 cosθ < 0，「投影」落在 b 的反方向上，点乘为负——这说明两个向量总体上在「互相背离」。当 θ < 90° 时 cosθ > 0，投影在 b 的方向上，点乘为正——两个向量总体上在「互相帮助」。当 θ = 90° 时 cosθ = 0，投影长度为 0——两个向量垂直，谁也不影响谁。

$$\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + \cdots + a_nb_n = \|\mathbf{a}\|\,\|\mathbf{b}\|\,\cos\theta$$

为什么「分量乘完求和」=「长度×长度×cos」？

三步推导，只需要余弦定理：

第 1 步——画出三角形。 向量 $\mathbf{a}$ 和 $\mathbf{b}$ 的差 $\mathbf{a}-\mathbf{b}$ 构成三角形第三条边。余弦定理告诉我们第三条边的长度平方：

$$\|\mathbf{a} - \mathbf{b}\|^2 = \|\mathbf{a}\|^2 + \|\mathbf{b}\|^2 - 2\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

第 2 步——用代数定义展开左边。 注意：为什么 $\|\mathbf{v}\|^2 = \mathbf{v}\cdot\mathbf{v}$？靠的是勾股定理——向量 $\mathbf{v}=(v_1, v_2)$ 是两个直角边，它的长度（斜边）$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2}$，所以 $\|\mathbf{v}\|^2 = v_1^2 + v_2^2$。而点乘的代数定义是各分量相乘求和：$\mathbf{v}\cdot\mathbf{v} = v_1\times v_1 + v_2\times v_2 = v_1^2 + v_2^2$。两者相等——勾股定理把几何长度和代数分量串在了一起：

$$ \begin{aligned} \|\mathbf{a} - \mathbf{b}\|^2 &= (\mathbf{a}-\mathbf{b})\cdot(\mathbf{a}-\mathbf{b}) \\ &= \mathbf{a}\cdot\mathbf{a} + \mathbf{b}\cdot\mathbf{b} - 2(\mathbf{a}\cdot\mathbf{b}) \\ &= \|\mathbf{a}\|^2 + \|\mathbf{b}\|^2 - 2(\mathbf{a}\cdot\mathbf{b}) \end{aligned} $$

第 3 步——对比左右两边。 第 1 步和第 2 步都等于 $\|\mathbf{a}-\mathbf{b}\|^2$，所以它们相等：

$$\cancel{\|\mathbf{a}\|^2 + \|\mathbf{b}\|^2} - 2(\mathbf{a}\cdot\mathbf{b}) = \cancel{\|\mathbf{a}\|^2 + \|\mathbf{b}\|^2} - 2\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

消去相同项：

$$\mathbf{a}\cdot\mathbf{b} = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

所以「对应分量乘完求和」和「长度×长度×夹角余弦」是同一个东西——不是分别定义，是余弦定理推导出来的等价关系。

拆开看：

  • $\|\mathbf{a}\|$：向量 $\mathbf{a}$ 的长度（从原点到箭头尖的距离）
  • $\|\mathbf{b}\|$：向量 $\mathbf{b}$ 的长度
  • $\cos\theta$：夹角的余弦。$\cos 0°=1$（同向），$\cos 90°=0$（垂直），$\cos 180°=-1$（反向）

三个情况一目了然： 同向 → 点乘最大（影子拉最长）；垂直 → 点乘 = 0（没有投影）；反向 → 点乘为负（影子"反方向"了）。

import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# np.dot(a,b)：对应位置相乘再求和 → 1×4+2×5+3×6=32
dot = np.dot(a, b)
print(f"点乘 = {dot}")

# 验证几何公式：cosθ = (a·b) / (|a|×|b|)
# np.linalg.norm 默认算 L2（欧几里得长度）
cos_theta = dot / (np.linalg.norm(a) * np.linalg.norm(b))
print(f"cosθ = {cos_theta:.3f}")  # 接近 1 → 几乎同向

二、矩阵乘法 — 流水生产线

画面： 工厂里一条生产线。第一台机器把原材料处理成半成品（$A$ 的变换），第二台机器把半成品加工成成品（$B$ 的变换）。两台机器首尾相连——这就是 $C = BA$。矩阵乘就是两张"操作手册"的接力。

为什么是"行×列"？ 从流水线角度看：输入向量 $\mathbf{x}$ 先经过 $A$，第 $j$ 个中间分量 = $A$ 第 $j$ 行 · $\mathbf{x}$。然后 $B$ 拿这些中间分量做加权组合——$B$ 第 $i$ 列上的数字就是第 $i$ 个输出的各权重。两步合起来：$(BA)\mathbf{x}$ 的第 $i$ 分量 = $\sum_j B_{ij} \cdot (A$ 第 $j$ 行 · $\mathbf{x})$。去掉 $\mathbf{x}$，剩下 $(BA)_{ij} = B$ 第 $i$ 行 · $A$ 第 $j$ 列。所以"行乘列"规则不是硬记的——它是变换复合的自然结果。

怎么算： $C$ 的第 $i$ 行第 $j$ 列 = $A$ 的第 $i$ 行 与 $B$ 的第 $j$ 列 做点乘。

铁律：内维咬合。 $(m, \cancel{n}) \times (\cancel{n}, p) = (m, p)$。就像两台机器必须接口对上才能串联——$A$ 输出的宽度 = $B$ 输入的宽度。

A = np.array([[1,2,3], [4,5,6]])  # (2,3)
B = np.array([[7,8], [9,10], [11,12]])  # (3,2)：列数 3 = A 的行数 3 ✓

C = A @ B  # (2,3)×(3,2) → (2,2)
print(f"C = A@B:\n{C}")
# C[0,0]=1×7+2×9+3×11=58  C[0,1]=1×8+2×10+3×12=64
# C[1,0]=4×7+5×9+6×11=139 C[1,1]=4×8+5×10+6×12=154

三、广播 — 自动"复印"

画面： 老师发卷子。讲台上只有一份卷子，但老师把它"复印"了 40 份，每人一份——每一份的内容一模一样。广播就是 numpy 帮你自动"复印"小数组去匹配大数组的形状。

注意："复印"只是比喻——numpy 不是真的在内存里复制 40 份数据，它只是假装有那么多份。实际内存里只有一份。所以广播不浪费内存。

规则：三步判断法

两个数组能不能广播，走这三步：

  1. 从右向左对齐两个 shape
  2. 短的补 1：哪个数组维度少，在左边补 1，补到一样多
  3. 逐维比较：每一维必须相等或其中一个是 1

示例 1：成功 (3,1) + (1,4) → (3,4)

x = np.array([[1], [2], [3]])           # (3,1) — 3 行 1 列
y = np.array([[10, 20, 30, 40]])         # (1,4) — 1 行 4 列

# 对齐：      (3, 1)
#             (1, 4)
# 第1维: 1 vs 4 → 1 可以复印成 4 ✓
# 第0维: 3 vs 1 → 1 可以复印成 3 ✓
# 结果: (3,4)

z = x + y
print(z)
# [[11 21 31 41]
#  [12 22 32 42]
#  [13 23 33 43]]

示例 2：成功 — 不同 rank (3,2) + (2,) → (3,2)

一个矩阵加一个向量，能不能广播？

A = np.array([[1,2],[3,4],[5,6]])      # (3,2) — 2 维
v = np.array([10, 20])                   # (2,)  — 1 维，rank 不同

# 步骤1-2: 短的补 1
#   (3, 2)     ← A
#   (2,) → (1, 2)  ← v 左边补 1
#
# 步骤3: 逐维比较
#   第1维: 2 vs 2 → 相等 ✓
#   第0维: 3 vs 1 → 1 可以复印成 3 ✓
# 结果: (3,2)

print(A + v)
# [[11 22]
#  [13 24]
#  [15 26]]

示例 3：失败 — (3,2) + (3,) ❌

为什么这个会报错？过一遍三步：

A = np.array([[1,2],[3,4],[5,6]])      # (3,2)
w = np.array([10, 20, 30])               # (3,)

# 步骤1-2: 短的补 1
#   (3, 2)
#   (3,) → (1, 3)   ← w 左边补 1
#
# 步骤3: 逐维比较
#   第1维: 2 vs 3 → 2≠3，而且都不是 1 ❌ 炸了！
#   不用再看第0维了

# ValueError: operands could not be broadcast together

关键教训： 广播看的是每一维的数值，不是看数组里一共有几个数。(3,) 虽然长度和 (3,2) 的行数一样，但广播对齐后它变成了 (1,3)——第 1 维是 3，和对方的 2 对不上，所以炸了。

示例 4：失败 — (3,2) + (2,3) ❌

同样的 rank，但每一维都对不上：

# (3, 2)
# (2, 3)
# 第1维: 2 vs 3 → 都不等于 1 ❌
# 第0维: 3 vs 2 → 都不等于 1 ❌
# 两维都不行，彻底炸

速查表
