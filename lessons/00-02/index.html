00-02 矩阵运算

上节课知道了矩阵是「操作手册」。这节课学四种最基本的操作——点乘、矩阵乘、转置、广播。其中矩阵乘和广播是深度学习里每时每刻在用的。

一、点乘 Dot Product — 两个箭头的「投影积」

几何直觉：把一个箭头"投"到另一个箭头上，看投过去有多长。

想象你站在地面上，太阳在你头顶正上方。一根斜插在地上的棍子，它的影子有多长？影子的长度 = 棍子长度 × 阳光和棍子夹角的余弦。这就是点乘。

公式：

$$\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + \cdots + a_nb_n$$

但真正重要的是它的几何含义：

$$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\|\,\|\mathbf{b}\|\,\cos\theta$$

拆开看：

  • $\|\mathbf{a}\|$：向量 $\mathbf{a}$ 的长度（从原点到箭头尖的距离）
  • $\|\mathbf{b}\|$：向量 $\mathbf{b}$ 的长度
  • $\cos\theta$：两个箭头夹角的余弦。$\cos 0° = 1$（同向），$\cos 90° = 0$（垂直），$\cos 180° = -1$（反向）

三种情况一目了然：

  • 同向（$\theta = 0°$）→ $\cos\theta = 1$ → 点乘最大 → 两个箭头完全"一致"
  • 垂直（$\theta = 90°$）→ $\cos\theta = 0$ → 点乘 = 0 → 两个箭头"无关"
  • 反向（$\theta = 180°$）→ $\cos\theta = -1$ → 点乘为负 → 两个箭头"对抗"
深度学习里点乘无处不在： 注意力机制（Attention）里，Query 和 Key 做点乘来判断「这句话里哪些词和我有关」。Self-Attention 的本质就是一句话里所有词两两之间做点乘。 
import numpy as np

a = np.array([1, 2, 3])  # 向量 a
b = np.array([4, 5, 6])  # 向量 b

# np.dot(a, b) 计算点乘：1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
# 等价写法: a @ b 或 np.inner(a, b)
dot = np.dot(a, b)
print(f"点乘: {dot}")  # 输出: 32

# 验证几何公式：cosθ = (a·b) / (|a| × |b|)
# np.linalg.norm 默认算 L2 范数（向量的长度）
len_a = np.linalg.norm(a)  # sqrt(1²+2²+3²) = sqrt(14) ≈ 3.742
len_b = np.linalg.norm(b)  # sqrt(4²+5²+6²) = sqrt(77) ≈ 8.775
cos_theta = dot / (len_a * len_b)  # 32 / (3.742 × 8.775) ≈ 0.975
print(f"cosθ = {cos_theta:.3f}")  # 接近 1，说明两个向量几乎同向

二、矩阵乘法 — 两本操作手册"接力"

上一课的 $Wx$ 是矩阵乘向量。这节课看矩阵乘矩阵。

如果你先做变换 $A$，再做变换 $B$，总效果等价于一个「复合变换」$C = BA$。这里的 $BA$ 就是矩阵乘法。

怎么算：

$$C_{ij} = \sum_k A_{ik} \cdot B_{kj}$$

翻译成人话：$C$ 的第 $i$ 行第 $j$ 列 = $A$ 的第 $i$ 行 与 $B$ 的第 $j$ 列 做点乘。

铁律：内维必须匹配。 $A$ 是 $(m,n)$，$B$ 必须是 $(n,p)$。$A$ 的列数 = $B$ 的行数 = 做点乘的长度。

直觉记忆： $(2, \cancel{3}) \times (\cancel{3}, 4) = (2, 4)$。内维相消，外维相乘。 
import numpy as np

A = np.array([[1, 2, 3],    # 形状 (2, 3)
              [4, 5, 6]])
B = np.array([[7, 8],         # 形状 (3, 2)
              [9, 10],
              [11, 12]])

# A @ B = (2,3) × (3,2) → (2,2)
# C[0,0] = A 第 0 行 · B 第 0 列 = [1,2,3] · [7,9,11] = 7+18+33 = 58
# C[0,1] = A 第 0 行 · B 第 1 列 = [1,2,3] · [8,10,12] = 8+20+36 = 64
# C[1,0] = A 第 1 行 · B 第 0 列 = [4,5,6] · [7,9,11] = 28+45+66 = 139
# C[1,1] = A 第 1 行 · B 第 1 列 = [4,5,6] · [8,10,12] = 32+50+72 = 154
C = A @ B
print(f"矩阵乘结果:\n{C}")
print(f"形状: {C.shape}")  # 输出: (2, 2)

三、转置 — 行列互换

$$(A^T)_{ij} = A_{ji}$$

第 $i$ 行第 $j$ 列变成第 $j$ 行第 $i$ 列。$(m,n)$ → $(n,m)$。

比如 $[1, 2, 3]^T$ 变成 $\begin{bmatrix}1\\2\\3\end{bmatrix}$：行向量变列向量。

四、广播 Broadcasting — numpy 的"自动扩展"

形状不同的数组做加减乘除时，numpy 自动把小数组"拉伸"到和大数组一样。

规则：从最后一维开始向前对齐，维度为 1 的可以扩展。

比如：(3, 1) + (1, 4) → (3, 4)。两个都是 1 的维度各自扩展到对方的大小。

广播不是复制数据——它只是假装有那么多份，实际内存里只有一份。所以不浪费内存。

import numpy as np

# x 形状 (3,1)：3 行 1 列
x = np.array([[1], [2], [3]])
# y 形状 (1,4)：1 行 4 列
y = np.array([[10, 20, 30, 40]])

# 加法：numpy 自动 
#   x 的 1 列「假装」重复 4 次 → (3,4)
#   y 的 1 行「假装」重复 3 次 → (3,4)
# 然后逐元素相加
z = x + y
print(z)
# 输出:
# [[11 21 31 41]    ← 第一行：1+10, 1+20, 1+30, 1+40
#  [12 22 32 42]    ← 第二行：2+10, 2+20, ...
#  [13 23 33 43]]   ← 第三行：3+10, 3+20, ...
