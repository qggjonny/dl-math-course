00-02 矩阵运算

一、点乘 (Dot Product)

几何直觉：两个向量在同一方向上的投影长度。

$$\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + \cdots + a_nb_n = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

$\cos\theta = 1$（同向）→ 点乘最大；$\cos\theta = -1$（反向）→ 点乘最小；$\cos\theta = 0$（垂直）→ 点乘 = 0。

二、矩阵乘法

$$C_{ij} = \sum_k A_{ik} \cdot B_{kj}$$

$C$ 的第 $i$ 行第 $j$ 列 = $A$ 的第 $i$ 行 与 $B$ 的第 $j$ 列的点乘。

铁律：$(m \times n) \times (n \times p) \to (m \times p)$。内维必须匹配。

三、转置

$$(A^T)_{ij} = A_{ji}$$

行变列，列变行。$(m \times n)^T \to (n \times m)$。

四、Hadamard 积（逐元素乘）

$$(A \odot B)_{ij} = A_{ij} \times B_{ij}$$

形状必须完全一致。深度学习里到处是它：dropout 掩码、attention mask、门控机制。

五、广播 (Broadcasting)

不同形状的数组做运算时，numpy 自动"拉伸"小数组。规则：从最后一维向前对齐，维度为 1 的可以扩展。

(3, 1) + (1, 4) → (3, 4)——两个都从 1 维扩展。

🖥️ 代码

import numpy as np

# 点乘：对应位置相乘再求和
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
dot = np.dot(a, b)  # 1×4 + 2×5 + 3×6 = 32
print(f"点乘: {dot}")

# 矩阵乘：A(2,3) × B(3,2) → (2,2)
A = np.array([[1,2,3],[4,5,6]])  # 形状 (2,3)
B = np.array([[7,8],[9,10],[11,12]]) # 形状 (3,2)
C = A @ B  # @ 是矩阵乘法的运算符
print(f"矩阵乘:\n{C}\n形状={C.shape}")  # (2,2)

# 转置：行变列，列变行
At = A.T  # (2,3) → (3,2)
print(f"转置:\n{At}\n形状={At.shape}")

# Hadamard 积：逐元素相乘，形状必须一致
H = A * np.array([[2,2,2],[3,3,3]])  # 形状=(2,3)
print(f"Hadamard:\n{H}")

# 广播：(3,1) + (1,4) → (3,4)
x = np.array([[1],[2],[3]])    # 形状 (3,1)
y = np.array([[10,20,30,40]])  # 形状 (1,4)
z = x + y  # numpy 自动广播：x 重复 4 列，y 重复 3 行
print(f"广播结果:\n{z}\n形状={z.shape}")  # (3,4)
