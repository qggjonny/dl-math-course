00-11 导数与偏导数

一、导数：山路的坡度

画面： 你开车走盘山公路。仪表盘上的坡度计指着 15°。如果你继续往前开 1 公里，高度大约会上升 $\tan(15°)\times 1\text{km} \approx 270\text{m}$。

导数就是这个「坡度」——在某一点，你往前走一点点，高度变化的速率。

$$f'(x) = \lim_{\epsilon \to 0} \frac{f(x+\epsilon) - f(x)}{\epsilon}$$

逐符号拆开：

  • $f(x+\epsilon)$：你现在在 $x$ 位置，往前走一丁点 $\epsilon$ 后到达的新位置上的函数值
  • $f(x+\epsilon) - f(x)$：往前走 $\epsilon$ 后，函数值变化了多少（上升、下降、或不变）
  • 除以 $\epsilon$：归一化——不管走了多远，算出"每走 1 单位"的变化率
  • $\lim_{\epsilon \to 0}$：$\epsilon$ 无限趋近 0——我要的是这一点的瞬时坡度，不是一段路的平均坡度

回到开车的比喻：导数 > 0 = 正在上坡（往前走高度会增加），导数 < 0 = 正在下坡，导数 = 0 = 到了山顶或山谷（坡度为零）。

从定义推导求导规则

定义是好，但每次都用极限算太慢了。从定义出发，推几个最常用的规则。

$f(x) = x^2$ 的导数。 代入定义：

$$\begin{aligned} f'(x) &= \lim_{\epsilon \to 0} \frac{(x+\epsilon)^2 - x^2}{\epsilon} \\[4pt] &= \lim_{\epsilon \to 0} \frac{x^2 + 2x\epsilon + \epsilon^2 - x^2}{\epsilon} \\[4pt] &= \lim_{\epsilon \to 0} \frac{2x\epsilon + \epsilon^2}{\epsilon} = \lim_{\epsilon \to 0} (2x + \epsilon) = 2x \end{aligned}$$

所以 $(x^2)' = 2x$。每步做了什么：① 展开平方 ② 消掉 $x^2$ ③ 提出 $\epsilon$ 消掉 ④ $\epsilon \to 0$ 时 $\epsilon$ 项消失。

$f(x) = x^n$ 的通式（幂函数求导）： 还是走定义，但这次 $n$ 可以是任意正整数。关键一步是把 $(x+\epsilon)^n$ 展开——这叫二项式展开。别被名字吓到，直接从 $n=3$ 走一遍，再推广。

先看 $n=3$：完全展开，逐项看清楚

$(x+\epsilon)^3 = (x+\epsilon)(x+\epsilon)(x+\epsilon)$。老老实实乘开：

$$\begin{aligned} (x+\epsilon)^3 &= (x+\epsilon)(x+\epsilon)(x+\epsilon) \\[4pt] &= (x^2 + 2x\epsilon + \epsilon^2)(x+\epsilon) \\[4pt] &= x^3 + x^2\epsilon + 2x^2\epsilon + 2x\epsilon^2 + x\epsilon^2 + \epsilon^3 \\[4pt] &= x^3 + 3x^2\epsilon + 3x\epsilon^2 + \epsilon^3 \end{aligned}$$

整理后四个项：

项系数$\epsilon$ 的次方
$x^3$1$\epsilon^0$（没有 $\epsilon$）
$3x^2\epsilon$3$\epsilon^1$
$3x\epsilon^2$3$\epsilon^2$
$\epsilon^3$1$\epsilon^3$

系数 1, 3, 3, 1——正好是杨辉三角第 3 行。这不是巧合。

推广到一般的 $n$——「选盒子」的直觉

先回到 $n=3$，但这次不走代数展开，而是用组合视角——看系数 1, 3, 3, 1 到底从哪来。

把 $(x+\epsilon)^3 = (x+\epsilon)(x+\epsilon)(x+\epsilon)$ 想象成三个并排的盒子：

$(x+\epsilon)$   $(x+\epsilon)$   $(x+\epsilon)$
盒子1       盒子2       盒子3

展开这个乘积，就是要从每个盒子里选一样东西（要么选 $x$，要么选 $\epsilon$），然后把选出来的三个东西乘起来。所有可能的选法：

选法盒子1盒子2盒子3乘积几个 ε
1$x$$x$$x$$x^3$0
2$\epsilon$$x$$x$$x^2\epsilon$1
3$x$$\epsilon$$x$$x^2\epsilon$1
4$x$$x$$\epsilon$$x^2\epsilon$1
5$\epsilon$$\epsilon$$x$$x\epsilon^2$2
6$\epsilon$$x$$\epsilon$$x\epsilon^2$2
7$x$$\epsilon$$\epsilon$$x\epsilon^2$2
8$\epsilon$$\epsilon$$\epsilon$$\epsilon^3$3

合并同类项：

  • $x^3$：只有选法 1（三个盒子都选 $x$）→ 1 种选法，系数 = 1
  • $x^2\epsilon$：选法 2、3、4（ε 可以来自盒子1、盒子2、或盒子3）→ 3 种选法，系数 = 3
  • $x\epsilon^2$：选法 5、6、7（挑两个盒子选 ε）→ 3 种选法，系数 = 3
  • $\epsilon^3$：只有选法 8（三个盒子都选 ε）→ 1 种选法，系数 = 1

杨辉三角第 3 行的 1, 3, 3, 1，本质就是「从 3 个盒子里挑 0、1、2、3 个选 ε」的选法数。

推广到 $n$ 个盒子——$(x+\epsilon)^n$ 是 $n$ 个 $(x+\epsilon)$ 连乘：

$(x+\epsilon)$   $(x+\epsilon)$   $(x+\epsilon)$   $\cdots$   $(x+\epsilon)$
盒子1       盒子2       盒子3       …       盒子n

每个盒子选 $x$ 或 $\epsilon$，乘起来。按「选了几个 ε」分类：

  • 0 个 ε（全选 $x$）： 只有 1 种选法 → 系数 = 1，这一项是 $x^n$
  • 1 个 ε： 从 $n$ 个盒子里挑 1 个选 ε，有 $n$ 种挑法 → 系数 = $n$，这一项是 $n x^{n-1}\epsilon$
  • 2 个 ε： 从 $n$ 个盒子里挑 2 个选 ε → 系数是某个数，但这一项带 $\epsilon^2$
  • $\vdots$
  • $n$ 个 ε（全选 $\epsilon$）： 只有 1 种选法 → 系数 = 1，这一项是 $\epsilon^n$

我们不需要知道挑 2 个、3 个……的系数具体是多少——只需知道它们都带着 $\epsilon^2$ 或更高次方。这在下一步导数计算中会自动消掉。

补充：组合数——从 n 个里挑 k 个

前面说「不需要知道挑 2 个、3 个的系数具体是多少」——那是针对导数推导而言（反正都带 $\epsilon^2$ 会被消掉）。但「从 $n$ 个里挑 $k$ 个」这个数本身太常用了，值得单独讲清楚。

先补一句前面没点破的话：每个盒子里只有两件东西——$x$ 和 $\epsilon$。展开 $(x+\epsilon)^n$ 时，每个盒子必须拿一件。所以「挑 $k$ 个盒子选 $\epsilon$」=「从 $n$ 个盒子这个整体里，选出 $k$ 个」，剩下 $n-k$ 个自动选 $x$。

组合数的定义：从 $n$ 个互不相同的东西里，选出 $k$ 个（不计顺序），选法总数记作 $\binom{n}{k}$，读作「n 选 k」或「n 取 k」，也写作 $C(n,k)$。 $$\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$$ 其中 $n!$ 是阶乘（00-02 提过：$n! = n\times(n-1)\times\cdots\times1$，比如 $4!=24$）。

定义里两个关键词一个都不能漏：互不相同（盒子 1、盒子 2……是不同的盒子，不能混淆）和不计顺序（只问「选了哪几个」，不问「先选谁后选谁」）。第二个词是组合数最容易乱的根源，下面专门拆开讲。

先搞清楚：顺序到底重不重要？

看一个具体例子——3 个同学 A、B、C，选 2 个人。

情形一（顺序重要）：选一个正班长 + 一个副班长。先选正班长（A、B、C 三选一，3 种），再选副班长（剩下 2 人里选，2 种），共 $3\times2 = 6$ 种：

(A,B)  (A,C)  (B,A)  (B,C)  (C,A)  (C,B)

注意 (A,B) 和 (B,A) 是两种不同结果——A 当正班长、B 当副班长，跟反过来，班子不一样。

情形二（顺序不重要）：选两个「代表」，不分正副。这时 (A,B) 和 (B,A) 是同一种结果（都是 A、B 两个人）。6 种里每两个人被重复算了 2 遍，真正不同的选法只剩：

{A,B}  {A,C}  {B,C}

共 3 种。从 6 变 3，就是除以 2——因为选出来的 2 个人内部有 $2! = 2$ 种排队顺序（AB 和 BA），排列把它们当成 2 种，组合只看成 1 种。

这两个概念都有名字：顺序重要叫「排列」（$3\times2=6$ 种），顺序不重要叫「组合」（$6\div2=3$ 种）。组合数 = 排列数 ÷ 内部顺序数。我们的盒子问题是组合——下面会确认。

公式怎么来的

把上面的例子推广到一般情况：从 $n$ 个里选 $k$ 个。

第一步，先算排列（顺序重要）：第 1 个位置 $n$ 种选法，第 2 个位置 $n-1$ 种……一直选到第 $k$ 个位置 $n-k+1$ 种。连乘：

$$\underbrace{n \times (n-1) \times \cdots \times (n-k+1)}_{k\ \text{个因子}}$$

第二步，除以内部顺序数：选出来的 $k$ 个东西，它们之间有 $k! = k\times(k-1)\times\cdots\times1$ 种排队顺序，而组合不区分这些顺序——所以每种组合被排列重复算了 $k!$ 遍，除回去：

$$\binom{n}{k} = \frac{\overbrace{n\times(n-1)\times\cdots\times(n-k+1)}^{k\ \text{个因子}}}{k!}$$

这个式子就是 $\dfrac{n!}{k!(n-k)!}$（分子分母同乘 $(n-k)!$ 就补齐成 $n!$）。手算口诀：$n$ 往下连乘 $k$ 个，再除以 $k!$。比如 $\binom{5}{2} = \dfrac{5\times4}{2\times1} = 10$。

回到盒子：为什么是「组合」不是「排列」

因为展开时我们只关心「哪几个盒子贡献了 $\epsilon$」，不关心选的先后顺序。盒子 1、2 选 $\epsilon$ 和盒子 2、1 选 $\epsilon$，乘出来的都是 $x^{n-2}\epsilon^2$——同一个结果，只该算一次。所以系数 = 组合数 $\binom{n}{k}$。

拿 $n=3$ 跟前面手算的 8 种选法对一遍：

$k$（几个 $\epsilon$）含义组合数值
0三个盒子都不选 $\epsilon$（全选 $x$）$\binom{3}{0}$1
1三个里挑 1 个选 $\epsilon$$\binom{3}{1}=\frac{3}{1!}$3
2三个里挑 2 个选 $\epsilon$$\binom{3}{2}=\frac{3\times2}{2!}$3
3三个盒子都选 $\epsilon$$\binom{3}{3}$1

得到 1, 3, 3, 1——正是前面 8 种选法合并同类项后的系数，也是杨辉三角第 3 行。

杨辉三角 = 所有组合数排成的三角形

把 $\binom{n}{k}$ 按 $n$（行）、$k$（列）排起来，行和列都从 0 数起：

n=0:       1
n=1:      1  1
n=2:     1  2  1
n=3:    1  3  3  1
n=4:   1  4  6  4  1
n=5:  1  5 10 10  5  1

第 $n$ 行从左到右就是 $\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$。每一行相邻两数相加得到下一行的数（比如第 3 行的 $1+3=4$ 就是第 4 行的 $\binom{4}{1}$）——这是组合数的一条恒等式 $\binom{n}{k}+\binom{n}{k+1}=\binom{n+1}{k+1}$，先记住「加出来的」这个画面，证明留到需要时再展开。

二项式定理——把结论写成一条公式

有了组合数，二项式展开就能写成紧凑的一条：

$$(a+b)^n = \binom{n}{0}a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b^2 + \cdots + \binom{n}{n}b^n = \sum_{k=0}^{n}\binom{n}{k}\,a^{n-k}b^k$$

代入 $a=x$、$b=\epsilon$，就是 $(x+\epsilon)^n = \sum_{k=0}^{n}\binom{n}{k}x^{n-k}\epsilon^k$。系数 $\binom{n}{k}$ 的含义一句话说清：展开时，选 $k$ 个因子贡献 $\epsilon$（其余贡献 $x$）的选法数。

一个自然的疑问：盒子要是装了三件东西怎么办？

好问题。如果每个盒子里有 3 件东西（比如展开 $(x+y+z)^n$），就要分两步选：先选哪些盒子贡献 $x$（$\binom{n}{a}$ 种），再在剩下的盒子里选哪些贡献 $y$（$\binom{n-a}{b}$ 种），剩下自动是 $z$。于是 $x^a y^b z^c$（$a+b+c=n$）的系数是：

$$\binom{n}{a}\binom{n-a}{b} = \frac{n!}{a!\,b!\,c!}$$

这叫多重组合数。二项式是它「只有 2 组」的特例（$b=n-a$，退化成 $\frac{n!}{a!(n-a)!}=\binom{n}{a}$）。

但现在不用管它。推导导数只需要二项式——每个盒子 2 件东西，$\binom{n}{k}$ 足够。先把「两件东西 + 组合数」这个最常用的情形吃透，多项的情形是它的自然延伸，用到时（概率里的多项分布）再展开不迟。

代码验证

# 用 Python 的 math.comb 算组合数，验证杨辉三角
# 导入 math 模块——comb(n,k) 就是组合数 C(n,k)
import math

# n=3 的展开系数：C(3,0), C(3,1), C(3,2), C(3,3)
# 应该等于 [1, 3, 3, 1]——和前面手算的 8 种选法一致
coeffs = [math.comb(3, k) for k in range(4)]
print(f"n=3 的系数: {coeffs}")

# n=4 的展开系数——杨辉三角第 4 行，应等于 [1, 4, 6, 4, 1]
coeffs4 = [math.comb(4, k) for k in range(5)]
print(f"n=4 的系数: {coeffs4}")

print(f"(x+y+z)^3 里 x·y·z 的系数 = {coef:.0f}")

组合数后面会在概率课（二项分布 $\binom{n}{k}p^k(1-p)^{n-k}$）里反复用到——这里的「选盒子」直觉到时候直接复用。

回到导数——走三步

① 展开： $(x+\epsilon)^n = x^n + n x^{n-1}\epsilon + (\text{带 }\epsilon^2\text{ 及更高次的项})$

② 代入差商：

$$\begin{aligned} \frac{f(x+\epsilon) - f(x)}{\epsilon} &= \frac{(x+\epsilon)^n - x^n}{\epsilon} \\[4pt] &= \frac{(x^n + n x^{n-1}\epsilon + \epsilon^2\!\cdot\!(\cdots)) - x^n}{\epsilon} \\[4pt] &= \frac{n x^{n-1}\epsilon + \epsilon^2\!\cdot\!(\cdots)}{\epsilon} \\[4pt] &= n x^{n-1} + \epsilon \!\cdot\! (\cdots) \end{aligned}$$

每步做了什么：$x^n$ 和 $-x^n$ 抵消；第一项 $n x^{n-1}\epsilon$ 除以 $\epsilon$ 得到 $n x^{n-1}$（干净！）；后面所有带 $\epsilon^2$ 及更高次的项，除以 $\epsilon$ 后还剩至少一个 $\epsilon$ 因子。

③ 取极限 $\epsilon \to 0$： 所有还带着 $\epsilon$ 的项全部归零——只留下干干净净的 $n x^{n-1}$。

$$\boxed{(x^n)' = n \cdot x^{n-1}}$$

用 $n=3$ 验证：$(x^3)' = 3x^2$。用 $n=2$ 验证：$(x^2)' = 2x$——和前面一步步手算的结果一致 ✓。$(x)' = 1 \cdot x^0 = 1$，$(5)' = 0$（常数相当于 $x^0$，导数是 $0 \cdot x^{-1} = 0$——水平线没有坡度）。

🔗 求和与常数倍的规则： 求导是线性运算。
  • $(f+g)' = f' + g'$ —— 和的导数 = 导数之和
  • $(c \cdot f)' = c \cdot f'$ —— 常数可以提到外面

为什么分两条？ 从和的规则其实能推出正整数倍——$(2f)' = (f+f)' = f'+f' = 2f'$，$(3f)' = 3f'$，以此类推。但 $c$ 如果是 $\frac{1}{2}$、$\sqrt{2}$、$\pi$，你不能把 $c \cdot f$ 写成「$c$ 个 $f$ 相加」。常数倍规则直接从极限定义来——$c$ 可以提到极限符号外面，对任意实数 $c$ 都成立。两条合在一起说了一件事：求导是线性运算。

这意味着 $(3x^2 + 2x + 5)' = 3 \cdot 2x + 2 \cdot 1 + 0 = 6x + 2$。逐项求导再拼起来就行。

代码验证：数值微分

定义里的 $\lim_{\epsilon \to 0}$ 在计算机上没法真正做到——但取一个很小的 $\epsilon$（比如 $10^{-5}$），差商 $\frac{f(x+\epsilon)-f(x)}{\epsilon}$ 会非常接近真实导数。这叫数值微分。

# 00-11 第一步：数值微分——用定义验证 f(x)=x² 的导数 f'(x)=2x
# 导入numpy，别名np（本例主要用于规范，实际未用numpy功能）
import numpy as np

# 定义函数 f(x) = x²
def f(x):
    # docstring文档字符串：说明这个函数做什么
    """f(x) = x²"""
    # **是幂运算：x**2 = x²，返回x的平方
    return x ** 2

# 数值微分函数，参数：函数f、求导点x、微小步长ε（默认10⁻⁵）
def numerical_derivative(f, x, eps=1e-5):
    # 用极限定义近似：f'(x) ≈ (f(x+ε)−f(x)) / ε
    """用定义算 f'(x)：取一个很小的 eps，算差商"""
    # 前向差商：(f(x+ε)−f(x))/ε，ε越小越精确
    return (f(x + eps) - f(x)) / eps

# 在 x=1, 2, 3 处验证——理论值：f'(x) = 2x
# 循环测试3个点：x=1→导数值=2, x=2→4, x=3→6
for x in [1, 2, 3]:
    num = numerical_derivative(f, x)      # 调用数值微分，传入f和当前x → 数值近似导数
    # 理论值：幂函数求导法则 (x²)' = 2x
    exact = 2 * x
# f-string: {x}=x值, {num:.6f}=数值结果保留6位, {exact}=理论值, {abs(...):.2e}=误差用科学记数法2位
    print(f"f'({x})  数值={num:.6f}  理论={exact}  误差={abs(num-exact):.2e}")

误差约 $10^{-5}$——和 $\epsilon$ 同一量级。定义不是空洞的，是能在计算机上跑通的。

二、偏导数：只看一个踏板

如果函数有两个输入 $f(x,y)$——就像开车同时有油门和方向盘。偏导数就是问：「我只踩油门（$x$ 变），方向盘不动（$y$ 不变），高度变化多快？」

$$\frac{\partial f}{\partial x} = \lim_{\epsilon \to 0} \frac{f(x+\epsilon, y) - f(x, y)}{\epsilon}$$

$\partial$（读作 "round d"）这个符号只是提醒你：不止一个变量，但我现在只看这一个。

偏导数的计算规则——简单到离谱： 对 $x$ 求偏导时，把 $y$ 当成常数就行（就像把 $y$ 当成数字 5）。

例子：$f(x,y) = x^2 + 3xy + y^3$。

  • 对 $x$ 求偏导：$\frac{\partial f}{\partial x} = 2x + 3y + 0$。$y^3$ 看成常数 → 导数 = 0
  • 对 $y$ 求偏导：$\frac{\partial f}{\partial y} = 0 + 3x + 3y^2$。$x^2$ 看成常数 → 导数 = 0

    """对 x 的偏导：只动 x，y 不动"""
    # 只改变x（加ε），y保持不变 → 数值近似偏导
    return (f(x + eps, y) - f(x, y)) / eps

# 对y的偏导数
def partial_y(f, x, y, eps=1e-5):
    # 偏导数定义：∂f/∂y = lim_{ε→0} (f(x,y+ε)−f(x,y))/ε
    """对 y 的偏导：只动 y，x 不动"""
    # 只改变y（加ε），x保持不变 → 数值近似偏导
    return (f(x, y + eps) - f(x, y)) / eps

# 在点 (2, 3) 验证——把x₀=2, y₀=3代入偏导公式
# 测试点：x₀=2.0, y₀=3.0（浮点数）
x0, y0 = 2.0, 3.0
# 理论：∂f/∂x = 2x + 3y（对x求偏导，y当常数）→ 2*2 + 3*3 = 4+9 = 13
# 理论：∂f/∂y = 3x + 3y²（对y求偏导，x当常数）→ 3*2 + 3*9 = 6+27 = 33
px_num = partial_x(g, x0, y0)             # 数值计算 ∂g/∂x 在 (2,3) 的值 → 应≈13.0
py_num = partial_y(g, x0, y0)             # 数值计算 ∂g/∂y 在 (2,3) 的值 → 应≈33.0
# :.6f=保留6位小数，误差约10⁻⁵量级
print(f"∂f/∂x  数值={px_num:.6f}  理论=13")
# 数值结果和理论值非常接近
print(f"∂f/∂y  数值={py_num:.6f}  理论=33")

🔗 在线运行

把 $y$ 当成常数——这个规则不是死记的，是「只动 $x$，$y$ 不动」这个定义的直接结果。

三、梯度：把所有偏导数打包

偏导数一个个算完之后，把它们装进一个向量里——这就是梯度：

$$\nabla f = \begin{bmatrix} \frac{\partial f}{\partial x} \\[4pt] \frac{\partial f}{\partial y} \end{bmatrix}$$

对 $f(x,y) = x^2 + 3xy + y^3$，梯度 = $\begin{bmatrix} 2x+3y \\ 3x+3y^2 \end{bmatrix}$。

在点 $(2,3)$ 处，梯度 = $\begin{bmatrix} 13 \\ 33 \end{bmatrix}$。

梯度的几何含义是下一课（00-12）的主题——这里先知道它就是把所有偏导打包成一个向量。
