00-04 导数、偏导数、梯度

一、导数：变化率

几何直觉：曲线在某点的切线斜率。

$$f'(x) = \lim_{\epsilon \to 0} \frac{f(x+\epsilon) - f(x)}{\epsilon}$$

切线向上斜（导数 > 0）→ 往右走函数变大。这就是梯度下降的基础：沿导数反方向走，函数值下降。

二、偏导数

多变量函数 $f(x,y)$，固定其他变量，只对一个变量求导。

$$\frac{\partial f}{\partial x} = \lim_{\epsilon \to 0} \frac{f(x+\epsilon, y) - f(x, y)}{\epsilon}$$

三、梯度：所有偏导数的向量

$$\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \cdots, \frac{\partial f}{\partial x_n}\right]$$

几何直觉：指向函数上升最快的方向。 梯度方向 = 最陡上坡。反方向 = 最陡下坡。梯度大小 = 坡度有多陡。

梯度下降 = 沿梯度反方向走一小步，反复。 $$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$ $\eta$ 是学习率，控制每步大小。

🖥️ 代码

import numpy as np

# 中央差分求导：f'(x) ≈ (f(x+eps) - f(x-eps)) / (2*eps)
# 精度 O(eps²)，优于单边差分的 O(eps)
def numerical_grad(f, x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

# f(x)=x²，理论导数 f'(x)=2x
def f(x):
    return x ** 2

for x in [1, 2, 3]:
    num = numerical_grad(f, x)
    theory = 2 * x
    print(f"f'({x}) 数值={num:.5f} 理论={theory}")

# 梯度下降：找 f(x)=x²-4x+4 的最小值（x=2）
x = 0.0             # 初始值
lr = 0.1            # 学习率 η
for step in range(30):
    grad = 2*x - 4     # f'(x) = 2x - 4
    x = x - lr * grad  # 沿反方向走
    if step % 5 == 0:
        print(f"第{step:2d}步: x={x:.4f}")  # 0→2
