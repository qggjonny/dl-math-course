00-04 导数、偏导数、梯度

这节是深度学习的心脏——训练的本质就是沿着梯度反方向走下去。

一、导数：曲线的「坡度」

画面： 你开车上山。看仪表盘上的坡度计：正在 15° 上坡。如果你现在踩油门往山上再开 1 公里，高度大约上升 $\tan(15°) \times 1\text{km} \approx 270\text{m}$。

导数就是这个「坡度」——在某一点，函数值随着输入变化的瞬时比率。

$$f'(x) = \lim_{\epsilon \to 0} \frac{f(x+\epsilon) - f(x)}{\epsilon}$$

拆开看：

  • 分子 $f(x+\epsilon) - f(x)$：往前走一丁点，函数值变了多少
  • 分母 $\epsilon$：走了多远
  • 比值 = 每走 1 单位，函数值变多少 = 坡度
  • $\lim_{\epsilon \to 0}$：$\epsilon$ 无限趋近 0，得到瞬时坡度（不是一段路的平均坡度）
导数 > 0 → 切线向上斜 → 往右走函数变大。
导数 < 0 → 切线向下斜 → 往右走函数变小。
导数 = 0 → 切线水平 → 局部极值点（山顶或山谷）。

二、偏导数：多变量的坡度

如果函数有两个输入 $f(x,y)$，你只问「$x$ 方向上的坡度是多少（$y$ 先不动）」，这就是偏导数。

$$\frac{\partial f}{\partial x} = \lim_{\epsilon \to 0} \frac{f(x+\epsilon, y) - f(x, y)}{\epsilon}$$

$\partial$（读"round"）这个符号只是提醒你「不止一个变量」。算法上跟普通导数一模一样。

三、梯度：所有方向的坡度合到一个向量里

$$\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right]$$

核心直觉：梯度向量指向函数值上升最快的方向。它的每个分量告诉你「沿着这个坐标轴走，坡有多陡」；合在一起，它指向全局最陡的上坡方向。

梯度下降 = 沿着梯度反方向走一小步，不断重复。 $$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$
  • $\theta_t$：当前的参数位置
  • $\nabla f(\theta_t)$：当前位置的梯度（最陡上坡方向）
  • 负号：因为我们想下降，所以反着走
  • $\eta$（学习率）：走多大步。太大 → 可能跳过最小值；太小 → 收敛太慢

🖥️ 代码：从手算导数到梯度下降

import numpy as np

# ===== 1. 数值微分：验证链式法则的手算 =====
def numerical_grad(f, x, eps=1e-5):
    """中央差分法求 f 在 x 处的导数
    (f(x+eps) - f(x-eps)) / (2*eps) 
    精度 O(eps²)，比单边差分的 O(eps) 高一个数量级
    """
    return (f(x + eps) - f(x - eps)) / (2 * eps)

# 测试 f(x) = x² → f'(x) = 2x
def square(x):
    return x ** 2  # x 的平方

for x in [1, 2, 3]:
    num = numerical_grad(square, x)  # 数值近似
    theory = 2 * x                      # 理论 f'(x) = 2x
    print(f"f'({x}) 数值={num:.6f}  理论={theory}")

# ===== 2. 梯度下降：找 f(x)=x²-4x+4 的最小值 =====
# 理论最小值在 x=2（f'(x)=2x-4=0 → x=2）
x = 0.0                    # 从 0 出发
lr = 0.1                   # 学习率 η
print(f"\n出发: x={x:.1f}")
for step in range(30):
    grad = 2*x - 4          # f'(x) = 2x - 4
    x = x - lr * grad       # 沿梯度反方向走
    if step % 5 == 0:
        print(f"  第{step:2d}步: x={x:.4f}  grad={grad:.4f}")
print(f"  最终: x={x:.4f} (理论=2)")
# x 从 0 逐渐滑到 2，梯度也从 -4 逐渐变成 0
