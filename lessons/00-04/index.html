00-04 导数、偏导数、梯度

一、导数：山路的坡度

画面： 你开车走盘山公路。仪表盘上的坡度计指着 15°。如果你继续往前开 1 公里，高度大约会上升 $\tan(15°)\times 1\text{km} \approx 270\text{m}$。

导数就是这个「坡度」——在某一点，你往前走一点点，高度变化的速率。

$$f'(x) = \lim_{\epsilon \to 0} \frac{f(x+\epsilon) - f(x)}{\epsilon}$$

逐符号拆开：

  • $f(x+\epsilon)$：你现在在 $x$ 位置，往前走一丁点 $\epsilon$ 后到达的新位置上的函数值
  • $f(x+\epsilon) - f(x)$：往前走 $\epsilon$ 后，函数值变化了多少（可能是上升、下降、或不变）
  • 除以 $\epsilon$：归一化——不管走了多远，算出"每走 1 单位"的变化率
  • $\lim_{\epsilon \to 0}$：$\epsilon$ 无限趋近 0——我要的是这一点的瞬时坡度，不是一段路的平均坡度

回到开车的比喻：导数 > 0 = 正在上坡（往前走高度会增加），导数 < 0 = 正在下坡，导数 = 0 = 到了山顶或山谷（坡度为零）。

二、偏导数：只看一个踏板

如果函数有两个输入 $f(x,y)$——就像开车同时有油门和方向盘。偏导数就是问：「我只踩油门（$x$ 变），方向盘不动（$y$ 不变），高度变化多快？」

$$\frac{\partial f}{\partial x} = \lim_{\epsilon \to 0} \frac{f(x+\epsilon, y) - f(x, y)}{\epsilon}$$

$\partial$（读作 "round d"）这个符号只是提醒你：不止一个变量，但我现在只看这一个。

三、梯度：最陡的方向

把所有偏导数拼成一个向量——这就是梯度。

$$\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right]$$

核心直觉：梯度向量指向函数值上升最快的方向。

画面： 你站在山谷里，四周都是坡。你原地转一圈，总有一个方向是最陡的上坡——那就是梯度指的方向。梯度的大小 = 那个方向的坡度有多陡。梯度的反方向 = 最陡的下坡路。

为什么是最快？——方向导数

你沿着任意方向走一小步，上升多快？这个速率叫做方向导数。它的公式很简单：

$$\text{方向导数} = \nabla f \cdot \mathbf{u}$$

$\nabla f$ 是梯度向量，$\mathbf{u}$ 是你选择的方向（长度=1 的单位向量）。

点乘公式告诉我们：$\nabla f \cdot \mathbf{u} = \|\nabla f\| \cdot 1 \cdot \cos\theta$。$\theta$ 是梯度和你走的方向之间的夹角。

  • $\theta = 0°$（和梯度同向）→ $\cos\theta=1$ → 上升最快
  • $\theta = 90°$（和梯度垂直）→ $\cos\theta=0$ → 高度不变（沿等高线走）
  • $\theta = 180°$（和梯度反向）→ $\cos\theta=-1$ → 下降最快（这就是梯度下降！）

所以梯度指的方向是最快上升方向——这不是定义，而是点乘取最大值的自然结果（$\cos\theta$ 在 $\theta=0°$ 时最大）。

梯度下降 = 闭着眼睛，每一步都往最陡的下坡方向踩一脚。 $$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$
  • $\theta_t$：你现在站的位置
  • $\nabla f(\theta_t)$：这个位置的最陡上坡方向
  • 负号：因为我们想下降，所以反着走
  • $\eta$（学习率）：走多大步。太大→可能跨过山谷冲到对面山上去了；太小→半天走不到底

🖥️ 代码

import numpy as np

# ===== 数值微分：用代码算坡度 =====
def num_grad(f, x, eps=1e-5):
    """中央差分：往前走一丁点，往后退一丁点，算平均坡度
    (f(x+eps)-f(x-eps)) / (2*eps) 
    精度比单边高：单边只看"往前"，中央看了"前后"然后取平均，误差抵消了一部分
    """
    return (f(x + eps) - f(x - eps)) / (2 * eps)

# 测试 f(x)=x²，理论导数 = 2x
def sq(x):
    return x ** 2

for x in [1, 2, 3]:
    n = num_grad(sq, x)           # 数值近似
    t = 2 * x                      # 理论：f'(x)=2x
    print(f"f'({x}) 数值={n:.6f}  理论={t}")

# ===== 梯度下降：从山顶走到山谷 =====
# f(x)=x²-4x+4 的最小值在 x=2（f'(x)=2x-4=0 → x=2）
x = 0.0                    # 站在 x=0 的位置
lr = 0.1                   # 学习率：每步走 0.1 倍的坡度
print(f"\n从 x=0 出发，目标 x=2")
for step in range(30):
    grad = 2*x - 4          # 当前位置的坡度
    x = x - lr * grad       # 沿着坡度反方向走一步
    if step % 5 == 0:
        print(f"  第{step:2d}步: x={x:.4f}  坡度={grad:+.4f}")
        # 坡度从 -4 逐渐变成 0，x 从 0 逐渐滑到 2

💭 概念题

  1. 梯度指向上升最快方向。为什么是"最快"？用方向导数 = 梯度与方向向量的点乘来解释。提示：$\cos\theta$ 在 $\theta=0°$（同向）时最大。——考察：方向导数的几何直觉
  2. 学习率太大的后果：画面上你站在山谷一边，步子太大跨到对面山上去了，再一步又跨回来，来回振荡——永远到不了谷底。试算一下 lr=1.5 在 x=1 处会发生什么。梯度是 $f'(1)=2\times1-4=-2$，更新后 x 变成多少？——考察：梯度下降的发散条件
  3. 中央差分为什么比单边差分更精确？中央用 $(x+\epsilon)$ 和 $(x-\epsilon)$ 两边的信息取平均，单边只用一边。在你心里过一遍：x² 的中央差分计算结果比单边差分更接近 2x 吗？——考察：对称差分抵消误差
