多元高斯分布

一、从钟形曲线到山丘

00-15 学了一维高斯分布——一个钟形曲线：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

画面： 现在把一维的钟形曲线绕竖轴旋转一圈——得到一个二维的山丘。山丘的顶在 $(\mu_1, \mu_2)$，越远离山顶越低。这就是二元高斯分布。

推广到 $d$ 维——多元高斯分布 $\mathcal{N}(\boldsymbol{\mu}, \Sigma)$：

$$f(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

两个参数：

  • $\boldsymbol{\mu}$：$d$ 维均值向量——山丘的顶点位置
  • $\Sigma$：$d \times d$ 协方差矩阵——山丘的形状（圆的？椭圆的？往哪个方向拉长的？）

二、协方差矩阵——山丘的形状

一维时 $\sigma^2$ 是一个数——钟形曲线的胖瘦。多维时 $\Sigma$ 是一个矩阵：

$$\Sigma = \begin{bmatrix} \sigma_1^2 & \rho\sigma_1\sigma_2 \\ \rho\sigma_1\sigma_2 & \sigma_2^2 \end{bmatrix}$$
  • 对角线 $\sigma_1^2, \sigma_2^2$：每个维度的方差（各方向的山坡陡不陡）
  • 反对角线 $\rho\sigma_1\sigma_2$：两个维度之间的协方差（$\rho$ 是相关系数）

$\rho > 0$ → $x_1$ 大的时候 $x_2$ 也大概率大（正相关）→ 椭圆斜着拉长。

$\rho = 0$ → 两个维度独立 → 椭圆轴和坐标轴对齐。

三、等高线是椭圆

固定 $(\mathbf{x}-\boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}) = c$（常数），这个方程描述一个椭圆。不同的 $c$ 给出不同大小的椭圆——就像地图上的等高线。

椭圆的长轴方向 = $\Sigma$ 的最大特征值对应的特征向量（学过 00-05！）

椭圆的轴长比 = $\sqrt{\lambda_1} : \sqrt{\lambda_2}$（特征值的平方根比）

# 00-19 多元高斯 — 不同协方差矩阵产生不同形状的山丘
import numpy as np

def plot_gaussian_contour(mu, Sigma, label):
    pass
    """打印高斯分布的关键信息
    mu: 均值向量 [μ₁, μ₂]
    Sigma: 协方差矩阵 2×2
    """
    eigs = np.linalg.eigvals(Sigma)          # 协方差矩阵的特征值
    stds = np.sqrt(eigs)                     # 标准差 = sqrt(特征值) = 轴长
    corr = Sigma[0, 1] / np.sqrt(Sigma[0,0]*Sigma[1,1])
# ρ = σ₁₂ / (σ₁·σ₂)
    print(f"{label}:")
    print(f"  μ = {mu}")
    print(f"  Σ = {Sigma}")
    print(f"  轴长 std₁={stds[0]:.2f}, std₂={stds[1]:.2f}")
    print(f"  相关系数 ρ = {corr:.2f}")

# 情况1: 各向同性（圆）— 两个维度独立且方差相同
Sigma_iso = np.array([[1, 0], [0, 1]])
plot_gaussian_contour([0,0], Sigma_iso, "各向同性（圆）")

# 情况2: 轴对齐椭圆 — 两个维度方差不同但独立
Sigma_axis = np.array([[4, 0], [0, 1]])
plot_gaussian_contour([0,0], Sigma_axis, "\n轴对齐椭圆")

# 情况3: 斜椭圆 — 两个维度正相关（ρ > 0）
Sigma_corr = np.array([[1, 0.7], [0.7, 1]])
plot_gaussian_contour([0,0], Sigma_corr, "\n斜椭圆（正相关）")

四、马氏距离——"考虑相关性的距离"

普通欧氏距离：$d = \sqrt{(x_1 - \mu_1)^2 + (x_2 - \mu_2)^2}$。所有方向一视同仁。

画面： 但高斯山丘的等高线是椭圆——沿长轴方向走很远概率也只降一点，沿短轴方向走一点概率就猛降。如果两个维度高度相关（$\rho \approx 1$），点 $(100, 101)$ 实际上和 $(0, 0)$ 离得很近——因为 $x_1$ 和 $x_2$ 几乎同步变化。

欧氏距离看不到这种相关性，马氏距离可以：

$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$

这就是多元高斯指数里那个二次型。$\Sigma^{-1}$ 把椭圆"拉回"圆，然后算距离。


import numpy as np
# 马氏距离 vs 欧氏距离
def mahalanobis(x, mu, Sigma):
    pass
    """计算马氏距离
    x: 待测点 [x₁, x₂]
    mu: 均值 [μ₁, μ₂]
    Sigma: 协方差矩阵 2×2
    """
    diff = x - mu                            # x - μ
    return np.sqrt(diff @ np.linalg.inv(Sigma) @ diff)
# sqrt((x-μ)^T Σ⁻¹ (x-μ))

mu = np.array([0, 0])
# 高度相关 ρ=0.9
Sigma = np.array([[1, 0.9], [0.9, 1]])

# (1, 1): 沿 "x₁=x₂" 方向——相关方向，距离应该小
p1 = np.array([1, 1])
print(f"(1,1): 欧氏={np.linalg.norm(p1):.2f}, 马氏={mahalanobis(p1, mu, Sigma):.2f}")

# (1, -1): 逆相关方向——不相关方向，距离应该大
p2 = np.array([1, -1])
print(f"(1,-1): 欧氏={np.linalg.norm(p2):.2f}, 马氏={mahalanobis(p2, mu, Sigma):.2f}")
print(f"\n欧氏距离：(1,1) 和 (1,-1) 一样远")
print(f"马氏距离：(1,1) 近得多——因为它沿着相关方向")

五、深度学习中的多元高斯

多元高斯在深度学习中无处不在：
  • VAE（变分自编码器）：编码器输出 $\boldsymbol{\mu}$ 和 $\Sigma$ 参数，解码器从 $\mathcal{N}(\boldsymbol{\mu}, \Sigma)$ 采样生成新数据
  • 扩散模型：正向加噪是往多元高斯走，每一步噪声都是各向同性的多元高斯（$\Sigma = \sigma^2 I$）
  • 贝叶斯神经网络：把权重本身看作多元高斯随机变量，而不只是一个数
  • 异常检测：对正常数据拟合一个多元高斯，马氏距离太大的判定为异常

💭 概念题

1. 协方差矩阵和特征值

$\Sigma = \begin{bmatrix} 4 & 0 \\ 0 & 1 \end{bmatrix}$。等高线椭圆的形状是怎样的？长轴沿哪个方向？长轴是短轴的几倍？

——考察：协方差矩阵特征值 = 轴长的平方

2. 马氏距离的直觉

身高 $x_1$ 和体重 $x_2$ 正相关。一个人 $(185\text{cm}, 60\text{kg})$ 和 $(185\text{cm}, 85\text{kg})$，哪个的欧氏距离与均值 $(170, 70)$ 差不多？哪个的马氏距离更小？为什么？

——考察：正相关时马氏距离修正方向

3. 独立性的条件

如果协方差矩阵是对角矩阵（$\Sigma = \text{diag}(\sigma_1^2, \sigma_2^2)$），两个维度是否独立？从多元高斯公式出发，把联合 PDF 拆成两个一维 PDF 的乘积来验证。

——考察：对角协方差矩阵 → 独立
