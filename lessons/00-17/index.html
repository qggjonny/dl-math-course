00-17 积分入门

一、曲线下的面积——微积分的另一半

画面： 你有一张速度-时间图。横轴是时间（秒），纵轴是速度（米/秒）。从第 0 秒到第 10 秒，你走了多远？

如果速度恒定（比如一直 5 m/s），答案很简单：$5 \times 10 = 50$ 米——就是矩形面积。

但如果速度在变呢？第 1 秒 3 m/s，第 2 秒 7 m/s，第 3 秒 4 m/s……曲线弯来弯去。这时候距离 = 曲线下的面积。

这就是积分要解决的问题：给一条曲线 $f(x)$，算它下面从 $a$ 到 $b$ 的面积。

🔗 微积分两块拼图：
微分（00-08）：给定路程，求瞬时速度——切线斜率
积分（本课）：给定速度，求总路程——曲线下面积
两者互为逆运算，就像加法和减法。

用矩形逼近——黎曼和的直觉

曲线弯，不好直接算面积。但如果我们把它切成很多细条，每条近似成矩形呢？

步骤：

  1. 把区间 $[a, b]$ 切成 $n$ 等份，每份宽度 $\Delta x = \frac{b-a}{n}$
  2. 在每一小段上，取该段某一点的函数值作为矩形的高
  3. 把所有矩形面积加起来：$\sum_{i=1}^{n} f(x_i) \cdot \Delta x$
  4. $n$ 越大（条越细），近似越精确。$n \to \infty$ 时，逼近真实面积

这就是黎曼和的核心思想——用直线逼近曲线，用有限算无限。

画面： 想象你在数一堆硬币。先把它们铺开，竖着切成 10 列，每列的高度就是硬币摞起来的个数。总硬币数 ≈ 每列高度 × 列宽。列越窄，数得越准。积分就是把列宽缩到无穷小，然后加总。

二、积分符号——一个拉长的 S

黎曼和的极限写法太啰嗦。莱布尼茨发明了一个简洁的符号：

$$\int_a^b f(x)\,dx$$

逐符号拆开：

  • $\int$：积分号——一个拉长的 S，来自拉丁文 "Summa"（总和）。提醒你积分本质是「无穷多小条之和」
  • $a$ 和 $b$：积分下限和上限——从哪到哪。$a$ 写下面，$b$ 写上面
  • $f(x)$：被积函数——曲线的高度
  • $dx$：积分变量和「无穷小宽度」——黎曼和里 $\Delta x$ 的极限形态。提醒你每条矩形的宽在极限下变成 0

整个符号读作：「从 a 到 b，f(x) 对 x 的积分」。意思是：把 f(x) 的曲线从 a 到 b 切成无穷多条宽 dx 的细条，每条面积 $f(x) \cdot dx$，全加起来。

📝 $dx$ 不是装饰： $dx$ 告诉你积分变量是谁。$\int f(x)\,dx$ 是对 $x$ 积分，$\int f(t)\,dt$ 是对 $t$ 积分——被积函数一样，但变量不同。它也是「乘上无穷小宽度」的记号残余——$\int$ 是加总，$dx$ 是被加的东西的「宽度」。

三、两个最简单的例子

例 1：常数函数——矩形面积

$f(x) = c$（常数）。曲线是一条水平线，高度恒为 $c$。从 $a$ 到 $b$ 下面的面积显然是矩形：

$$\int_a^b c\,dx = c \cdot (b - a)$$

因为每条宽 $\Delta x$ 的矩形高度都是 $c$，$n$ 条加起来：$c \cdot \Delta x \cdot n = c \cdot (b-a)$。

如果 $c=3$，$a=1$，$b=5$：面积 = $3 \times 4 = 12$。

例 2：线性函数——三角形 + 矩形

$f(x) = x$。从 $0$ 到 $b$ 下面的面积是一个直角三角形（底 $b$，高 $b$）：

$$\int_0^b x\,dx = \frac{b^2}{2}$$

因为三角形面积 = $\frac{1}{2} \times 底 \times 高 = \frac{b^2}{2}$。

从 $a$ 到 $b$（$a \geq 0$）：

$$\int_a^b x\,dx = \frac{b^2}{2} - \frac{a^2}{2}$$

就是大三角形减掉前面小的那块。

更一般地，如果把 $x$ 看成 $x^1$，积分会让幂次 +1 并除以新幂次：

$$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$$

这就是幂函数的积分公式——和求导公式 $\frac{d}{dx}x^n = nx^{n-1}$ 恰好对称：求导降幂乘系数，积分升幂除系数。

🧩 $+C$ 是什么？ 不定积分（没有上下限）时，需要加上常数 $C$。因为 $\frac{x^2}{2}$ 的导数是 $x$，$\frac{x^2}{2} + 100$ 的导数也是 $x$——常数求导后消失。所以反过来，积分时所有常数都「可能」存在，用 $+C$ 表示。定积分（有上下限）时 $C$ 会抵消，所以不用写。

四、微积分基本定理——导数与积分的互逆

这是微积分里最重要的一句话：导数和积分互为逆运算。

直观画面： 你有一个水桶，水龙头在往里面滴水。

  • 导数视角： 你知道桶里水位随时间的变化曲线 $h(t)$，求任意时刻的进水速度 → $h'(t)$
  • 积分视角： 你知道进水速度随时间的变化 $v(t)$，求 0 到 T 一共进了多少水 → $\int_0^T v(t)\,dt$

这两个操作互为逆：

$$\frac{d}{dx}\left[\int_a^x f(t)\,dt\right] = f(x)$$

先积分再求导，回到原函数：

$$\int_a^b f'(x)\,dx = f(b) - f(a)$$

先求导再积分，回到原函数的变化量。

不严格但准确的直觉： 积分是求导的逆运算，就像除法是乘法的逆运算。你知道 $2 \times 3 = 6$，反过来求「什么数乘以 3 等于 6」就是积分在干的事。

微积分基本定理把「面积问题」和「切线问题」连接起来了——你用求导的逆运算（反导数）就能算出面积，不用每次切矩形！

五、积分与概率——面积就是概率

回到 00-16 学的概率密度函数 $f(x)$。连续随机变量 $X$ 落在区间 $[a, b]$ 的概率：

$$P(a \leq X \leq b) = \int_a^b f(x)\,dx$$

画面： 概率密度曲线像一座山。你想知道身高在 170-175cm 之间的人占多少比例——那就是这座山在 170 到 175 之间的面积。整座山的总面积一定是 1（总概率 = 100%）。

这就是为什么概率密度可以大于 1（山可以很尖），但积分（面积）必须在 0 到 1 之间。密度是高度，概率是面积——两回事。

📐 积分在深度学习里无处不在：
• 损失函数：对整个数据集的误差求和 → 连续形式就是积分
• 概率论：$\mathbb{E}[X] = \int x f(x)\,dx$ ——期望也是积分
• 信息论：熵 $H = -\int f(x) \ln f(x)\,dx$ ——信息量的加权平均
• 归一化：softmax 的分母，归一化流中的 Jacobian 行列式积分

六、代码：用黎曼和逼近积分

我们用手算 $\int_0^3 x^2\,dx$。解析解：$\frac{x^3}{3}\big|_0^3 = \frac{27}{3} - 0 = 9$。

下面用黎曼和（矩形法）逼近，看 $n$ 变大时怎么收敛到 9：

# 00-17 黎曼和：用矩形逼近 ∫₀³ x² dx，解析解 = 9
# 导入numpy，别名np
import numpy as np

# 被积函数：f(x) = x²
def f(x):
    return x**2

# 积分区间 [a, b] = [0, 3]
a, b = 0, 3

# 用不同数量的矩形逼近：n=10, 100, 1000, 10000
for n in [10, 100, 1000, 10000]:
    # np.linspace(a,b,n+1)：在[a,b]之间均匀取n+1个点 → n个小区间
    x_edges = np.linspace(a, b, n+1)
    # 每个小矩形的宽度 Δx = (b-a)/n
    dx = (b - a) / n
    # 用右端点法：取每个小区间右端点的函数值作为矩形高
    # x_edges[1:] 取从第1个到最后一个点（n个右端点）
    x_right = x_edges[1:]
    # 高度数组 = f(每个右端点x值)
    heights = f(x_right)
    # 黎曼和：Σ f(xᵢ) · Δx → 所有矩形面积之和
    riemann_sum = np.sum(heights) * dx
    # f-string输出：n值和对应的黎曼和近似值
    print(f"n={n:5d}  →  黎曼和 = {riemann_sum:.6f}")

# 解析解（精确值）：∫₀³ x² dx = x³/3|₀³ = 27/3 = 9
exact = 9
print(f"\n解析解（精确值）：{exact}")

# 用 n=10000 的误差展示收敛效果
x_edges = np.linspace(a, b, 10001)
riemann_10k = np.sum(f(x_edges[1:])) * ((b-a)/10000)
print(f"n=10000 误差：{abs(riemann_10k - exact):.8f}")

🔗 在线运行

输出大约：n=10 → 9.135，n=100 → 9.0135，n=1000 → 9.00135，n=10000 → 9.000135。看到没？每多一个数量级的细分，误差就减少约 10 倍——黎曼和一阶收敛。

注：右端点法对递增函数会高估面积（取右边最高点），左端点法会低估。取中点更准。

进阶：用梯形法改进

矩形法的升级版——每条不用矩形，用梯形（上边是斜线，更像原曲线）：

# 00-17 梯形法：比矩形法收敛更快（二阶）
import numpy as np

# 同样的 f(x)=x², 区间[0,3]
a, b = 0, 3
def f(x): return x**2

for n in [10, 100, 1000]:
    # n+1个等间距点（包含两端）
    x = np.linspace(a, b, n+1)
    y = f(x)
    dx = (b - a) / n
    # 梯形公式：面积 ≈ Δx/2 · [y₀ + 2y₁ + 2y₂ + ... + 2yₙ₋₁ + yₙ]
    # 两端系数为1，中间系数为2 → 头和尾各算半次，中间算完整
    trapezoid_sum = dx * (0.5*y[0] + np.sum(y[1:-1]) + 0.5*y[-1])
    # f-string，保留8位小数
    print(f"n={n:4d}  梯形法 = {trapezoid_sum:.8f}  误差={abs(trapezoid_sum-9):.2e}")

🔗 在线运行

梯形法 $n=10$ 的误差就已经比矩形法 $n=100$ 还小——二阶收敛，快得多。
