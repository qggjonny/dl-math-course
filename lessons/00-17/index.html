00-17 概率基础

一、抛硬币：不确定的世界

画面： 你手里有一枚硬币。把它往上一抛——在硬币落地之前，你不知道它是正面还是反面。这就是随机试验（random experiment）：结果在发生前无法确定，但所有可能的结果我们是知道的。

你抛了一次，正面。又抛了一次，反面。再抛一次，又是正面。抛 10 次，7 次正面、3 次反面。抛 1000 次呢？大概 500 次正面，500 次反面。抛得越多，正面的比例越接近 0.5。

这个「0.5」就是概率——对不确定事件发生的可能性给一个精确的数字。它不是预言单次结果（你永远不知道下一次是正还是反），而是描述大量重复后的稳定频率。

🎯 核心区分： 概率 ≠ 预言。概率告诉你扔10000次大约5000次正面，但不告诉你第37次是什么。就像天气预报说「明天下雨概率70%」——不是说明天一定下雨或一定不下雨，而是说：类似的气象条件下，10次里有7次会下雨。

二、样本空间与事件

抛一枚硬币，可能的结果就两个：{正面, 反面}。这就是样本空间（sample space），记作 $S$ 或 $\Omega$——所有可能结果的集合。

抛一枚骰子：$S = \{1,2,3,4,5,6\}$。样本空间的大小就是可能结果的总数。

事件（event）是样本空间的子集——你关心的某些结果组成的集合。比如：

  • 「掷出偶数」→ $A = \{2,4,6\}$
  • 「掷出大于 4 的点」→ $B = \{5,6\}$
  • 「掷出 1 点」→ $C = \{1\}$（单个结果也是事件，叫基本事件）

事件就是一个「命题」——你问「掷出偶数了吗？」如果结果是 2、4 或 6 中的任何一个，事件就发生了。

三、概率的三条公理

概率 $P$ 是定义在事件上的函数，把每个事件映射到 $[0,1]$ 之间的一个数。它必须满足三条规则——不是推导出来的，是定义：

公理 ①：非负性与上界

$$0 \leq P(A) \leq 1$$

概率不能是负数（「这件事 -30% 会发生」没有意义），也不能大于 1（「120% 会发生」也是胡说）。0 = 绝不可能，1 = 必然发生。

公理 ②：样本空间的概率为 1

$$P(S) = 1$$

每次试验必然会出现样本空间中的某个结果。掷骰子，结果必然在 $\{1,2,3,4,5,6\}$ 之中——没有第七种可能。所以「出现某个结果」这件事的概率是 1。

公理 ③：互斥事件的加法

如果 $A$ 和 $B$ 互斥（disjoint，即 $A \cap B = \varnothing$——两个事件不可能同时发生），则：

$$P(A \cup B) = P(A) + P(B)$$

画面： 掷骰子。$A = \{1,2\}$（掷出 1 或 2），$B = \{5,6\}$（掷出 5 或 6）。$A$ 和 $B$ 没有重叠——一个结果不可能同时属于 $\{1,2\}$ 和 $\{5,6\}$。所以「掷出 1、2、5 或 6」的概率就是 $P(A)+P(B)$。

概率就像面积：互斥事件就是把两块不相交的区域并起来，总面积 = 各自面积之和。

⚠️ 公理 ③ 只对互斥事件成立。 如果 $A$ 和 $B$ 有重叠（比如 $A=\{2,4,6\}$ 偶数，$B=\{4,5,6\}$ 大于3），用 $P(A)+P(B)$ 会把重叠部分（4和6）算了两次。这种情况后面学「条件概率」时会处理。

四、古典概型：等可能结果

当样本空间中所有基本结果等可能时（公平硬币、公平骰子），概率计算变得极其简单：

$$\boxed{P(A) = \frac{\text{事件 A 包含的结果数}}{\text{样本空间的总结果数}} = \frac{|A|}{|S|}}$$

这个公式也叫拉普拉斯概率。它来自三条公理：因为每个基本结果等可能，设为 $p$；$n$ 个结果，公理②说 $np = 1$，所以 $p = 1/n$。事件 $A$ 有 $|A|$ 个结果，公理③把它们加起来：$P(A) = |A| \times p = |A|/n$。

走一遍例子：

  • 掷公平骰子，掷出偶数的概率：$A=\{2,4,6\}$，$|A|=3$，$|S|=6$，$P=3/6=1/2$
  • 掷出大于 4 的概率：$B=\{5,6\}$，$P=2/6=1/3$
  • 掷出 7 的概率：$C=\varnothing$（空集），$P=0/6=0$——不可能事件

古典概型的陷阱： 「等可能」这个前提很关键。扔一枚被压扁的硬币（重心不均），正面和反面就不再等可能了——公式失效，需要靠实验或物理模型来估计概率。深度学习里大多数概率都不是古典概型，而是从数据中学出来的。

五、随机变量：把结果变成数字

概率论要算期望、方差、分布——这些都需要数字。但「正面」「反面」是文字，不是数字。所以我们需要一个翻译：随机变量（random variable）。

随机变量是一个函数，把样本空间的每个结果映射到一个实数。

抛硬币：定义 $X$：

$$X(\text{正面}) = 1, \qquad X(\text{反面}) = 0$$

掷骰子：定义 $Y$ 为「掷出的点数」——$Y(1)=1, Y(2)=2, \dots, Y(6)=6$。这个最简单，随机变量的取值就是结果本身。

随机变量不是变量，是函数。 名字叫「变量」是历史遗留。它本质上是从 $\Omega \to \mathbb{R}$ 的映射。输入一个随机结果，输出一个数字。

有了随机变量，「掷出正面的概率」可以写成：

$$P(X = 1) = 0.5$$

有了数字，就能定义接下来要学的期望（平均值）、方差（散布程度）、各种分布——整个概率大厦都建立在随机变量之上。

六、大数定律：频率收敛到概率

概率说正面是 0.5——但凭什么相信？抛 10 次，可能 7 次正面（频率 0.7），和 0.5 差得远。是概率错了，还是抛得不够多？

大数定律（Law of Large Numbers）回答了这个问题：试验次数越多，频率越接近概率。

抛 10 次，频率可能是 0.3 或 0.7。抛 1000 次，频率几乎一定在 0.47~0.53 之间。抛 100000 次，频率几乎就是 0.5。

这就是概率的「物理意义」——它不是玄学，是通过大量重复可以验证的稳定频率。下面用代码来亲眼看看：

# 00-18 概率模拟：抛硬币，看频率如何随次数收敛到 0.5
# 导入numpy，别名np，提供随机数和数组运算
import numpy as np

# np.random.seed(42)：固定随机种子，保证每次运行结果一致
# 42 是惯例数字（《银河系漫游指南》梗），换成任何整数都可以
np.random.seed(42)

# 总抛掷次数 N=10000
N = 10000

# np.random.random(N) → 生成 N 个 [0,1) 之间的均匀随机浮点数
# 每个数有 50% 概率 < 0.5（对应正面），50% 概率 ≥ 0.5（对应反面）
# random()只有一个参数size=N → 返回长度为N的一维数组
flips = np.random.random(N)

# flips < 0.5 → 布尔数组，True=正面(1), False=反面(0)
# .astype(int) 将 True→1, False→0，得到整数数组
heads = (flips < 0.5).astype(int)

# np.cumsum() → 累积和：第i个元素 = 前i+1个元素之和
# 即前k次抛掷中正面出现的总次数
cum_heads = np.cumsum(heads)

# np.arange(1, N+1) → [1, 2, 3, ..., 10000]，即前k次的k
# 累积正面次数 / 抛掷次数 = 频率
freq = cum_heads / np.arange(1, N+1)

# 输出几个关键节点的频率看收敛趋势
# 前10次：频率波动大，可能远偏离 0.5
print(f"前 10 次频率: {freq[9]:.3f}")
# 前100次：开始稳定趋向 0.5
print(f"前 100 次频率: {freq[99]:.3f}")
# 前1000次：已经很接近 0.5
print(f"前 1000 次频率: {freq[999]:.3f}")
# 全部10000次：几乎就是 0.5
print(f"全部 {N} 次频率: {freq[-1]:.4f}")

# 再换一组更大的试验：N=100000，不设种子看随机波动
# np.random.random(100000) → 生成十万个随机数
big_flips = np.random.random(100000)
# 正面 = 随机数 < 0.5，.mean()直接算频率（True=1, False=0）
big_freq = (big_flips < 0.5).mean()
# 输出十万次频率 → 非常接近 0.5
print(f"\\n十万次抛硬币频率: {big_freq:.5f}")

🔗 在线运行

运行几次（删掉 seed 那行），你会发现：每次 10 次的结果飘忽不定（0.3, 0.6, 0.5...），但 10000 次的结果始终在 0.5 附近（误差不超过 0.01）。这就是大数定律在起作用。

📊 关键洞察： 频率 → 概率的收敛不是「每次都比上一次更近」（会有波动），而是统计意义上的收敛——偏差越来越小的概率趋向于 1。这不等于频率一定等于概率（技术上，抛无限次才完全相等），但在有限次里，结果以极高概率落在概率附近。
