00-13 梯度下降

一、从梯度到梯度下降

00-11 学到了：梯度指向函数值上升最快的方向。现在反过来——如果我想找最小值（谷底），每一步往梯度的反方向走。

梯度下降 = 闭着眼睛，每一步都往最陡的下坡方向踩一脚。 $$\theta_{t+1} = \theta_t - \eta \cdot \nabla f(\theta_t)$$
  • $\theta_t$：你现在站的位置
  • $\nabla f(\theta_t)$：这个位置的最陡上坡方向
  • 负号：因为我们想下降，所以反着走
  • $\eta$（学习率）：走多大步。太大→可能跨过山谷冲到对面山上去了；太小→半天走不到底

二、代码演示——亲眼看着小球滚下山

拿最简单的二次函数 $f(x) = x^2$ 来跑梯度下降。最小值显然在 $x=0$。我们故意从 $x=3$ 出发，看它能不能滚回去。

# 00-13 第二节：梯度下降——亲眼看着小球从 x=3 滚到 x≈0
# 导入numpy，别名np
import numpy as np

# 定义函数 f(x)=x² 和它的导数 f'(x)=2x
# 导数 f'(x) 告诉我们每一步该往哪走——梯度方向
def f(x):
    """f(x) = x²——最简单的抛物线，谷底在 x=0"""
    return x**2

def df(x):
    """f'(x) = 2x——导数，指向上升最快的方向"""
    return 2 * x

# 初始位置——从 x=3 出发（函数值=9，离谷底 x=0 还有 3 个单位）
# 学习率 η=0.3（相当于每次往谷底走 30% 的当前偏移）
x = 3.0
# 学习率：步长参数，控制每步走多远
eta = 0.3

# 迭代 15 次——每一步打印：第几步、位置 x、函数值 f(x)、梯度 df(x)
# f"{i:2d}"：第几步，占 2 位右对齐，方便对齐阅读
# f"{x:8.4f}"：x 值，占 8 位保留 4 位小数
# f"{f(x):8.4f}"：函数值，格式同上
print(f"{'步':>3s}  {'x':>8s}  {'f(x)':>8s}  {'梯度':>8s}")
print("-" * 35)
for i in range(15):
    # 保存更新前的位置用于打印
    x_old = x
    # 梯度下降核心：x_new = x_old - η × f'(x_old)
    # 负号表示往梯度的反方向走——下坡
    x = x - eta * df(x)
    print(f"{i:3d}  {x_old:8.4f}  {f(x_old):8.4f}  {df(x_old):8.4f}")

# 最终位置——如果收敛，x 应该非常接近 0
print(f"\n最终: x={x:.6f}, f(x)={f(x):.10f}")

🔗 在线运行

看输出：x 从 3.0 → 1.2 → 0.48 → 0.192 → 0.077 → ... → 趋近于 0。每一步的梯度（2x）越来越小——坡度越来越缓，步幅也越来越小。这是在「自刹车」——越靠近谷底，自然就走得越慢。

为什么步幅自动缩小？

$f(x)=x^2$ 的导数是 $2x$。梯度下降的更新是 $x_{t+1} = x_t - \eta \cdot 2x_t = (1-2\eta)x_t$。

当 $\eta=0.3$ 时：$x_{t+1} = (1-0.6)x_t = 0.4x_t$。每一步位置缩为原来的 40%——呈指数衰减。

本质原因：$f'(x)=2x$ 在谷底（x=0）为零，越靠近谷底导数越小，更新量自然变小——这是梯度下降「自刹车」的根源。

三、学习率多大算太大？——发散条件

不是说「学习率太大了会跨过山谷」——要多大才会跨过去？用二次函数来精确算。

拿 $f(x) = x^2 - 4x + 4$（配成 $(x-2)^2$），谷底在 $x=2$，导数 $f'(x) = 2x - 4$。

梯度下降更新：

$$x_{t+1} = x_t - \eta \cdot (2x_t - 4) = (1 - 2\eta) x_t + 4\eta$$

关心的是离谷底还有多远，所以定义误差 $e_t = x_t - 2$。注意这里的 $2$ 不是随便取的——它就是谷底的位置，也就是 $(x-2)^2$ 取到最小值时那个 $x$：

$$e_{t+1} = x_{t+1} - 2 = (1-2\eta)x_t + 4\eta - 2 = (1-2\eta)(x_t - 2) = (1-2\eta) \cdot e_t$$

每一步误差乘以 $(1-2\eta)$：

  • $|1-2\eta| < 1$ → 误差越来越小 → 收敛。解：$-1 < 1-2\eta < 1$ → $0 < \eta < 1$
  • $|1-2\eta| = 1$ → 误差不变 → 来回跳但不缩小（$\eta=1$ 时原地振荡）
  • $|1-2\eta| > 1$ → 误差越来越大 → 发散！

验证 $\eta = 1.5$： $1-2\eta = 1-3 = -2$，$|{-2}| = 2 > 1$ → 发散。从 $x_0 = 1$ 出发：误差 $e_0 = 1-2 = -1$（谷底在右边，人在左边）。$e_1 = (-2) \times (-1) = 2$，$|e_1| = 2 > |e_0| = 1$——越走越远。直接算：$x_1 = 1 - 1.5 \times (-2) = 1 + 3 = 4$，从谷底左边直接跳到右边更远的地方——发散无疑。

四、从特例到一般——$f(x) = ax^2 + bx + c$ 的收敛条件

第三节那条 $0 < \eta < 1$ 是 $a = 1$ 的特例。把数字换成字母 $a$、$b$、$c$ 之后，结论会变成什么样？设 $a > 0$（开口向上才有谷底）。

第一步——先找谷底。谷底是斜率为零的位置。按 00-11 的多项式求导规则（$ax^2$ 的导数是 $2ax$、$bx$ 的导数是 $b$、常数项导数是 $0$），$f'(x) = 2ax + b$。令它为零：

$$2ax + b = 0 \Longrightarrow x^* = -\frac{b}{2a}$$

这里就看清了 $b$ 和 $c$ 各干什么：$c$ 根本不在导数里——它只把曲线上下平移，不改变任何一点的坡度；$b$ 只有一件事——把谷底从原点挪到 $x^*$。核对第三节：$f = x^2 - 4x + 4$ 里 $a=1$、$b=-4$，代入得 $x^* = 4/2 = 2$ ✓ 正是第三节那个谷底。

第二步——把导数写成「离谷底多远」。第三节的导数 $f'(x) = 2x - 4$ 里那个 $-4$，和它的谷底 $x=2$ 有个关系：$-4 = -2 \times 1 \times 2$。这不是巧合——把第一步的 $2ax^* + b = 0$ 移项，就得到

$$b = -2ax^*$$

把它代回导数，$b$ 就消失了：

$$f'(x) = 2ax + b = 2ax - 2ax^* = 2a\,(x - x^*)$$

括号里就是第三节的误差 $e = x - x^*$——离谷底还有多远。所以 $f'(x) = 2a\,e$。

几何读法：坡度 = $2a$ × 离谷底的距离。$2a$ 是一个固定的数（由曲线弯得多急决定），所以坡度只取决于你站得离谷底多远——离得远坡就陡，站到谷底（$e=0$）坡为零，不再动。第三节的 $f'(x) = 2(x-2)$ 就是这个式子在 $a=1$、$x^*=2$ 时的样子 ✓

第三步——照抄第三节。更新式 $x_{t+1} = x_t - \eta f'(x_t)$ 两边同时减 $x^*$，左边正好是 $e_{t+1}$：

$$e_{t+1} = x_{t+1} - x^* = x_t - \eta \cdot 2a\,e_t - x^* = (1-2a\eta)(x_t - x^*) = (1-2a\eta)\,e_t$$

式和第三节一模一样，只是 $2\eta$ 换成了 $2a\eta$。后面的分析不用重算——每一步误差都乘同一个数 $r = 1-2a\eta$，$|r| < 1$ 时误差归零，解出

$$0 < \eta < \frac{1}{a}$$

回看特例：$a = 1$ → $0 < \eta < 1$，就是第三节那条；$f(x) = x^2$ 也是 $a = 1$，同样要求 $\eta < 1$ ✓

再用 $f'' = 2a$（二阶导数——把导数再求一次导）把上界写成只跟弯曲程度有关的形式：$\eta_{\max} = \frac{1}{a} = \frac{2}{f''}$——步长上限由曲线弯得急不急决定，与当前梯度多大无关。

拿 $a=2$、$b=-3$、$c=7$ 跑一遍（谷底 $x^* = 0.75$，上界 $\eta < 0.5$），边界看得见：

# 00-13 第四节：一般二次函数 f(x)=ax²+bx+c——用代码看 η<1/a 这条边界
# 取 a=2, b=-3, c=7——谷底在 x*=-b/(2a)=0.75，收敛上界 1/a=0.5
a = 2.0
b = -3.0
c = 7.0

# 谷底位置：解 f'(x)=2ax+b=0，得 x*=-b/(2a)
x_star = -b / (2 * a)
# 收敛上界：η 必须小于 1/a
eta_max = 1 / a
print(f"谷底 x*={x_star}, 收敛要求 η<{eta_max}")

# 导数 f'(x)=2ax+b——这里用 a、b 算，不再写死数字
def grad(x):
    """f'(x)=2ax+b，指向上升最快的方向"""
    return 2 * a * x + b

# 试 3 个学习率：0.45 收敛、0.50 卡在边界、0.51 越界
for eta in [0.45, 0.50, 0.51]:
    # 每个学习率都从同一点出发：x=1.0
    x = 1.0
    # 误差乘子：每步误差都乘以它，|r|<1 才收敛
    r = 1 - 2 * a * eta
    # 打印这个小节的开头：η 和误差乘子的绝对值
    print(f"\nη={eta:.2f}  |1-2aη|={abs(r):.2f}")
    # 走 6 步，每步打印：第几步、当前位置、误差（离谷底的距离）
    for step in range(6):
        print(f"  第{step}步  x={x:8.4f}  e={x - x_star:8.4f}")
        # 梯度下降更新：x ← x - η·f'(x)
        x = x - eta * grad(x)

🔗 在线运行

看这 3 段输出：$\eta = 0.45$ 在区间内，误差 0.2500 → −0.2000 → 0.1600 → …，符号左右横跳但绝对值每步缩为 80%（乘子 $|1-2a\eta| = 0.80$），最终归零；$\eta = 0.50$ 正好卡在 $\eta = 1/a$ 上，乘子的绝对值等于 1，误差 0.2500 → −0.2500 → 0.2500 → …，大小一点不变，人在谷底两边永远来回跳；$\eta = 0.51$ 越过上界，乘子绝对值等于 1.04，0.2500 → −0.2600 → 0.2704 → …，一步比一步大——发散。

注意 $\eta = 0.45$ 那一段也出现过符号横跳（跨过谷底冲到另一侧），它照样收敛——判断收敛看的是误差的绝对值，不是符号。

五、代码验证——亲眼看到发散

把第三节的 $\eta=1.5$ 跑一遍，看发散长什么样：

# 00-13 第五节：学习率太大导致发散——亲自跑一遍
# 函数 f(x) = x² - 4x + 4，谷底在 x=2
def f2(x):
    """f(x)=x²-4x+4=(x-2)²，谷底 x=2, f(2)=0"""
    return x**2 - 4*x + 4

def df2(x):
    """f'(x) = 2x - 4"""
    return 2*x - 4

# 学习率 η=1.5——超过收敛条件 η<1，应该发散
# 从 x=1 出发，离谷底 x=2 差 1 个单位
x = 1.0
# 学习率达 1.5——太大，误差会指数爆炸
eta = 1.5

print(f"{'步':>3s}  {'x':>10s}  {'|误差|':>10s}")
print("-" * 28)
for i in range(8):
    # 误差 = 当前位置离谷底 (x=2) 的距离的绝对值
    # 如果发散，这个值应该越来越大
    error = abs(x - 2)
    print(f"{i:3d}  {x:10.4f}  {error:10.4f}")
    # 梯度下降更新——同一条公式，但 η 太大导致误差翻转放大
    x = x - eta * df2(x)

# 最后一次更新后的位置——应该比起点离 x=2 更远
print(f"\n8步后: x={x:.4f}, |误差|={abs(x-2):.4f}")
print(f"误差从 1.0 变成了 {abs(x-2):.1f}——越走越远，发散！")

🔗 在线运行

输出中误差从 1.0 开始，每一步翻倍——这就是发散。小球没有被「吸」向谷底，而是被「弹」向远方。

💭 概念题

  1. 学习率太大的后果：画面上你站在山谷一边，步子太大跨到对面山上去了，再一步又跨回来，来回振荡——永远到不了谷底。试算一下 lr=1.5 在 x=1 处（$f(x)=x^2-4x+4$）会发生什么。梯度是 $f'(1)=2\times1-4=-2$，更新后 x 变成多少？——考察：梯度下降的发散条件
  2. 对于 $f(x)=x^2$，用 $\eta=0.3$ 时每步位置缩为原来的 $1-2\eta=0.4$ 倍。如果 $\eta=0.1$，每步位置缩为原来的多少倍？哪个收敛更快？为什么不是 $\eta$ 越大越好？（提示：想想 $\eta=0.9$ 会怎样）——考察：收敛速度与学习率的关系
  3. 梯度下降的「自刹车」——为什么越靠近谷底步子越小？从 $f(x)=x^2$ 的导数 $f'(x)=2x$ 在 $x\to 0$ 时的行为解释。——考察：导数在极值点为零的几何后果
  4. 为什么 $f(x) = ax^2$ 里 $a$ 越大，能用的学习率上界 $1/a$ 越小？从误差乘子 $1-2a\eta$ 出发解释，并说明 $\eta = 1/a$ 时误差会怎样变化。——考察：曲率（二阶导数）对收敛条件的影响
