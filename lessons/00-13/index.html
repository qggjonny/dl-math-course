凸性与优化

一、梯度下降的"体检报告"

00-10 学了梯度下降——小球沿坡度往下滚，每一步往梯度反方向走。但有一个问题没回答：

小球最后停在哪里？是全局最低点，还是某个坑里？

这完全取决于"地形"是不是凸的。

二、凸函数的几何画面

画面： 拿一根橡皮筋，两端固定在曲线上。如果函数是凸的，橡皮筋永远在曲线的上方（或重合）。

换成数学：对任意两点 $x_1, x_2$ 和任意比例 $t \in [0, 1]$：

$$f(tx_1 + (1-t)x_2) \le t f(x_1) + (1-t) f(x_2)$$

左边是曲线上的函数值，右边是弦上的值。凸函数就是「弦在曲线上方」。

一句话：凸函数的图像像一个碗，随便选两个点，连线的中点比两个端点的函数值平均值低。

三、正例和反例

函数凸？画面
$f(x) = x^2$✅ 凸U 形碗，只有一个底
$f(x) = e^x$✅ 凸指数增长，越来越陡
$f(x) = -\ln x$（$x > 0$）✅ 凸递减但向下弯，像滑雪坡
$f(x) = x^3$❌ 非凸S 形，左边凸右边凹
$f(x) = \sin x$❌ 非凸波浪形，有无穷多个坑
# 00-13 凸 vs 非凸 — 用二阶导数判断
import numpy as np

def is_convex_1d(f, xs):
    """对一维函数采样，检查弦在曲线上方（数值验证凸性）
    f: 待检查的函数
    xs: 采样点数组
    返回: True 表示在这些采样点上看起来是凸的
    """
    n = len(xs)
    for i in range(n):
        for j in range(i+1, n):
            for t in [0.25, 0.5, 0.75]:
                xi, xj = xs[i], xs[j]        # 选两个端点
                x_mid = t*xi + (1-t)*xj      # 弦上的一点
                # 凸函数条件：f(中间点) ≤ t*f(xi) + (1-t)*f(xj)
                if f(x_mid) > t*f(xi) + (1-t)*f(xj) + 1e-10:
                    return False
    return True

xs = np.linspace(-3, 3, 30)

print("x² 凸?", is_convex_1d(lambda x: x**2, xs))             # True
print("x³ 凸?", is_convex_1d(lambda x: x**3, xs))             # False
print("sin(x) 凸?", is_convex_1d(np.sin, xs))              # False
print("eˣ 凸?", is_convex_1d(np.exp, xs))                 # True

四、二阶导数判定法

一维函数判断凸性有个简单方法：看二阶导数。

$$f''(x) \ge 0 \text{ 对所有 } x \quad\Longleftrightarrow\quad f \text{ 是凸函数}$$

直觉： $f''(x)$ 是坡度的变化率。$f'' \ge 0$ 意味着越往前走坡越陡——函数向上弯。就像碗的侧面：从碗边走到碗底，坡度从陡变缓再变陡，但没有"反向弯"。

$$f''(x) < 0 \quad\Longrightarrow\quad \text{上凸，凹的（像倒扣的碗）}$$ 
# 二阶导验证凸性
def check_convexity_2nd(f, f_dd, xs):
    """给定函数的解析二阶导数，验证凸性
    f: 原函数
    f_dd: 二阶导函数
    xs: 检查点
    """
    for x in xs:
        dd = f_dd(x)                     # 二阶导数值
        if dd < -1e-10:                     # 如果有个点的二阶导 < 0
            print(f"  x={x:.1f}: f''={dd:.2f} < 0 → 非凸")
            return False
    return True

xs = np.linspace(-3, 3, 20)

print("x²: 二阶导 = 2 ≥ 0",
      "→ 凸" if check_convexity_2nd(lambda x: x**2,
                                            lambda x: 2, xs)
      else "→ 非凸")
                                   # f(x)=x², f''(x)=2 恒≥0

print("\nx³: 二阶导 = 6x，可正可负",
      "→ 凸" if check_convexity_2nd(lambda x: x**3,
                                            lambda x: 6*x, xs)
      else "→ 非凸")
                                   # f(x)=x³, f''(x)=6x: x<0时负,x>0时正

五、多元函数：Hessian 矩阵

对多元函数 $f(\mathbf{x})$，二阶导变成一个矩阵——Hessian：

$$H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$$

画面： 一维时 $f''(x) \ge 0$ 说明碗向上弯。多元时，所有方向都向上弯 = Hessian 是半正定矩阵。

回到 00-05 特征值的直觉：半正定 = 所有特征值 ≥ 0。等价于沿任何方向 $\mathbf{v}$，都有 $\mathbf{v}^T H \mathbf{v} \ge 0$（二阶方向导数非负）。

# 多元凸函数：f(x,y) = x² + y²（抛物面）
def f(X):
    """f(x,y) = x² + y²，X 是 2 维向量 [x, y]
    二阶导矩阵（Hessian）= [[2, 0], [0, 2]]
    特征值 = 2, 2 → 都 ≥ 0 → 凸 ✅
    """
    return X[0]**2 + X[1]**2

def f2(X):
    """f(x,y) = x² − y²（马鞍面）
    Hessian = [[2, 0], [0, -2]]
    特征值 = 2, −2 → 有负的 → 非凸 ❌
    """
    return X[0]**2 - X[1]**2

# 用有限差分近似 Hessian
eps = 1e-5
for name, func in [("x²+y²", f), ("x²−y²", f2)]:
    x0 = np.array([1.0, 1.0])             # 在 (1, 1) 处算 Hessian
    # 手动计算 2×2 Hessian 矩阵的每个元素
    # H[0,0] = ∂²f/∂x²: 对 x 做两次差分
    f0 = func(x0)
    x1 = x0 + np.array([eps, 0])        # x+eps, y 不变
    x2 = x0 - np.array([eps, 0])        # x-eps, y 不变
    H00 = (func(x1) - 2*f0 + func(x2)) / eps**2
    # 同理 H[1,1] = ∂²f/∂y²
    y1 = x0 + np.array([0, eps])
    y2 = x0 - np.array([0, eps])
    H11 = (func(y1) - 2*f0 + func(y2)) / eps**2
    # 交叉项用中心差分近似
    H = np.array([[H00, 0], [0, H11]])
    eigs = np.linalg.eigvals(H)          # Hessian 特征值
    print(f"{name}: Hessian 特征值 = {np.round(eigs,2)}, 凸? {np.all(eigs >= 0)}")

六、凸 = 梯度下降保证收敛到全局最优

结论： 如果损失函数是凸的，梯度下降一定会走到全局最低点——不管从哪个起点出发。

如果不是凸的（神经网络就是这样）：

  • 可能卡在局部最优（local minimum）——附近最低但不是全局最低
  • 可能卡在鞍点（saddle point）——某个方向是谷底、另一个方向是山脊
  • 好在实践中，大网络的鞍点和局部最优往往没那么差——这是深度学习的"蜜汁好运"
为什么凸性重要： 线性回归的 MSE 是凸函数 → 一定有唯一解析解。逻辑回归的交叉熵是凸函数 → 梯度下降一定收敛。但神经网络没有这个保证——一切靠经验调参。
